Hello，各位。相信 MCP、Agent、RAG、Claude Code、OpenClaw，这些概念本身都不难，但放在一起就都乱了。原因只有一个，就是你没有建立好自己的概念坐标系。它是在哪一层，以及跟其他概念是什么关系，你可能会懵掉。所以今天我想用一家公司的结构作为类比，来给你捋一遍。我给它分成了五层。

第一层，我给它定义的就是大脑。公司要运转，就得先有人。这个人，或者说这个大脑，就是 LLM，也就是大语言模型。像我们说的 GPT、Claude，本质上都是同一个东西，叫做超级预测机器。你给它文字，它预测下一个词是什么。听起来很简单，但是这个能力叠加到极致，能够去写代码、帮你做分析、帮你做翻译、帮你做聊天。

OK，那如果我们要去理解 LLM 这个概念，有几个词是绕不开的。第一个叫做 Token，这个是大语言模型处理信息的最小单元，中文名叫做词元。你发的每句话，它都会先拆成 Token 再处理。Token 越多越贵，你整个推理的成本就越高，推理速度也就越慢。

第二个概念叫做 Context Window，这个叫做上下文窗口，是它的工作记忆。AI 为什么有的时候会忘掉前面说的？因为超出了记忆的上限。所以窗口越大，记得也就越多。很多的工作都在去看怎么把这个上下文窗口扩大。

第三个叫做多模态，Multimodal。多模态指的是它不只能够读文字，还能够看图、听声音。比如你发张图让 AI 去分析，用的就是这个能力。

第四个叫做推理模型，或者推理模式。这个是近几年出现的一个特殊分类，代表有 o1、o3，还有 DeepSeek R1。普通模型直接给答案，推理模型会先去打草稿、反复推敲，就会更擅长数学和复杂的逻辑。

所以你看，同样是 LLM，能力差异还是很大的。但是这一层是一个地基，后面所有的东西都得建立在这一层上面。

第二层，你怎么去跟这个模型沟通、说话。有了员工以后，接下来的问题就是你用什么方式去跟它沟通。相信大家其实已经用过两种了。

一个是 GUI，就是像网页、App，你用鼠标点点点，用手指点点点。比如 GPT 的网页版、Claude.ai，都是界面。

第二个叫做 CLI，就是命令行，就是那个黑色的框，然后你需要去打字、发命令。不同的员工可以有不同的沟通方式来跟你沟通。

所以这也能解释很多人的一个困惑，就是 Claude 和 Claude Code 是什么关系？本质上都是同一个大脑、同一个 Claude 模型，入口不同。上面的 Claude 可能是一个网页版，Claude Code 可能就是一个终端的命令行。

OK，沟通方式决定了你能用它来做什么，但到底说得清不清楚同样也很重要。那怎么去保证说清楚呢？这个要提的词就是 Prompt 和 Prompt Engineering。前面的 Prompt 就是提示词，就是你说的那句话本身。Prompt Engineering 就是提示词工程，它研究的是怎么说话才能让员工去干好活。所以听起来很玄，但本质上是好好说话的技术。

第三层，就是工具和手册。你看，光会沟通还不够，员工得有趁手的工具，还得有操作手册，否则每次都要重新摸索。

我们先说 RAG。RAG 就是检索增强生成。我们知道，大语言模型的知识在训练的时候已经固定好了，它肯定不知道最新的信息，因为最新信息没有喂给模型训练。RAG 就是让模型在回答之前先去档案室查资料，查完以后再给你答案。所以你看，你用 AI 问公司的内部文档、查最新新闻，背后都是 RAG。

第二个概念叫做 MCP。MCP 全称就是 Model Context Protocol，是工具接入的统一标准。以前每接一个外部工具都要单独去对接，MCP 相当于统一了一个插头规格，就像 USB-C 统一的数据线。所以你只需要符合 MCP 协议，员工就能直接去用任何的工具。

接下来就是 Skills。Skills 可以定义为技能，也可以定义为操作手册。特定任务的最佳做法，你把它提前写好，AI 直接调用，这样不用每次重新摸索。比如写短视频脚本，这本手册的格式、风格、注意事项，你都可以写在里面。关于 Skills 有很多技巧，像渐进式披露等等，我之前的视频也有给大家讲过，大家可以往前去翻一翻。

第四个概念就是 Harness。Harness 可以理解为管理这些手册的系统。Skills 是一本本的手册，Harness 就是书架加管理员，决定什么时候该调用哪一本。本质上是一个 Agent 的运行框架。Harness 直译过来是「缰绳」，它就希望这个 Agent 能够被控制，以及控制得越来越好。

OK，这几件事合在一起，员工才能够从会说话变成能够干活。但是能干活还不够，我们需要的是自主干活，所以就讲到第四层。

第四层，就是自主干活的员工，我们就叫它 Agent，也就是智能体。普通员工得一步步去指挥，但 Agent 不一样。比如你跟一个 Agent 说：「帮我做一份竞品分析。」它自己会去搜资料、整理数据、写出稿，全程不用你盯着，发现问题自己修正，完了以后再交给你。

像 Claude Code，Anthropic 出的这个编程 Agent，它跑在终端里，能够去读写代码、执行命令、自主调试。像 Codex CLI，就是 OpenAI 在 2025 年推出的编程 Agent，逻辑也是一样。

像 OpenClaw，对吧，中文名叫「小龙虾」。它应该是今年最火的一个开源 Agent，短短几个月几乎涨到了 25 万的 GitHub Star。普通人能用 OpenClaw，或者说小龙虾，做什么呢？你可以自动清理收件箱、整理日历、规划三餐等等。而且你还可以用微信发条消息，它在后台把事情给你办好。你睡觉，它干活。

再往下要提的还有一个最近比较火的，叫做【疑似：Hermes】。【疑似：Hermes】也是一个开源 Agent，但它最大的特点是有学习循环。它从每次使用中积累经验，自动生成新技能，用得越久就越聪明。

OK，关于 Agent，你可以记住下面这个公式：Agent 等于 LLM 加工具，再加上自主循环，这三个关键模块。所以它不是一个新的模型，它是一种组合方式。

接下来讲第五层。第五层，我给它定义的是办公室，Office。你看，我们员工最终都得在一个地方办公。大模型的办公室，比如说编程的办公室，就是 IDE。像 VS Code 是 IDE，Cursor 也是 IDE。目前很多 IDE 都会加上 AI 的功能，也就是有很多 AI 大模型在 IDE 这个地方办公。你可以在 IDE 里面用自然语言去指挥 AI 改代码，不用去切换工具，也可以去换很多模型，像 Claude、GPT、DeepSeek、Kimi，你都可以去换。

所以整体下来，IDE 是个办公室，Claude 或者其他模型是员工，它们是两个维度的东西，不在同一层。另外还有很多其他的办公室，包括我们国内提出来的，像阿里的【疑似：QoderWork】、腾讯的【疑似：CodeBuddy】、MiniMax Agent。这些都是一个办公室，里面可以有很多大语言模型的员工。

OK，之后还有一个概念叫做 Vibe Coding。Vibe Coding 是这一切组合之后催生的一种新的工作方式。你不用去写代码，只要用自然语言跟它说你要什么，AI 全程去生成、修改、调试。人负责提需求和审核，AI 负责执行。所以它就不是一个单纯的工具了，它是一种做事的新方式。

所以你看，AI 工具会越来越多，新名词也会越来越多，包括刚刚已经提到了很多各个大厂提出的东西。但是你只要理解这五层：大脑、沟通方式、工具、自主决策，然后环境或者办公室，你就能够有自己的 AI 概念坐标系。

每次看到新的概念以后，你可以先去想一想，这个概念到底属于哪一层？是属于大模型层的，还是属于沟通方式的？然后你就会知道它大概服务于哪一批人群，以及它的创业机会是什么。这样你就会很直观地去了解目前新的一些概念。
