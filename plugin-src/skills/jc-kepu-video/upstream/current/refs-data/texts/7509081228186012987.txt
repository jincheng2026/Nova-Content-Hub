Hello，大家好。今天给大家讲三个看起来很靠谱的事实。

第一，地球到月亮的距离是五千四百万公里。

第二，我曾经去参加过全国健美健身大赛。

第三，中国的夸父一号首次拍到了太阳的极紫外线照片。

除了我之前参加过健身大赛以外，其他都听起来很像那么回事，对吧？但其实它们全都是幻觉。不是我骗你的，而是大模型来骗我的。

第一条，五千四百万公里，它是地球到火星的距离，不是地球到月亮的距离。第二条，去参加过健美健身大赛的不是我，而是我的一个一起健身的朋友。第三条，夸父一号确实是拍过太阳的，但首张极紫外线的图像早在 SOHO 探测器时代就已经有了。

所以这就是今天我想给大家聊的主题，叫作大模型的幻觉。它们听起来都很像是大模型告诉你的真的事情，但其实这些都是大模型编的。

OK，接下来我会从什么是幻觉、为什么会有幻觉、怎么去避免幻觉这三个维度，给大家盘明白大模型的幻觉。

幻觉呢，指的是大模型的内容看起来很流畅、逻辑很通顺，但仔细深究，发现事实错误、无中生有，甚至前后矛盾。常见的幻觉有几种。

第一种是语言的自相矛盾。比如「北京今天阳光明媚」，然后后面接着一句「北京今天下雪了」，连续两句话就在自我打脸。

第二个呢，就是与提示词矛盾。比如你让模型写一篇夸赞 Mate 70 的产品测评，它直接给你回「系统卡顿，非常不好用」，这就和我们的目标有点相违背了。

第三，事实错误。比如之前讨论得沸沸扬扬的「9.11 是大于 9.9 的」。

第四，它会做一些无意义的延伸。比如「上海是中国的经济中心之一」，然后它顺便一提「《上海堡垒》是中国最好的科幻片」。到底谁说它经典了？

接下来讲，大模型为什么会瞎编呢？这其实跟它的训练方式是息息相关的。我们可以从三个角度来理解。

第一个是数据质量。模型它是读了海量的文本去长大的，比如维基百科、国内的百度百科，甚至豆瓣的热评。但这些数据其实质量是参差不齐的，有些帖子可能是网友去瞎编的，也有一些呢是直接复制粘贴过来的。而且更关键的是，模型的学习方式，它不是去理解这个句子想表达什么意思，而是去理解这个词它后面跟着的词，最大概率是哪一个。

第二个引发大模型幻觉的原因呢，就是它的生成机制。你知道吗？模型的每一次回复啊，就好像在投骰子。我们以概率学的角度去简单解释一下，在给定前缀的序列 Token X1 到 Xn 的情况下，模型的目标是去最大化下一个词的概率 P(Xn+1)。实践过程中会采取以下几种策略。

第一种叫作贪婪搜索，只去取概率最高的那个词。它会保证一个稳定的输出，但是会有一些重复输出的情况。

第二种呢，就是 Top-K。它只从前 K 个词里面去随机地选取，能够去提升多样性，但同时也会引入幻觉。

第三个呢，它有温度系数。这个参数主要是去控制随机性的，温度高呢，输出更是天马行空。具体解释呢，就是 P(X) 正比于 e 的 z(x)/T 次方，其中 z(x) 是 logit。如果 T 更大呢，它的分布也就更发散了。所以当你调用 API 的时候，你发现模型越来越神志不清了，你可以检查一下是不是温度调太高了。

下一个引发大模型幻觉的原因呢，就是输入的上下文。你给模型什么样的提示词，它就会给你什么样的答案。所以如果你的 Prompt 本身就写得不明确的话，它也可能会给你脑补出一些幻觉的信息。

举个例子，比如说你让它直接去介绍清华大学，模型可能后面会加一句：「清华大学是在民国时期被美国资助的大学。」但其实这个是被混淆了很多次的历史误读。清华的前期啊，确实是有留美预备学校的身份，并不是美国资助的、完整建立的大学。

那说了这么多，大模型是什么以及大模型为什么会发生幻觉，那我们针对于这个幻觉应该怎么去做呢？怎么去避免幻觉呢？下面我就给大家介绍几个方法。

第一个呢，就是你要把你的提示词变得精准。比如不要用「请介绍 ChatGPT」这样很泛的概念，而是可以写得更详细。比如：「请用三百字以内介绍 ChatGPT 的技术原理和应用场景，并给一个 AI 客服的例子。」写得越具体越好，避免模型去做一些脑补。

第二呢，就是去用一些 Few-shot 或者 Multi-shot Learning 的方法。这是什么意思呢？这是指你给大模型提要求的时候，可以去写几个具体的案例。比如说你希望大模型去写一个简洁风格的用户手册，那可以在提示词里面给它两个参考样本，让它去模仿参考样本的写作手法和语气。

第三个呢，就是之前提到的，我们要设置合理的温度和 Top-K。这个其实是在调用 API 的时候会涉及到的。在这里呢，我推荐温度是设在 0.2 到 0.5，Top-K 呢设置在 30 以内，会比较安全。

第四步，你可以引入检索增强，也就是之前大家一直听到的 RAG。它的全称叫作 Retrieval-Augmented Generation，指的是模型在回答前先去查文档，在数据库做一些索引，然后再结合查到的信息去给我们做一些答复。

第五个方法呢，就是可以通过一些后处理的校验。比如你可以去写一些代码，使用规则、使用正则表达式，对模型输出的结果去做进一步的校验和过滤。这种在企业级应用里面，会常常结合知识图谱去做一些交叉验证。

最后总结一下，大语言模型真正的厉害之处，并不是在于它从来不会犯错，而是在于我们可以去理解它为什么会犯错，以及我们怎么做去规避这个犯错。我们都希望自己的系统像轨道一样精准，而不是偏离了五千四百万公里。

那就请你先记住今天这三点。

第一，幻觉是大语言模型最常见的问题，不可避免，但可以去做管理。

第二，通过 Prompt 调整、温度调节、多轮示例和结构化引导，能够有效地去减少幻觉。

第三，真正可靠的 AI 系统，从来都不是靠聪明，而是靠稳定。
