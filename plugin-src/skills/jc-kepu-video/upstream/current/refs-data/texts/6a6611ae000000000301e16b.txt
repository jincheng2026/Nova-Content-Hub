只学 Skill，学好 Skill。如果你能力有限，精力有限，你还想快速地提高自己的 AI 应用能力，你还想通过学习 AI 快速地去变现，那么你听我的，一定要去学好 Skill。因为 Skill 是现在 AI 应用里面最重要的一个部分了。它在 AI 应用中所处的地位也很重要，它是处在一个承上启下的一个很关键的地方，它上接 prompt 提示词，下接 Agent。如果你一旦学好了 Skill，你的 prompt 一定是没有问题的，写得会非常好。那么你在 Agent 的应用中，你的 loop 和 harness 你也会通过 Skill 去做得非常的漂亮。

所以这期视频给大家解决三个问题。第一，Skill 是什么？第二，Skill 由什么构成的？第三，Skill 是怎么工作的？了解完这三个问题，在下一期视频，我会手把手地带大家去做一个属于你自己的 Skill，也就是蒸馏。

好，第一趴我们先讲 Skill 是什么。这时候我们再请出我们的老伙计，新疆特产店老板，由你来扮演。那清华实习生小张就由 AI 来扮演。清华实习生小张呢，刚刚来你的店里，他对你的店里的工作一窍不通，所以你要给他安排工作。假设你给他安排了一个打扫卫生的工作，你告诉他：「小张，今天你要打扫一下店里的卫生。啊，你需要先扫地，再拖地，然后再去把货架擦干净等等。」你教了小张，小张就会做了。

但是 AI 大模型有一个很大的问题，就是它没有记忆。你今天教会小张了，你第二天还想让小张去打扫卫生，小张已经忘了应该怎么打扫卫生了。所以你为了避免每天都要教一下小张如何打扫卫生，你就做了一个这样的工作手册。这个工作手册里面就详细地记录了小张他应该用什么工具去打扫卫生，啊，应该先用扫把去扫地，再用拖把去拖地，再用抹布去擦货架等等等等等等啊，以及记录了他应该如何正确地打扫卫生。

OK，那么有了这个工作手册之后，第二天你再跟小张说：「小张，你现在应该去打扫下卫生。」小张就会先去看他的工作手册里面有没有记录如何打扫卫生。诶，他发现工作手册里面有，他就会直接去按照工作手册里面的要求去打扫卫生了。那么这个工作手册其实就是 Skill。所以 Skill 的定义就非常清晰了：Skill 就是把一项工作固定下来，交给 AI 按照约定的流程去执行的一个文件。

注意，这个 Skill 最终的落点它是一个文件，那么既然它是一个文件，那么它就一定有固定的格式或者是构成，对吗？那我们来看一下一个 Skill 文件是由什么来构成的呢？一个标准的 Skill 的结构，它一定会有一个 SKILL.md 文件。这个文件实际上就是一个 markdown 文档，.md 就是 markdown 文件的后缀名。这个 SKILL.md 呢，里面一定会包含至少这两大块的内容。第一大块我们叫它 trigger，这个 trigger 至少包含两个内容，第一就是它的 name，就是 Skill 的名字。第二就是 description，就是这个 Skill 的介绍。第三就是这个 Skill 的正文。正文就是你要告诉小张，哎，我要怎么去打扫卫生，我应该使用什么工具去打扫卫生等等这些内容。

那么聪明的小伙伴这个时候就会想到，哎，如果我在这个 SKILL.md 里面写明了，小张你应该怎么样去打扫卫生，需要使用什么样的工具去打扫卫生，那这个 SKILL.md 直接就可以去执行了。难道说一个标准的 Skill 就是一个单独的 SKILL.md 这个文件吗？哎，没错啊，如果是一个很简单的任务的 Skill，那么确实这个 Skill 就只需要这一个文件就可以了。但是如果你需要处理的任务是一个相对复杂的任务，它可能需要很多个判断，它可能需要很多个其他的工具等等，那么一个简单的 SKILL.md 就无法支撑了。你就可以根据你的实际的需要，在你的 Skill 里面去增加文件夹，其他的各种各样的参考文档，还有知识库，还有数据库，还有脚本等等等等等等文件。那么这个时候你创造了一个复杂的 Skill，这个复杂的 Skill 可以处理复杂的工作任务。那么这个时候你的一个 Skill 就是整个这些文件的集合，被称为一个 Skill。

好，接下来我们来看一下一个 Skill 的示例。这是我制作的一个示例 Skill，这个示例文件夹的名字我就叫它示例 Skill 了，你看这里一定会包含这个 SKILL.md 的文档，这个文件是绝对不可以缺少的。然后我根据这个 Skill 的能力和需要，我还新建了四个文件夹，这四个文件夹的名字是我随便写的，你只要自己认识就可以了。比如说第一个文件夹是数据库，为了做这个工作，它可能需要一些数据的支撑，对吧？所以我做了这个数据库文件夹。第二个呢是 examples，就是示例，就是我要求 AI 在处理这个工作的时候，输出的内容和输入的内容是要符合标准的，我给了他一个示例。我还给了他一个 reference 文件夹。这个 reference 呢，就是我要求他，你在处理这个工作的时候，你可能需要用到的一些数据和资源等等。然后我还给了他一个什么？脚本，有 shell 脚本，还有 python 脚本。那这些所有的这些东西，我一定会在我的 SKILL.md 里面写明在什么情况下用到什么，什么情况下该用什么。AI 就会按照我们之间的约定和要求去执行这项工作，去使用这个 Skill。

好，那我们把这个 Skill 文档打开来看一下它长什么样子。这个 SKILL.md 文档打开来，它就长这个样子。首先这上面的这一大趴就是 trigger 部分。trigger 部分至少包含，并且一定包含 name 和 description 这两个东西。name 就是指这个 Skill 是什么名字。description 就是这个 Skill 的介绍。你要把这个 Skill 有什么功能，它在什么场景下处理什么任务的时候要去用它，一定要写清楚。那这接下来就是这个 Skill 的正文部分。比如说你要告诉小张在什么情况下要用拖把，什么情况下要用扫把，在什么时间应该打扫卫生。打扫卫生应该打扫成什么样子？以什么标准去打扫卫生？这就是在正文里要写的内容。

在整个 Skill 里面，最重要的就是这个 description，这个 description 几乎决定了 Skill 的生死。我们新手在刚刚学习做 Skill 的时候，这个 description 一定要写好。如果这个 description 你写得太宽，那么从 AI 的视角来看，就是做什么任务都有可能去用这个 Skill，那么就意味着你这什么任务都做不好。如果你的 description 写得太窄的话，那大概率 AI 永远都不会用到你这 Skill，你这 Skill 就白写了。第三，由于你在 Agent 里面肯定不止只安装一个 Skill，你可能安装上百个 Skill，所以这个 description 的边界要写得清晰，不能写得模糊。写得模糊就会导致 Agent 在做一项工作的时候，他会发现，诶，好像有三个 Skill 都可以做这个工作，他就不知道该用哪一个了，他就迷糊了。

他为什么会迷糊呢？这就涉及到 Skill 是怎么工作的。Skill 是怎么工作的呢？通过这个流程图你就理解了。首先你发起任务，比如说你告诉小张：「小张，你现在应该去打扫一下卫生了。」小张接到了你这个任务，他就会去想，诶，我现在应该是先扫地，再拖地，再去打扫货架。他把你让他打扫卫生这个大的任务呢，拆成了这三个小的任务。这时候他就会去翻他的工作手册了，也就是这时候 AI Agent 会读取你的所有的 Skill。由于你的 Skill 可能会非常的多，那如果完全读取所有的 Skill 的正文的话，那你的 token 一定会炸掉。所以 AI 这个时候它只会去读你的每一个 Skill 的 description，也就是它的介绍。小张把他的工作手册全部看了一遍之后，他挑出来三个 Skill，一个是如何使用扫把的，一个是如何使用拖把，一个是如何打扫货架的。他挑出来三个他认为最适配这个任务的三个 Skill，接下来就是小张使用这个 Skill 去处理你给他的工作任务，直到任务完成，给你一个输出结果。这就是 Skill 的整个工作流程。

好，我们来复习一下，这个视频主要跟大家讲了 Skill 是什么。Skill 首先它是一个文件，它是把一项工作固定下来的，交给 AI 按照约定的流程去执行的一个文件。那 Skill 由什么构成呢？Skill 至少由一个 SKILL.md 这样一个 markdown 文档来构成。那这个文档至少要包含 name、description 和正文。我们还可以根据这个 Skill 具体的需要，去灵活地增加文件夹、文档、知识库、脚本等等等等文件。第三，Skill 是怎么工作的呢？首先由你发起任务，AI Agent 会对你的任务进行拆解，然后读取你的电脑上安装的所有的 Skill 的 description，从中挑选出最适合处理这批任务的 Skill，然后使用这些任务去处理工作任务，直到任务完成，给你一个满意的输出结果。

好，这期你对 Skill 已经有了一个基本的了解，下期视频我将教你制作属于你自己的 Skill，我们通常呢，把制作 Skill 的这个过程叫做蒸馏。比如说有一个作者写了一本教你如何理财的书，那这书里面可能教你如何投资、如何储蓄、如何买保险等等等等。那他这里面教的每一项，我们都可以怎么样？都可以把把它固定下来，可以让 AI 去执行的一个 Skill，这就是蒸馏。除了蒸馏书，还可以蒸馏人。如果你自己有一个技能，这个技能呢，就是用来处理你工作中某一个固定的任务的。那么你当然可以把自己的这个技能给它固定下来，成为一个 Skill，让 AI 按照你的这个 Skill 去帮你完成这项工作。这就是蒸馏你自己的一个技能成为 Skill。好，那下期视频我们一起搞清楚蒸馏这件事。
