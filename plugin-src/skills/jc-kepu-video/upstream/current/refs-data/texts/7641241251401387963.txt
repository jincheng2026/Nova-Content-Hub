今天我要讲一个主题，叫做开源。其实整个互联网的基础设施，有超过一半都是建立在开源软件上的。你现在用来学 AI 的 Python 语言也是开源的，运行 AI 模型的 PyTorch 框架也是开源的。

开源的英文叫 Open Source，它其实就是开放我们的源代码。一个软件到底是不是开源，取决于两件事情。第一个，它的源代码是不是可以被公开、可读；第二个，它的 License，也就是许可证，是不是允许他人使用、修改、分发。两者缺一不可。

光是代码公开还不够。有些代码你虽然能看，但是不能用，那个叫做「可见源码」，不叫开源。真正的开源必须得附上一套许可证，明确告诉你，你可以用这段代码做什么、不能做什么。

OK，与开源相对的就是闭源，Closed Source，也叫专有软件。代码其实就是公司的商业机密，你只能使用编译好的程序，无法看到内部逻辑。Windows、macOS、Adobe 全家桶，都是闭源软件。

讲完代码公开可见以后，我们再去讲开源许可证，也就是 License。这个许可证决定的是你能够做什么。代码开源不等于没有规则，规则就是写在这一套许可证里面的。不同的许可证，给用户的自由度差别很大。

开源许可证大致分成两大类。第一类就是比较宽松的，像 MIT、Apache。你拿这些代码想干什么就干什么，用在商业产品里面，改了不公开，甚至拿去卖，都没问题。VS Code 用的就是 MIT 许可证。

另一类叫做传染型，叫做 Copyleft，代表就是 GPL。它有个条件，就是如果你用了 GPL 的代码，修改后的版本也必须开源，开源的设置要一路传染下去。Linux 内核用的就是 GPL。

这就是为什么很多公司宁愿选 MIT 许可证的项目，也不愿意选 GPL。前者不影响闭源商业产品的开发，后者可能会导致整个产品代码都必须开源。

这个时候很多人就会困惑，为什么会有这么多人愿意免费贡献代码呢？其实他们的动机，我自己感觉是多元的，不单单只是无私奉献。有些可能是从战略上驱动的。比如 Android、TensorFlow，Meta 的 React 和 PyTorch，微软的 VS Code，这些公司其实也不是在做慈善。开源让更多人使用这个技术，就等于建立了生态的护城河，最终反过来有利于公司的商业利益。

第二个，就是个人的声誉和自己的职业发展。对开发者而言，一个活跃的 GitHub 主页、几个有影响力的开源项目，真的比任何简历都有说服力。很多顶尖工程师的第一份好工作，就来自于他们在开源社区的贡献被人看到。

还有一个原因，是为了解决自己的问题，顺便公开。很多开源项目的起点就是：「我需要一个工具，但没有现成的，我自己写了一个，那不如公开让别人去用一下。」Linux 就是这么诞生的。

第三个，就是集体智慧。一个人维护代码，真的不如一千个人去审查代码来得可靠。所以开源项目暴露在全球开发者的目光里面，漏洞被发现的速度、被修复的速度，往往也会超过闭源软件。

OK，讲完开源以后，它的运作方式是怎么样的呢？它整个运转循环的核心机制叫做 Issue、Fork、PR。也就是用户发现 Bug，然后在 Issue 区提报告；贡献者 Fork 仓库，修复后提交 PR；维护者审查代码，发现没问题以后，新版本发布，所有用户受益，包括最初发现问题的那个人。

而且每一个改进都是公共的财产，永久留在项目历史里面。后来者可以无限次地站在这些改进的肩膀上继续建设。

所以，对于今天要学 AI 编程来说，我觉得开源还有几个具体的意义。

第一个，就是你用的工具几乎都来自开源。像 Python 的包管理，有很多开源包，AI 相关的也有几万个。你在写代码时 Import 的每一个库，背后往往都是某个开源项目数年的积累。理解这一点以后，你就会知道为什么不要重新发明轮子，因为大概率你需要的东西已经有人开源了。

第二个，就是 AI 模型本身也在开源化。除了闭源的 GPT，像 Llama、Qwen，很多都开源了。这意味着你可以自己下载模型的权重，在自己的服务器上运行，数据完全不出境，成本也比调用 API 要低得多。AI 工具链的开源生态也在以惊人的速度成长。

第三个，就是参与开源是学习编程最重要、最快的路径。与其自己憋在家里练习，不如找一个真实的开源项目，修个小 Bug，提一个 PR。当你的代码被合进去的那一刻，你的贡献就永久写进了项目历史，全世界的用户都会间接用到它。这种正反馈，是所有教程都给不到你的。

OK，所以开源是软件世界里面一种关于共享和协作的制度设计。它让知识不被垄断，让改进可以累积，让个人的努力也能成为公共资产。互联网之所以长成今天这个样子，很大程度也是因为它的地基，包括 Linux、TCP/IP 协议栈，以及各种语言和框架，都是开源的。任何人都可以在上面建造，而不需要向任何人付租金。

在 AI 编程时代，你也不需要成为开源贡献者，但是你至少应该知道，你每天调用的那些库和工具背后，真的就是数以万计的人几十年的无偿劳动堆积起来的。用好它，就是我们自己最起码的尊重。
