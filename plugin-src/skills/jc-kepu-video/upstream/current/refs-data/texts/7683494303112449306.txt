hello 大家好，今天想跟大家去聊一下，就是在我们现在通用 Agent 发展得越来越好，那这一类我们看到的垂直类的 Agent，它会不会在这个迭代过程中直接被通用 Agent 给吃掉，我们今天就来详细讲一讲这个东西。现在的通用 Agent 越来越厉害，已经非常能干了，还可以查资料、写代码、写表格，还可以直接操作一些专业软件去给你干活，那问题就来了，就是我们现在市面上还有一些专门去做某个行业的 AI，比如说专门看健康，然后专门解视频，还有专门做法律，这种专门的 Agent，它会不会被这种通用 Agent 给吃掉呢？

那我先给大家一个结论，就是会有一部分被吃掉，那些做得不到位的、拿不出真本事的肯定是会被吃掉了，但是还会有一部分不但吃不掉，反而通用 AI 越强它活得更好。那到底得做成什么样才能不被吃掉呢？所以今天的话，我会用两个案例来给大家讲透这个事情。在讲案例之前，我先需要大家去了解一下，就是垂直领域 Agent 这条路到底该怎么走，就是以前的人是怎么走的、现在该怎么走。

我们可能有些人会有一个概念，就是我们去做这个垂直领域的 Agent，那 Agent 底层的模型需要我们自己去训吗？需要去做一个行业专门的大模型吗？那这个的答案其实是不用的，现在基本上大家用的都是通用大模型，但其实在早几年并不是这样的，很多人想的可能是另一条路，就是每个行业都有自己的专业知识，那干脆我们直接给每一个行业都训一个自己的大模型，那二零二三年那个专门为金融数据去训出来的 BloombergGPT，它其实就是这条路的代表，还包括法律圈的 Harvey，它一开始也是想要去做一个最懂法律的大脑，那这条路很快就走不通了，为什么呢？因为自己炼一个大脑很烧钱，而且它要的数据、要的人力成本是高得吓人的，而你辛辛苦苦训出来，可能通用模型它一次升级，就把你这些东西全部都追平了，这也是 Harvey 后来公开去讲的，就是通用模型的法律水平已经足够高了，我没必要再去费劲自己训，直接用最强的模型来用，不仅省事，而且效果还更好。

所以你记住一句话，就是垂直领域要做的从来不是去取代通用的模型，而是把这些烧钱、炼大脑的事情全部交给大公司去解决，我们要做的是用他们迭代出来的最强大脑，真正要下功夫的其实是套在大脑外面的那一层，把它做扎实，这个是别人做不出来的、别人抢不走的。

那下面我就来讲两个案例，第一个例子就是蚂蚁的健康助手阿福，你的身体不舒服的时候你可以问它，它可以帮你去看体检报告、能管理健康档案、还能预约挂号，那它底下用的其实也是通用的大模型，它在外面包了一层医疗的东西。阿福它最关键的本事，其实是它背后有一个真正的医生团队，专门去给它做一件事情叫做评测，花十秒我来讲清楚评测这个词是什么东西。特别简单，就是给 AI 出题、判卷子，考它到底行不行，医疗的题是不能乱出的，就是 OpenAI 二零二五年就办过这件事情，它请了很多医生，然后一起去出题，凑了可能五千多段真实的看病对话，每段都会写好判卷的标准：哪些话是必须说的，哪些危险信号是必须提醒的，信息不够的时候你就应该老实地说我不确定。

那有了这支医疗团队和这套考题，阿福就可以不断地自己考自己，然后照着考出来的问题去修改，让它的回答变得更专业、更完整、更不容易漏掉一些要命的东西。而且要注意的是，它改的并不是那个通用模型的大脑，它改的其实是大脑外面的一层架构，考出来哪不行，它就把外面这套流程和规则去改好，它完全不需要去动模型本身。所以阿福的护城河不是它用的大脑，而是这支医生团队加上这套评测标准，这个通用大脑是谁都能接的，但是这支天天出题、判卷、改进的专业团队，是别的通用 AI 没有的，这就是它们吃不掉阿福的原因。

那第二个案例，我就讲一下这个剪视频的 AI，叫做 ChatCut，你用大白话去告诉它，我要把这个开头的废话给删了，我要加一个转场，我要把配乐的声音再压低一点，它就能真正在这个剪辑软件里面把这些东西给你剪好。那它最值钱的一个东西，其实是一套好用的编辑流程，它下一次可以一键复用，用行话来说，其实这个就是 Skill，我们的技能。那这时候可能有些人会觉得，Skill 也没什么厉害的呀，很多我们在网上看到的 Skill，GitHub 上很多开源的 Skill，一键帮我下载下来丢给通用模型直接就可以用了，为什么这个 ChatCut 的 Skill 会成为它的一个独家壁垒呢？

那其实它这个 Skill 真的和我们平时用的还不太一样，它真正的本事是，ChatCut 它的 Skill 是活的，它是每一天都在不断生长的，因为它每天都在不断地去帮海量的用户剪片子，用户会把 AI 剪不好的地方拖回去再改，系统就会记一下，这种情况我剪错了，明天就会多一条新规矩，这些细的规矩它不是常识，而是被几十万条真实的用户数据一次一次改进过来的，那这个的话其实就是别的 AI 走不到的地方，它是实时在更新的，你今天把这套 Skill 拷走，你拿到的也只是昨天的一版，它靠着每天的真实用户数据，可以不断去加固自己的护城河，让自己的 Skill 越来越好用，所以呢，这就是 ChatCut 自己的一个独家秘籍。

那讲到这里，你就会发现阿福和 ChatCut，它们其实是有一个共同点的，它们都是垂直领域天天在服务真实的用户，所以它们都攒下了大量别人都没有的独家数据，这个其实就是我们要讲的第三样，也就是压在最底下的一个垂直领域的王牌，那就是它们的数据，它们这个数据其实不光是量大，关键是它还带着真实的结局。就比如说阿福手里面有成千上万条，这个人怎么描述他的症状，后来到了医院怎么样确诊了什么病的记录，它知道这个正确的答案，而知道正确答案就意味着这批数据可以真正变成我们前面说的评测考卷，那当年描述的那段再喂给 AI，它就不会漏掉这个人后面其实是危险的信号，改完这批真实的病例，它再去重新考一遍，去看看自己有没有变好，检验这个成绩，它就会让自己的 Skill 外面的架构流程以及它的 Skill 变得越来越精准，而通用 AI 的手里，它并没有这种很精确的细分领域的数据，也没有这种这么完整的看病案例。

所以的话，这个就是垂直领域它数据这一层的护城河，它还能反过来去喂养前面的两样。所以我们再回到开头那个问题，就是会不会被通用 AI 给吃掉，那其实最主要的就是看它有没有把刚才我们讲的外面这层给做扎实，你不懂技术，你可以去记住这三句话，你就可以判断这个垂直 Agent 它有没有未来：第一，就是它怎么样证明它真的做对了，它有没有专业的团队拿真实的案例给它去做评测；那第二，就是它有没有一套天天在实时更新、越用越熟的成套流程，也就是 Skill；那第三，就是它手里面有没有别人拿不到的这种独家数据。

如果三个都答不上来，翻来覆去就是一句，我们用了最强的模型，那通用模型下一次升级可能就直接把它追平了。那如果前面我讲的这三样它都做得很扎实，而且还咬在一起，每天在一起转，那通用 AI 每升级一次，其实都是在帮它变强，因为说到底，用户花钱买的从来不是一个模型的名字，而是一件事情被靠谱地办成了。

所以呢，今天讲这些，大家就可以很简单地去判断，以后哪一个垂直 Agent 可以活下来，哪一个会被很快取代掉，我们就可以有这样的判断力。今天的话我们就分享到这里，关注我，后面会持续给大家分享这类 AI 和 Agent 的知识，然后你们想看什么也可以投稿给我，我来给大家讲，拜拜。
