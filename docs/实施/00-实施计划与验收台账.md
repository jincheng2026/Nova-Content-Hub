## 产品边界

- 一期五页：总览、模板、内容、日历、提示词；内容是主对象，封面生图是核心能力。
- 本地目录、Markdown、JSON、图片为业务真源。Electron 与插件共享业务文件操作核心；浏览器状态不能继续充当桌面业务真源。
- 模板是一组有版本的样张；本人照片负责身份，模板负责风格。生成候选、选定封面、计划发布、实际发布分别记录。
- AI 助手全局设置；同一任务一个继续入口。历史请求与输入不原地变更，跨助手继续保持来源关联。
- 正常使用尽量不要求复制链接、解压参考包、手工修改 JSON；真实宿主能力不足须明确提示并验证降级流程。
- 一期无需产品账号和鉴权；AI 宿主订阅/额度由用户已有助手提供。默认免费体验构建，不提供运行时鉴权开关。
- 首发按单人、本地磁盘设计；自动发布、社媒采集、多人协作、云同步、剪辑器、完整知识库管理暂不扩入一期。
- 用户于本轮明确首发 Windows 与 Mac 均正式支持，WorkBuddy 与 Codex 均首发必备。开发可逐条打通，但最终不能缩减成单系统/单宿主验收；四种组合都需证明可用。

4. 图片先完整提交，再登记可用结果；跨文件操作有恢复判据，不能仅依赖单文件 rename。
5. 重试/追加有明确语义；重复回执不重复登记，错误尺寸/错误内容不能验收成功。
6. 删除默认可恢复；被任务或已发布记录引用的版本不能无提示物理清除。
7. 修改当前标题/模板/照片/选定封面不篡改历史请求与已发布快照。
8. 外部文件变化重新核对；未登记图片不直接当作生成成功，未知/损坏状态明确显示。
9. renderer 不获得通用文件、shell、IPC 或凭据能力；main 与 CLI 都验证写入边界。
10. 第三方资料中的规则仅作参考，不执行其脚本或将其身份与私有资料放入内置示例。
