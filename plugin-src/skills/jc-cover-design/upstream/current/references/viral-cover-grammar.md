# 爆款封面共用视觉语法

这份文件只保留跨风格共用原则。具体材质、标题、配色和构图由对应风格文件决定。

## 一、三秒阅读顺序

缩小到手机信息流尺寸后，观众应依次读懂：

1. 最大承诺或核心冲突
2. 独特主视觉
3. 人物或真实证据

三层不能平均分配重量。每张封面只能有一个绝对主角。

## 二、完整案例优先，视觉命题负责改写

先从 `examples.md` 和 `assets/examples/` 选择一个已经成立的完整空间骨架，再决定「把它改写成什么画面」。不能只凭视觉命题自由设计。

视觉命题必须是：

- 一个正在发生的事件
- 一个明确的物件关系
- 一个数据异常
- 一个可以照着做的方法载体
- 两个对象的冲突

不得用「科技感、高级感、效率感、注意力管理」代替视觉命题。

视觉命题只负责替换案例里的主体、动作和结果；人物任务、标题几何、主视觉体量和遮挡层次应从案例继承。至少保留 3 个缩略图中可见的结构关系。

## 三、证据完整性

证据优先级：

1. 用户提供的真实产品、UI、设备和结果
2. 用户提供或已核实的数据、论文和资料
3. 能解释抽象机制的具象事件或编辑图形
4. 服务阅读方向的装饰

没有真实产品时，不生成似真产品后台。  
没有真实数据时，不虚构坐标和结论。  
抽象观点使用隐喻不等于伪造证据，必须让观众看出它是表达性画面。

## 四、材质合同

每张封面只选择一个主要视觉载体：

- 电影事件
- 数据编辑海报
- 真实设备／产品
- 纯色扁平插画
- 资料拼贴
- 纸媒教程
- 漫画对战

真实人物可以作为唯一摄影元素进入插画或纸媒世界，但必须用统一描边、阴影或纸张边缘完成融合。除非风格文件明确允许，不混用纸媒、玻璃 UI、柔光 3D、霓虹和漫画网点。

## 五、标题几何

- 指定文案逐字保留，但视觉重量必须分级。
- 最大关键词占标题组视觉重量的 50% 以上。
- 标题最多 3 级：主锤、补充、角标／引题。
- 同一画面最多 2 种主要字体、3 种文字颜色。
- 标题必须形成字块、纸条、印章、倾斜板、满宽数字或其他明确造型，不能只是多行等大居中排版。
- 颜色承担语义，具体用法服从风格文件。

## 六、组块与互动

默认识别为：

1. 标题组
2. 内容主视觉组
3. 人物组
4. 可选辅助证据组

这是验收用的认知分组，不要求物理分隔。标题、人物和内容应通过遮挡、方向、托举、推动、观察或冲突形成一个整体事件。

多元素必须共享：

- 同一容器或场景
- 同一材质
- 同一阅读方向
- 同一视觉任务

禁止把多个无关图标排成默认功能栏。

## 七、人物任务

人物只承担一个主要任务：

- 指引
- 托举
- 操作
- 观察／见证
- 裁判
- 角色扮演
- 情绪放大

人物比例按 `face-reference-policy.md` 验收。负面选题不自动让人物痛苦，由事件和标题承担负面张力。

## 八、安静区和边缘

- 保留可呼吸的低对比区域，但不要求是一块空白矩形。
- 安静区可以是暗部、纸面、低对比网格、烟雾、背景资料或负形。
- 人脸与完整关键词保持安全；装饰、纸边、背景事件和非关键信息可按风格出框。
- 不用统一 10% 边距和 20% 留白抹平所有视觉家族。

## 九、多风格探索

同一内容生成多个方向时：

- 每张选择独立完整案例，并建立独立视觉命题。
- 至少改变主视觉、材质、标题几何、人物任务中的两项。
- 推荐风格和实验风格使用同一质量门槛。
- 不允许同一仪表盘换色、换人物位置后作为新风格交付。

## 十、缩略图检查

- 最大关键词可辨认。
- 独特主视觉轮廓清楚。
- 高对比中心不超过 3 个。
- 人脸和手势可辨认。
- 不依赖正文小字才能理解选题。
- 中文逐字准确。
