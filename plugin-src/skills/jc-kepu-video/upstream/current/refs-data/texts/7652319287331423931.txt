2026 年，用 AI 的人已经分成了两批。第一批人每次打开对话框，第一句话还在解释：「我是做什么的，我的风格是这样，这次要干什么。」另一批人打开就能直接干活了，AI 已经知道他是谁，按他的方式去工作。

我觉得差距不在模型，也不在提示词，而在 Skill。所以今天我就用一条视频说清楚：Skill 是什么，去哪找，怎么装，装哪些。

用 AI 其实可以分成三个阶段。第一个阶段，就是把 AI 当成一个搜索引擎。问一个问题，得到答案，然后关掉。这个不是在用 AI，而是在查字典。

第二阶段，开始去研究提示词，花时间去打磨指令，输出质量确实上来了。但是还有一个问题没解决，每次对话还是从零开始。你花十分钟调教好的 AI，关掉对话框就全忘了。

所以这两个阶段本质上都是一样的，都在优化单个对话。所以我们要讲的是第三阶段：去构建 AI 的工作系统。不再优化每次对话，而是让 AI 永久记住你的工作方式。你的偏好、标准、流程全部都封装进去，打开就能用，不用再重新解释。

到了这个阶段，你不再是 AI 的用户，你就是 AI 的雇主，而 Skill 就是进入第三阶段的工具。

Skill 到底是什么呢？其实它就是一个 Markdown 文件，里面全是用自然语言写的指令，不是代码。就好像一本 AI 的工作手册。你把工作方式写进去，装进 Claude，它就按照这本手册来。

举个我自己的例子。我每天都要出短视频封面，之前每次都要找素材、选字体、调配色。现在我封装成了一个 Skill，输入标题和文稿，两分钟自动出封面。流程一次教完之后，每次调用就可以了。

OK，那怎么找到合适的 Skill？给你三个网站。

第一个，skills.pub，精品路线，三百多个经过筛选的 Skill，不知道从哪开始的就来这个网站。

第二个，skills.sh，看数据，24 小时安装量、历史总量、1 小时趋势。想知道大家都在用什么，看这个网站。

第三个，skillsmp.com，里面有 16 万个全收录。想找特定场景的，来这个网站。

还有个方法，就是去装一个叫做 Find Skills 的 Skill。你说你想做什么，它帮你在整个数据库里面去找，还能判断哪个更适合你。

那怎么装呢？很简单。第一个，把链接直接丢给 AI。你可以打开 GitHub 上的 Skill 页面，复制链接，告诉 Claude：「帮我安装这个。」全自动。

第二个，就是用 NPX 命令。GitHub 上大部分 Skill 有一行现成的 NPX 命令，复制粘贴到 Claude Code 对话框，按回车。如果你不懂 NPX 是什么，直接问 AI，让它帮你装。

第三个，手动把它放到文件夹里面。这个是最通用的。每个 AI Agent 都有一个固定目录，Claude Code 的目录我放在下方，包括 Cursor、Trae 的目录我也放在这里。Mac 可以直接按 Command + Shift + G，直接跳转，把 Skill 文件拖进去，主流的 Agent 全都能用。

装好之后，在对话框里打一个 `/skills` 这样的斜杠命令，所有的 Skill 都能调出来了。

OK，讲完了从哪找、怎么装以后，最后再讲一讲到底可以装哪些。我觉得一共有七个，可以分三层。

第一层，不管你做什么都能用得到的，先装这两个。

第一个叫做 Office Hours，gstack 套件里面的。做任何事情，先被 AI 追问六个问题，把目标、边界、成功标准全部逼出来。我现在启动新的任务，第一件事就跑它。用了它做很多东西，返工率特别低。

第二个就是 agent-reach。YouTube、小红书、推特、公众号，一句话跨平台搜素材，还能直接拉视频字幕，不花 API 费用。找素材这件事基本不用手动了。

第二层，按你的主要场景去选一个。如果你是做产品、写代码的，我建议 Superpowers。GitHub 上将近 20 万个 Star，官方收录的。它也不是一个 Skill，是 14 个 Skill 的套件，给 AI 编程装一套工作规范。你可以把它想成一个严格的监工，动手之前先把方案写出来，确认没问题才能开始写代码，再也不会乱来了。Claude、Codex 等主流 Coding Agent 都能用。

如果你要做 PPT，我推荐你安装 frontend-slides。【姓名未识别】做的，小红书发布帖有 2.4 万个赞。核心逻辑就是先看后选，先生成三个风格预览，你确认了再跑完整内容。12 套精选风格，七八分钟出一份 PPT。已经上线了【疑似：Any Agent】平台，网页端直接用，不用装 Coding Agent。

如果你是做内容，你可以装 humanizer-zh。原版是国外的英文 Skill，有人做了中文汉化版本。AI 写的东西通顺归通顺，读起来就是不像人话。这个 Skill 专门处理这个问题，过一遍，自然度明显就不一样。

第三层，用顺手了再装这两个。

一个叫做 Skill Creator，Claude 官方出品，是写 Skill 的 Skill。工作里面重复三次的事情，用一句话描述出来，它帮你封装成反复调用的 Skill。不用写代码，它问你问题，你回答就可以。这个长期价值最高。

第二个，【疑似：Agent Browser】，让 AI 直接管你的 Chrome，打开网页、点按钮、填表单、截图、发数据，跟你自己坐在电脑前面操作没有任何区别。每天要重复的流程丢给它去做，你去做别的事情。

OK，所以说实话，Skill 也不是装得越多越好。装多了，模型在一堆工具里面选，反而开始飘。这七个已经很够用了，按照顺序来，先把前两个用熟。

还有一点很多人没想到，就是第一次用 Skill 跑出来的结果，可能没有你预期的好。走错一步、跳过某个环节，或者某个细节有偏差，你会觉得自己装错了。其实不是。

你可以把装了 Skill 的 AI 想象成一个刚入职的聪明员工，脑子好、学习能力强。你给它一个目标，它能自己想办法，但执行层面上会犯各种奇怪的小错误。如果你用自动化系统的标准去看它，会觉得它根本不可靠；但如果你把它当成员工来管，逻辑就不一样了，你会去带它，而不是换掉它。

所以 Skill 也是用着变好的，不是装完了就完了。
