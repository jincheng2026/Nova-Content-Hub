# Prior-Art Research

## Current Review

- Reviewed at: 2026-08-13
- Method: read-only source inspection; no external package was executed or copied wholesale

## Keep

- intent clarification before authoring
- progressive disclosure and resource boundaries
- trigger, output, runtime, and human evaluation as separate evidence surfaces
- Skill IR, package validation, governance, and evidence-bound public claims
- explicit release gates and post-release iteration

## Adapt

- Convert useful prompt principles into explicit actions, conditions, decision criteria, autonomy boundaries, failure handling, and acceptance checks.
- Convert broad lifecycle ideas into a lighter architecture decision that creates only resources with a real job.
- Preserve cross-host portability through one local truth and host symlinks.
- Keep evaluation proportional to risk.

## Reject

- wholesale copying or close paraphrase
- dashboards, telemetry, registries, and complex review machinery without demonstrated need
- self-scores or internal examples as proof that this package is superior
- a second discoverable root `SKILL.md` inside fixtures or examples
- treating file count or directory depth as quality

## Invent

- a qualification gate that can decide not to create a Skill
- compact resource placement for root, references, scripts, evals, and reports
- hard constraints, recommended defaults, and permitted judgment
- autonomy / ask / stop boundaries and a failure-recovery matrix
- architecture and prompt-design checks in the main workflow, interface, manifest, tests, and handoff

## Evidence Boundary

This package contains explicit architecture and prompt-design methods and deterministic checks that those methods are present. No real task-level before/after comparison was run. Claims of superior generated results remain `missing evidence`.
