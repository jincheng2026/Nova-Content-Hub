# 免费体验与创作流程重构

2026-10-18。本批按用户新范围推进：一期给用户免费体验，不接账号登录、设备权益或收费鉴权；后续 Pro 再讨论。上一批未接线的三份新增授权内核文件已移出，不引入无消费者的授权框架。历史合同 26 保留但标明延期。根构建、默认启动与安装说明按 28 切到明确的免费体验模式，旧 required 仅供内部受限兼容。

## 真实参考与重新归纳

本轮通过本机 UI 自动化只读查看已安装的「旅游营销工作台」与「内容工作台」：总览、内容列表、活动详情及 VI 模板组。没有修改参考业务文件、发起生成、复制私人素材或改变系统安全设置。用户已明确授权把两款实际交互作为参考。

观察到的有效设计：先看到内容和真实成果，再进入具体工作；详情以封面、正文、资料、发布安排组织；下一条发布与待处理事项直接指向内容；模板呈现整组样张；本人照片和默认值放在侧栏。先前把建库、导入、维护和全部生成表单铺在业务页顶部，会令用户先处理技术细节，才找到自己的内容。这不是换颜色可以解决的问题。

## 本批源码变更

- 默认打开总览：当前日期、真实数量、本周节奏、下一条发布/最近创作、封面实图、正文复制、原图导出、待选封面/缺封面/过期计划与最近编辑。明确设置为空的发布文字不回退正文。
- 内容列表独立一页：标题与实际封面、封面进度、渠道与日期、搜索、事实筛选、回收站；主要操作进入详情或制作封面，管理操作收进次级菜单。
- 内容详情分封面、正文、资料、发布计划四个页签。保存正文后制作封面；正文编辑只出现在对应页签。生成设置在页签切换时保留，未保存正文仍走原保稿/冲突流程。发布入口聚焦日历中的当前内容。
- 封面页先展示实际候选、已选封面及一个活跃任务的继续入口。制作封面使用独立弹窗，左侧参考预览/内容摘要，右侧选模板组、人物、数量与比例；补充要求和资料按需展开，底部仅一个当前助手生成动作。
- 模板库以多图叠放、样张条和来源筛选呈现整组风格；我的照片、默认模板、默认人物和默认张数放右侧。模板导入、版本、回收站及学习/还原/人工验收继续复用文件流程。
- 提示词添加只需粘贴正文并保存一次；标题留空自动建议，分类说明可选。文件导入预填同一编辑器；去掉连续重复预览与确认。使用提示词仍为左侧完整预览、右侧填写，关联内容须明确勾选。
- 内容库、导入、备份和诊断移入管理弹窗；初始页仅显示建库/打开两个动作。设置保留全局助手选择器，免费体验不出现登录任务。
- 中断恢复集中到全局入口；空库也可恢复照片导入。编辑窗暂时收起并保留草稿时，恢复使用另一个非破坏弹窗，不必先放弃输入。封面页不再重复显示同类全局恢复按钮。
- 实际候选缩略图使用已有受限图片协议与库 epoch，不把绝对路径交给 renderer，不以模板样张冒充已生成成果。新增撤销旧 URL 与不改源文件的回归用例源码。
- 初始窗口调整为 1280×860，最小 960×680；蓝 N 应用/导航图标沿用用户提供的固定资源，页面不添加红色光晕。

## 源码审查与限制

Astra high 的定向源码审查识别了空库照片恢复不可达、托管草稿阻挡恢复入口两项问题，已在本批源码调整；其后模型容量不足，剩余定向源码审查改用 Sol high，不声称执行了完整 Astra 审查。

按照用户「先全部功能开发，再统一测试」要求，本批未运行测试、类型检查、构建、探针、我们的桌面应用或宿主生图，也未更新 Applications 中的旧安装包。参考产品观察不是本产品验收。所有本批改动标为「已写源码，待统一验证」，没有声明渲染效果、安装可用或商用就绪。
