## 本轮发现的缺口

1. **当前稿识别**：42/47条可直接读取当前来源。T020、T048 存在多个明确入口，需要作者选择；T019、T021 的参考逐字稿，T025 的脚本、JSON、日志被纳入当前稿候选，属于来源分类应修正的情况，不能全部归因于原库。
2. **保存与导航稳定性**：独立安装模块 UI 测试从 T029 录制返回内容目录后，连续90秒未结束加载；恢复 T044 候选与最终文案时两次保存 flush 超过25秒，部分操作后文件实际已落盘。真实原生只读导航随后通过，因此应保留两个不同范围的结果，尚未证明原因或修复。不能把“保存通道已连接”当成所有保存请求已完成。
3. **旧今天任务**：原飞书“07｜个人推进看板”的读取、完成、改期没有接入。现有内容日程、助手任务不能代替这个业务。
4. **X 收藏**：当前可绑定目录和打开原 HTML，未接真实数据库、同步、分类及“已选条目→素材任务”的确定性传递。
5. **资料选题**：打开具体资料后“保存并推荐选题”会冻结该资料；总目录“从资料定选题”没有资料选择器，不携带所选正文，不能称为依据全库资料完成推荐。
6. **综合调研**：通用调研走 jc-media-research，尚无可见 jc-synthesis-research 专用方法入口。后者只有 public-snapshot 来源，需同事确认完整性。
7. **原资源与媒体**：14条唯一媒体引用在登记位置均不可用，其中8条还存在“已做”目录的相对路径偏移。再按库根素材目录及导入档案候选位置核对，14条仍均未找到文件；仅修正相对地址不能恢复播放。这是所核对位置的缺件，不代表已证明全机没有原片。逐条结果见 [媒体路径校正](library/media-reference-location-correction.json)。
8. **四项原 Skill 完整包未取得**，清单如下。Nova 的 ASR、封面、创作页适配各有自身能力，不能因此宣称这四个原方法已等价迁移。
