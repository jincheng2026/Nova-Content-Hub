# 自媒体工作台：从第一篇内容开始

一期免费体验，无需注册或登录。本文随当前源码维护；最新源码仍待统一验收，已安装的旧版本可能没有全部入口。

## 第一次打开

1. 点「新建内容库」，选择存放位置并填写一个新名称。以后正文、图片、模板和发布安排都保存在这个文件夹里。
2. 已有内容库就点「打开内容库」，选择原文件夹。应用与内容库分开保存，更换应用时保留内容库。
3. 到左下角「设置」选择 Codex 或 WorkBuddy。所有制作入口都使用这里选中的助手。
4. 如提示需要配套插件，点「准备安装插件」。工作台会复制完整安装位置并打开助手；在助手的插件页添加本地市场、粘贴位置，安装并启用 Nova Content Hub。按助手提示确认权限，再回来重新检查连接。

插件无需另外安装 Node。插件连接正常不代表有生图额度；实际生成使用你已有的助手能力和套餐。

## 做出第一张封面

1. 到「内容」点「新建内容」，填写标题、正文并保存。
2. 点「制作封面」。左边查看风格参考，右边选择一组模板。
3. 想放入自己，就选择已声明为本人的照片；也可以选「这次不放人物」。照片可在模板页右侧导入。
4. 选择生成张数和比例。需要额外要求或参考附件时再展开「高级选项」。
5. 点「去 Codex / WorkBuddy 生成封面」，在助手里确认执行。完成后回工作台查看候选，选一张「选为封面」，或下载原图。

模板是一组风格样张，生成张数另行设置。样张里的人不会自动成为你的人物参考。只有本次明确选择的内容、照片、样张和资料会交给助手；助手可能通过自己的服务处理这些输入。

已有任务时用「去助手继续」，不必重复新建。想重做才选择重新生成；打开助手、接单、生成完成和图片入库是不同步骤。

## 安排发布

在内容详情的「发布计划」里新增渠道和日期，也可在「日历」中统一安排。每个渠道能保存自己的发布文字和封面。

你仍需到平台手动发布，工作台不会替你发送帖子。发布后点击计划上的「记录已发布」，核对真正的时间；填写发布链接后，以后可直接打开查看。

填错时用「更正记录」或「撤销记录」。原记录会留在历史中；撤销本机记录不会删除平台上的帖子。

## 模板与提示词

- 模板页可查看整组样张、导入自己的参考组和管理本人照片；先选一个风格，再明确选择要制作封面的内容，也可点「用此模板新建内容」，保存正文后继续制作封面。
- 提示词页点「添加提示词」，直接粘贴正文并保存即可。标题可留空，分类和说明可选；保存为新条目，不覆盖同名条目。
- 使用提示词时左侧预览、右侧填写，再复制完整提示词。选择关联内容后，还需明确勾选，才会把标题和正文加入复制结果。

## 保存、备份和恢复

正文改完后点「保存内容」。切换内容或退出时，未保存的填写会提醒你处理；尚未提交的草稿只在内存里，不保证断电后恢复。

定期进入「内容库 → 备份与维护」备份。恢复会新建独立文件夹，保留原库和备份；不要直接把备份文件夹当成正在使用的内容库。

打开旧库提示需要升级时，在同一页点「升级旧版内容库」，选择旧库，再选择另一处存放位置。确认后会分别建立完整备份和升级后的独立副本；原库业务文件保留。升级完成后点「打开升级后的库」。当前此入口支持第4版文件库，第1至3版和未来版本会给出明确提示，不会强行打开或修改。

如果出现「有一项操作等待确认」，点「继续处理」，先核验原操作。原填写会保留；不要自行删除锁、事务文件或「系统（别动）」目录，也不必重复点击保存。

## 关闭窗口和退出

菜单栏或任务栏图标可用时，关窗口会收起工作台，提醒仍可运行。需要完全退出，请在工作台常驻图标菜单中点「退出」。若常驻图标不可用，关闭窗口会退出。

开机启动、每天提醒和减少动画均在设置中主动开启。睡眠或退出时无法准时提醒，恢复运行后只检查当天安排。系统通知权限和专注模式可能影响提醒显示。
