为什么你用 Codex 只能搜索到少量的信息,而我可以用它登录真实网页,获取最新的一些内容,而且很稳定?像做大纲、整理资料、做工作台的时候,它干得都蛮好,但是一旦你想让它帮你去搜索一些最新的信息的时候,就会发现一个问题:它很快能给你一份看起来非常完整的答案,但当你真正去打开网页去对照,就发现有些信息已经过时,或者有些动态的内容没看到,还有一些社交平台登录才能查看的数据,它也都拿不到。所以说,问题不是 Codex 不会搜,也不是模型不够聪明,而是还缺少真正进入网页环境、操作浏览器的能力。所以说今天我给大家推荐 ego lite,一款专门为 Agent 设计的浏览器工具。

有什么用呢?其实当 Agent 可以操作真实浏览器,可以解决两个问题。第一个就是帮你去获取最新的一些信息,它可以像人一样去打开搜索结果,一条一条去查看网页的内容,继续去点击、滚动和翻页,然后再把最新的数据整理下来。第二个就是直接帮你去操作网页,比如说它可以直接打开网页,上传一些参考图,输入提示词,等待下载,再把图片一张一张地下载下来。而且它之后不止是 Codex,其他的 Agent,类似像 Claude Code,也可以接入真实的网页,完成搜索和网页的操作。

第一部分我们先看看到底怎么安装。首先我们进入 ego lite 官网下载安装,第一次打开的时候可以去选导入原来浏览器里面的设置,你平时使用的一些网页登录状态或浏览进度都可以使用,后面 Agent 在执行任务的时候就不用再次重新登录。接下来打开,在输入框里面去输入这个,就可以搜索到,直接去调用就 OK 了。

同时我今天给大家准备了一个场景【听不清】:生成我的视频的封面这个流程。比如先在应用窗口输入生成、下载、保存的需求,但现在我在这里面输入网页,就根据视频风格生成一期视频封面,下载下来,去打开图,等待生成、下载,下完之后直接去页面里去操作。里面还可以创建一个独立的网页空间,Agent 可以后台同时开启多个 space 去执行不同的任务,而我自己仍然正常去用浏览器。

第二个例子就是真实的数据获取,比如整理【听不清】的工作,爆款打开一些靠谱平台,刷到几个热门视频之后,凭经验去判断这个选题值不值得做,但这里面有个问题,就是你看到的是【听不清:法你的局结的根没到】。所以现在我会让 Codex 直接帮我去整理爆款的视频,我先输入多个关键词,去搜对应领域的视频,它就会逐条去打开这些视频,整理公开可见的数据【听不清:的量点】,完整的数据信息,然后最后生成一个完整的 CSV 文件。这样我拿到的就不是一个零散的案例,而是这七天这个领域的爆款的完整数据。更重要的是,数据回来之后它可以继续去帮我分析,因为它像 Codex 一样了解我的账号定位,也知道我之前做过哪些内容,所以说它不会只告诉我说这些视频,而是进一步去判断说哪些方向符合我的账号,哪些内容我没有覆盖,【听不清:话先去尝试】优先级排一段,我可以继续【听不清】的视频的选题。

所以说现在啊,Codex 加 ego lite 可以主动帮你去建立一个完整的数据【听不清】,从凭感觉找数据,变成一个基于真实的完整数据去做内容的决策。而当一个流程最终跑通的时候,还可以进一步去沉淀成【听不清】,比如刚刚这个低粉爆款的分析流程,可以把搜索关键词、标注的字段以及后续的分析方式全都保存下来,下一次去研究其他领域,只需要替换关键词和目标用户,整个流程就可以重新去执行一次,去解决今天遇到的所有问题。

最后,很多人可能会说 Playwright 也能操作浏览器,ego lite 有什么优势呢?传统的方案有三个很现实的问题:第一就是 Agent 工作时会弹出新的这种浏览器窗口,打开一堆的,甚至抢走你正在使用的这种窗口的焦点;第二个是多个任务并行,往往要手动切换多个浏览器,很麻烦;而 ego lite 会给 Agent 独立的窗口,不会让邮箱、社交平台经常要重新登录,额外 ego lite 直接继承你里面的登录状态,不同任务放到独立的 space 里去工作、去操作,而且还会继承你自己的登录状态。

所以说,现在 Agent 自己去搜索、操作网页,我最后可以简单总结一下,就是 Codex 拿到任务,去分析信息,进入网页获取信息,完成任务成功之后可以复用当前的流程,不用停在窗口里,真正进入网页。你下一步的内容我也沉淀到【听不清】,其他内容【听不清】,我们下期再见。
