关于 {{这项工作/工作流}}，在我们决定要不要把它完全交给你自动完成之前，先做一次测试：

请你完全独立地、不问我任何问题地跑一遍这个任务，把你能想到的方法都用上，尽力做到你能达到的最好结果。哪怕你觉得某些地方拿不准，也自己做判断，不要停下来等我确认。

完成后，把结果和过程中你觉得不确定的地方一起给我，我要看的是：完全没有我参与时，你能做到多少分，以及哪些环节是必须要有人参与、哪些环节可以放心交给你。
