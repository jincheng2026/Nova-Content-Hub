# 风格 DNA · 拆解自《曲率FDE实战训练营》48 页

## 一、这套 PPT 好看的原因（拆解结论）

1. **整页一张图**：没有 PPT 排版痕迹，标题、正文、图表、插画在同一张画里，风格天然统一。
2. **手绘统一律**：所有信息元素一律手绘化——图表画在白板/拍纸本上，清单画成夹纸板，结论写在木牌/横幅上，箭头是手绘虚线。没有任何「电脑感」元素混入。
3. **三色纪律**：藏青（墨色，承担 90% 文字）+ 琥珀橙/朱红（只给重点：圈、下划线、数字、结论横幅）+ 水彩淡彩（淡蓝/淡绿/淡赭，只做插画填色）。米白纸底提供统一基调。
4. **标题即书法**：大标题用浓墨毛笔字，自带视觉重量，替代了传统 PPT 的「大号加粗」。关键词用橙色手绘椭圆圈住，一眼锁定。
5. **隐喻承载论点**：抽象观点全部翻译成具体场景——竞争格局=灯塔与小店群、团队困境=风浪中的船、企业部门=大楼剖面、流程=工厂流水线、合作=山顶握手。画面替讲者说话。
6. **信息密而不乱**：一页塞得下 5-8 个信息块，靠「标题区 20% + 主体插画 65% + 底部结论横幅 15%」的三段式和留白呼吸维持秩序。
7. **底部收口**：多数页底部有一条手写结论横幅（橙色描边或橙底色块），把整页收成一句话。
8. **全角落细节**：角落有小植物、飞鸟、图钉、咖啡杯、比例网格线等手账元素，避免空洞。
9. **统一水印**：左下角小号品牌水印，48 页一致。

原始规格：1672×941 PNG（16:9），推测 GPT Image / 同级模型直接文生图，中文全部模型渲染。

## 二、风格锁 Style Lock（固定段，逐字复制进每页提示词）

```
手绘钢笔线稿加水彩淡彩风格的中文知识信息图，整页构图。背景是米白色水彩纸，带细腻纸张肌理，边缘有若有若无的淡蓝、淡绿、淡赭水彩晕染。所有元素均为手绘：细钢笔线勾勒轮廓，低饱和水彩上色，风格接近建筑手绘与城市速写。文字主色为藏青墨蓝，强调色为琥珀橙与朱红，插画填色只用淡蓝、淡绿、淡赭。中文大标题用浓墨毛笔书法体，笔画有力、略带飞白；小字标注用工整清秀的手写楷体。流程用手绘虚线箭头连接，图标画在手绘小圆圈里，角落点缀盆栽、咖啡杯、图钉、飞鸟等手账元素。画面信息密集但留白有呼吸感。左下角有小号「锦成」手写水印。
```

（默认品牌水印固定为「锦成」；仅当用户明确指定其他品牌或要求无水印时才替换或删除。**不要在提示词里写「16:9」等比例字样**——会被当成文字画进图里，比例由生图接口的 size 参数控制。）

## 三、文字白名单模板（无参考图时放最前，有参考图时紧跟参考图声明）

```
画面中允许出现的全部文字只有以下 N 处，每处只出现一次，逐字准确的简体中文，除此之外画面任何位置不得出现任何其他文字、字母、数字或符号：
1.「……」 2.「……」 3.「……」 …… N. 左下角水印「锦成」
```

提示词末尾加收尾段（含组图一致性句，学自 guizang-ppt-skill）：

```
这是同一套幻灯片中的一页，与其他页保持同一构图密度、线条粗细与边距节奏。不要照片写实风格，不要3D渲染，不要现代扁平UI风格，不要真实品牌logo，画面最外缘不要整页边框。
```

## 三点二、风格锁附加条款（不进提示词，写方案时遵守）

- 默认不在画面放日期、时间戳、页码、真实品牌 logo；需要 logo 时留空白区后期叠加。
- 二维码必须留白后期叠加（模型画不出可扫码的真码）。
- 整页最外缘永远不要黑边框/描边框（no outer border）。
- 一套 PPT 只用一套风格锁，禁止混入其他任务、其他参考图的视觉基因（风格隔离）。

## 三点五、防幻觉经验（2026-08-23 三轮实测）

1. **白名单必须放提示词第一段**，放结尾时压不住幻觉。
2. 豆包 Seedream 会把风格段里的描述性词句原样画进图（「工整清秀」曾被抄成画面乱码），风格段避免出现可被当作画面文字的示例句；「16:9」等比例字样绝不能写。
3. **留白多的页面（观点页）幻觉率最高**：要写「标题下方不要加任何横向装饰条、图标条或分隔线」「留白处什么都不画」；仍可能残留边缘碎字或橙圈圈错词，这类靠同提示词重跑 2-3 次抽卡选最好的一张。
4. 信息密集的流程页/结构页反而一次成功率高。
5. 质检第一件事：找「不在白名单里的字」；第二件事：核对橙圈是否圈对了关键词。
