就在昨天啊，DeepSeek V4 Pro 正式版终于发布了，就听说是性能直逼 Fable5，我只能说真的厉害。好吧，我们可以这里看到，就是 V4 Pro 的整个能力，跟 Fable5 已经非常接近，而且它的调用成本可能只是常规模型的二十五分之一，我真的只能说【疑似：量流】好。

那如果你日常用到 WorkBuddy 这个工具，然后发现积分根本不够用，我今天就教给你怎么给 WorkBuddy 配置 DeepSeek 正式版模型，你积分不够用的时候也可以按量去付费。简单来说，就是用工作流和工具的调用，但是模型我可以换成其他更便宜的 API。

首先第一个，怎么配 DeepSeek。首先我们要先获取 DeepSeek 的 API，我搜索对应 DeepSeek 的开放平台，进入到它的 API 开放的一个位置，然后这里面去点击 API key，然后创建 API key，然后随便输一个名称，然后就可以快速得到你的对应的 API key。但这里面有一个点需要注意，就是它只有在创建第一次的时候能够复制出来，后面的话你就只能够新建一个 API key 才 ok 呢。获取 API key 之后呢，要么就是跟 WorkBuddy 直接对话去配置，要么就是进入到设置去进行填写，非常简单啊，我们可以看一下，我们进去之后呢，我就只需要把对应的 key 和 URL 发给它，它就能够很快帮我配置好啊。配置完了之后，你就可以在右下角这边去点击对应的 DeepSeek Pro 或者【听不清】的模型。还有一种方式，就是你点击右下角这里面，进入到"配置自定义的模型"，然后这里面你就可以去选对应的提供商，比如深度求索啊，然后写你的 API key，然后保存就 ok 了，非常简单，几分钟就可以搞定。

第二步，就是 DeepSeek 配图像识别的能力。DeepSeek 只是一个文本类的模型，而像 Fable5 是一些多模态能力啊，其实也很简单，你只需要随便找一个，比说似像阿里云的这种多模态模型，我这里是阿里云的 API，复制之后然后发给它，那你只需要按照这段提示，让它去帮你去配置，然后把对应的模型和 API key 都发给它，然后它就能够很快地给你配置好，然后你后续去使用 DeepSeek 的时候，它就会比较好地能够帮你去识别图片。我可以看到这里发给它之后，它就能够快速地去识别这张图片啊。但是有一个问题啊，就是在于说，如果你自己配置好第三方的 API key，那这个时候你会发现在 WorkBuddy 上面，这个模型是不支持图片的，我觉得这还是 WorkBuddy 在第三方 API 配置上面有一些问题，但如果你在 Codex 这种上面去配置的话，就完全没有问题。

ok，所以说到目前为止啊，确实会更推荐用 DeepSeek V4 Pro，因为调用成本非常低的情况下能力也很强，我觉得大家可以放心去使用。
