# 规律提炼

先读适用定位和当前显式范围的素材、已有规律。只处理已入库的真实内容，不采集、不写正文、不生成选题。有效素材以稳定ID识别，已参考/未参考状态移动不算新增。

先逐条做摘录底稿，字段为：素材映射、平台与形式、真实标题、平台文案、封面/首帧文字、口播开头1–3句原文、口播结构。原件称六字段但清单含素材映射；本适配完整保留这七项，避免丢来源。

- 无资料写未采集；无逐字稿的口播字段写无逐字稿，不从标题/描述倒推。全部图片按实际顺序读取，无法读取标缺口。
- 抖音标题核对真实标题字段，不能拿描述第一句替代。标题、文案、封面与口播是不同位置。
- 口播结构按真实顺序记录，含结尾动作；摘录阶段不提前写跨样本结论。
- 标题、开头、正文结构各自提炼。同做法至少见于2条独立素材才成为候选规律，单条归单条观察；不以互动数据证明算法偏好或因果。
- 每条候选含大白话解释、适用内容、不适用内容、不可照搬点、来源素材ID/标题/引用及出现次数；自行改写的示例标AI示例。
- 现有已确认规律保留原文、状态和边界。新增材料支持已有规律时只提补证据候选，有新模式且满足门槛才新增；冲突保留反例和待确认。用户选择本期可用/以后再试/删除由受控采用记录，不改源Skill。

完成：逐条来源映射、缺转写/图片/文案清单、候选与单条观察数量、增量去重记录可检查；规律以knowledge/允许artifact候选交回，不直接写03目录或改已确认条目。
