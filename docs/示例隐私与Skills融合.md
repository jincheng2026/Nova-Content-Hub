# 示例隐私清理与 Skills 融合

日期：2026-10-17。

## 示例清理

本轮从当前项目与重新构建的双版本中移除个人姓名、账号标识、真人照片及相关成品；删除全部 59 张继承的栅格素材，换为 13 张原创几何 SVG。演示账号使用“星河 · 创作实验室”，参考来源使用虚构工作室；历史需求汇总重写为简短产品决策记录。上轮任务的指定临时源码快照已删除。

迁移仅匹配已知演示值的长度与双指纹，不保留旧姓名明文或字符码。它不是安全签名。对格式及结构有效的 schema 1 浏览器工作区、previous 恢复副本和导入备份，替换已知旧路径、默认身份与标准原图 dataURL；同时处理发布快照和回收记录。图像替换后删除旧像素/hash等失效信息，模板重新进入待拆解，不继承先前验收。

用户自建项目、自定义账号及无法确定来源的图片保留。迁移写入失败时保留原存储并进入只读，因此这时不能声称磁盘内容已清除。尚未打开新版的其他浏览器、损坏备份、外部导出文件、系统备份与聊天附件不在本次实际清理范围。重新编码、裁剪或修改过的图片无法用原文件指纹识别。

## Skills 取舍

保留现有三个业务 Skills，不另加一套竞争入口：

| Skill | 融合后的关键行为 |
|---|---|
| 模板拆解 | 逐图证据、固定/变化项、身份元素与视觉关系分开，输出兼容当前 UI 的规则 JSON |
| 模板还原 | 固定版本，标明参考用途，记录提示和真实结果，按明确偏差修订，人工验收 |
| 内容封面 | 继承模板参数，逐字检查标题、构图与尺寸，保留候选与失败原因，不自动发布 |

GitHub 来源为 JimLiu/baoyu-skills 的 baoyu-cover-image、openai/skills 的 imagegen、anthropics/skills 的 canvas-design。逐项读取相关正文并核对 MIT/Apache-2.0 许可；固定提交、具体采用与舍弃内容见 [来源与许可](../plugin-src/references/upstream-notices.md)。本项目以自己的中文步骤重写，没有复制上游整套技能、图片、字体或执行脚本。

共享 [视觉工作流](../plugin-src/references/visual-workflow.md) 随两版本插件及每个独立 Skill 打包，许可证也一同携带。没有全局安装、没有改变宿主信任、没有引入模型供应商依赖或读取 API Key。现有 Hooks 保持最小上下文和观察职责，鉴权/路径仍由 CLI 与后续主进程负责，未因借鉴第三方技能改变安全边界。

## 已验证与待验证

`npm run verify`：31 项原型/工作区测试、20 项插件测试、8 项实际双构建 CLI 联调测试，共 59 项通过。包含自定义数据保留、已知内嵌旧图片迁移、迁移失败保护、两份图库资源及独立 Skill 引用和许可完整性。

当前包仍返回 `executable:false`，没有真实 Agent 出图或写回；这些测试证明流程契约和打包完整性，不证明生成质量或宿主实际遵循 Skill。真实宿主往返、图片生成质量与浏览器渲染仍需后续验收。
