# 新岛定位访谈官（工作台版）

工作台初始化用的 Skill。学员第一次打开工作台时，AI 一次问一个问题，从他的真实经历里问出个人定位、账号定位、内容定位，再给三套主页方案让他挑。每确认一关就写进 `00_个人背景/`，中途断了，下次接着问。

它从 8 月自媒体 AI 实战营副本 1 的定位访谈 Skill 改来（原版公开在 https://github.com/jincheng2026/xindao-interview ），访谈方法和写进文件的格式都没变。

## 放进工作台

1. 把整个 `xindao-interview` 文件夹放进工作台的 Skill 目录。只有 `SKILL.md` 是给 AI 读的，问题、例子和两份文件模板都写在里面，宿主只读这一个文件也能跑。`agents/openai.yaml` 是 Codex 用的显示名，不用 Codex 可以不要。
2. 在工作台的规则文件（`AGENTS.md` 或 `CLAUDE.md`）里加一句，让 AI 第一次进来就主动开始访谈：

   ```text
   如果 00_个人背景/定位总览.md 不存在，或者里面还有哪一关写着「还没做」「仍有待确认」：不管学员先让你做什么，先用 xindao-interview 做定位访谈，做完再做他要的事。
   ```

3. 想让访谈结束后把学员带到工作台的下一步，在规则文件里写清初始化之后做什么，比如「定位做完后，带他去找对标账号」。没写的话，Skill 会默认说「照账号包装把主页设置好，然后去找对标账号」。

## 跑完会留下什么

- `00_个人背景/定位总览.md`：分「当前的我」「账号要说什么」「内容边界」「主页呈现」四节，每节有一行状态（还没做、已确认加日期），末尾有总状态。
- `00_个人背景/账号包装.md`：学员选定的那一套头像、昵称、简介、背景图，加上为什么选它。

工作台其他功能要读的字段：主要读者、核心内容主题、内容支柱、暂时不做、适合的表达视角、公开边界，都在 `定位总览.md` 里，字段名固定。

## 可以按工作台改的地方

- 档案放哪：规则文件里写了别的位置，Skill 就用那里；没写就用工作台根目录下的 `00_个人背景/`，没有会自己建。
- 赛道和内容形式：默认是 AI 自媒体，形式是 AI 科普、热点、测评、教程四种。规则文件里另写了，就按规则文件来。

## 跟实战营原版比改了什么

| 地方 | 实战营原版 | 工作台版 |
| --- | --- | --- |
| 什么时候存 | 四关全部确认完才写文件，中途关掉要从头问 | 每确认一关就存，下次从没做完的那关接着问 |
| 没有 `00_个人背景/` | 叫学员回副本 1 自己建，然后停下 | 自己建，不打断学员 |
| 怎么回答、怎么检查 | 写在副本 1 的飞书手册里，学员要自己去读 | 回答的方法、想不起来时的七个回忆方向、四句看着没错的空话、每关核对的四件事，都写进 Skill，由 AI 当场告诉学员 |
| 平台 | 默认小红书 | 主页那一关先问他发哪个平台 |
| 起步形式 | 固定先做 AI 科普 | 还没开始做内容的推荐科普并说明理由，已经在做别的形式就按他现在的来 |
| 访谈结束后 | 提示继续副本 1 第 07 节 | 照工作台规则文件里写的下一步说 |
| 新增 | 无 | 学员说时间紧，每关最多问三个问题就出小结；学员要全部重来时，先把旧档案另存一份；网页聊天这类不能写文件的地方，把要存的内容整段发给他 |

8 月学过实战营的学员，电脑上已有的 `定位总览.md` 是旧格式，没有每关的状态。Skill 会看末尾「本次确认」那行：写着全部确认的，当成已经做完，只帮他看或改。
