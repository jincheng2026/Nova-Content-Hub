# 首次配置

## 不依赖他人的内容库

本 Skill 不附带任何其他用户的历史反馈、发布数据或本地路径。第一次使用时：

1. 如果用户有内容项目，确定项目根目录。
2. 需要持续积累反馈时，在项目根目录下建立 `内容数据统计/教程视频迭代/`，并从 `assets/` 复制两个初始模板。
3. 用户只想在聊天里写一条视频时，可以不创建文件，直接使用公开基线。

初始化命令（用户确认项目根目录后执行）：

```bash
mkdir -p "<项目根目录>/内容数据统计/教程视频迭代"
cp "<jc-jiaocheng-video 安装目录>/assets/golden_rules-template.md" \
  "<项目根目录>/内容数据统计/教程视频迭代/golden_rules.md"
cp "<jc-jiaocheng-video 安装目录>/assets/feedback-template.md" \
  "<项目根目录>/内容数据统计/教程视频迭代/feedback.md"
```

没有安装 `jc-chendian` 或没有现成 `content_id` 时，用「日期 + 主题短名」作为当前聊天的临时标识，只在当前会话中迭代，不猜测其他内容包。

## 视频和转写依赖

- 只写稿不要求额外软件。
- 要分析参考视频时，使用同包的 `jc-video-analysis`。
- 需要转写时，必须使用当前电脑可用的本地 SenseVoice Small。没有安装时直接说明缺口，不自动上传用户视频到远程服务。

## 成功信号

用户给出一个教程主题后，Skill 会先给可拍的叙事框架，在用户确认前不直接写完整稿；确认后才分段写。
