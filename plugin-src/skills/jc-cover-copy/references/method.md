# 封面文字

只解决封面写什么，不生图、不重新改写正文或冒充已发布版本。读取当前确认稿/SRT、可用标题、核心冲突/结果/判断、指定文字、禁用词与适用公开边界；历史封面只按当前上下文实际提供的可比数据参考，不读取私人默认台账。

先一句话说明观众只看封面应该记住什么，选一个最强且真实的张力来源（反差、损失、身份、结果、冲突）。给三种有实质差别的角度：判断、冲突、结果，不只换词。

主文案通常6–14个汉字，必要时到18字，1–2行，每行一个短语；按缩略图可读性、标题互补、忠于内容、作者表达排序并推荐。用户指定文字逐字保持，改变先说明；不虚构数字、身份、结果、科学结论与因果，不堆空泛煽动词。

交付主方案(保留实际换行)、一句依据、备选、设计交接：锁定文字、一个强调关键词、不可出现的事实或误导。推荐不等于用户选定，提交packaging候选由用户采用；生图任务只有用户选定的锁定文字才可用，设计阶段不擅改。
