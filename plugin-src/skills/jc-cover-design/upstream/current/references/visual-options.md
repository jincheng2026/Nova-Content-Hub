# 视觉覆盖选项

探索模式默认由每个视觉家族使用自己的原生材质、配色和标题系统，不要求用户为所有候选选择同一套颜色和字体。统一选项会让不同风格重新收敛成同一模板。

只有用户明确提出偏好，或进入单风格生产模式时，才读取并应用以下覆盖项。

## A. 人物表达

1. 轻松微笑
2. 好奇发现
3. 笃定讲解
4. 推荐种草
5. 轻微惊讶
6. 揭秘噤声
7. 放松思考
8. 沿用真实照片

优先沿用真实照片已有表情。负面选题不自动生成崩溃、疲惫或痛苦表情。

## B. 画面密度

1. 高密度编辑海报
2. 中密度内容场景
3. 大留白观点海报
4. 由风格原生规则决定

密度只改变信息填充方式，不改变风格材质。

## C. 标题几何

1. 满宽大字块
2. 倾斜纸条／标签
3. 数字或关键词极端放大
4. 红黑印刷／手写批注
5. 漫画爆炸字效
6. 由风格原生规则决定

## D. 人物任务

1. 指引
2. 托举
3. 操作
4. 观察／见证
5. 裁判
6. 正面对视
7. 无人物
8. 由内容和风格决定

## 应用规则

- 用户未指定时，不主动发起一轮低价值视觉选项问答。
- 用户指定多个风格时，覆盖项只作用于用户明确要求统一的部分。
- 不允许用统一「深色＋超粗黑体＋渐变色」覆盖所有风格。
- 用户要求复刻某张已选方案时，优先继承该方案，而不是重新选择选项。
