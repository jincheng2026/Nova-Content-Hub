# jc-shouhui-ppt · 手绘水彩风整页图 PPT 生成器

拆解自《曲率FDE实战训练营线下带练》48 页 PPT。这类 PPT 的本质：**没有一个 PPT 文字框，每一页就是一张 AI 生成的 16:9 手绘水彩信息图**，中文文字全部由图像模型直接渲染，最后把图铺满画布组装成 PPTX。

管线：内容 → 选版式 → 拼提示词（风格锁）→ 样张确认 → 带参考图批量生图 → 质检重生成 → 组装 PPTX。

方法论对齐 2026-08 社区头部同类 skill（gpt-image2-ppt-skills 的模板克隆/layout bank、visual-style-ppt-skill 的 Style Lock/两遍法、codex-ppt-skill 的阶段确认）。

## 依赖与生图后端（按运行环境自动选，一套 skill 两端通用）

真源在 `~/.claude/skills/jc-shouhui-ppt/`，已自动桥接到 `~/.codex/skills/`。**先判断自己在哪个环境**：

| 运行环境 | 生图方式 | 密度能力 |
|---|---|---|
| **Codex**（当前 agent 有原生 `image_generation` 工具） | 直接调原生工具（GPT Image），不跑任何脚本、不需要 API key | 高：单页 20-40 处文字可行，能复刻曲率级密度，**高密度 PPT 首选** |
| **Claude Code / 无原生生图** | 本 skill `scripts/gen_slide.sh`，走豆包 Seedream（`DOUBAO_API_KEY` 在 `~/.zshrc`） | 中：单页 ≤10 处文字最稳，超了要抽卡 |

两条路径的提示词五段式、参考图、质检、组装完全相同，只有出图动作不同。

- 组装：本 skill `scripts/build_pptx.py`（python-pptx，本机已装）
- 版式参考图：`assets/refs/`（曲率原版 11 种版式各一页，生图时作风格参考）

## 第 0 步 · 判断模式

| 用户诉求 | 走法 |
|---|---|
| 做曲率手绘水彩风 PPT（默认） | 直接走下面第 1-5 步 |
| 「拆解这个 PPT/图的风格，以后照着做」 | 按 `references/style-distill.md` 拆解并交付本次所需的结论或风格卡；保存到共享风格库、试产校准及继续制作 PPT，分别按本次请求或已有明确授权执行，不因风格分析自动进入第 1-5 步 |
| 调用之前存过的风格 | 读对应 `references/styles/<名>.md` 当风格锁，其余流程相同 |

## 第 1 步 · 收内容出页面清单（信息设计在这一步完成）

**先读 `references/info-design.md`**——这套 PPT 的核心竞争力是信息密度高、传递效率高、画面应景，机制全在那份文件里。整理成**每页一条**的清单，每页按三层架构组织：

- **标题 = 结论**：完整判断句 ≤16 字（不是类目词），标注橙圈关键词
- **骨架层**：3-5 个论点短语（每项 ≤10 字，编号/胶囊/栏名）
- **证据层**：每个论点下 ≤4 条、每条 ≤8 字，写明装进什么道具（白板/清单板/便签/木牌）
- **隐喻**：先写「本页论点结构 = 对比/集中/流动/分层/循环/风险/协作/筛选」，再从 info-design.md 同构场景词库选场景
- **底部横幅**：≤20 字收口句（观点页必加）
- 版式：`references/layouts.md` 11 种之一

密度上限看 info-design.md「后端密度上限」：Seedream 单页文字 ≤10 处最稳，更高密度要抽卡或换 GPT Image 后端。清单发用户确认后再生图（用户明确说直接做的除外）。默认不放日期、真实 logo；左下角固定使用「锦成」手写水印；二维码留白后期叠加。

## 第 2 步 · 拼提示词

每页提示词固定五段，顺序不能换（2026-08-23 实测定型）：

1. **参考图声明段**（带参考图时放最前）：`references/style-dna.md`「参考图声明模板」——只学风格、禁止复制参考图文字内容。
2. **文字白名单段**：style-dna.md「文字白名单模板」。本页所有文字编号列全，声明除此之外不得出现任何字。
3. **风格锁段**：style-dna.md「风格锁（Style Lock）」，逐字复制不改写。
4. **版式与内容段**：从 layouts.md 选版式模板，逐区域写「位置 → 元素 → 逐字文字（用「」框出）」；⚠️「」只准框要渲染的字，描述用词一律不加「」（会被画进图）；写明视线动线（从哪到哪、箭头方向）；空白处写「留白处什么都不画」；无字道具写明「纸面留白不写字」。
5. **收尾段**：`这是同一套幻灯片中的一页，与其他页保持同一构图密度、线条粗细与边距节奏。不要照片写实风格，不要3D渲染，不要现代扁平UI风格，不要真实品牌logo，画面最外缘不要整页边框。`

每页提示词存 `prompts/NN-页面名.md`，重生成时只改一页。

## 第 3 步 · 样张先行，再批量生图

**先只生成 1 页样张**（选一页信息密度中等的），用户确认风格、密度、字体气质后再批量。跳过样张直接批量 = 返工整套。

**Codex 原生路径**（有 `image_generation` 工具时）：逐页调用原生工具——prompt 传该页 `prompts/NN-*.md` 的全文，参考图传对应版式的 `assets/refs/*.jpg`，尺寸 16:9 最高质量，输出存 `slides/NN-名称.png`。不要为了出图去跑 Python 脚本或配 key。

**Seedream 路径**（Claude Code 等环境）：

```bash
source ~/.zshrc
# 第 4 个参数起是参考图，选对应版式的 assets/refs/*.jpg
~/.claude/skills/jc-shouhui-ppt/scripts/gen_slide.sh prompts/05-观点页.md slides/05-观点页.png 2560x1440 \
  ~/.claude/skills/jc-shouhui-ppt/assets/refs/05-statement.jpg
```

两条路径通用规则：

- **参考图选择**：每页用与其版式对应的 `assets/refs/` 那张；新提炼的风格用该风格自己的参考图。样张定稿后，后续页可再叠加样张作第二张参考图，进一步锁全套一致性。
- 尺寸默认 16:9（Seedream 用 2560x1440，高密度页用 4096x2304）；竖版海报 3:4。
- 文件名 `NN-名称.png` 两位数字前缀，组装按文件名排序。
- 可并行，一批 ≤4 张防限速；整套只用一个后端，中途不换。
- 页数 ≥15 且用户在意节奏时，可先按 visual-style-ppt 两遍法生成一张整套缩略图拼板给用户过目，再逐页出大图（可选步骤）。

## 第 4 步 · 质检（必做，不可跳过）

逐张 Read 查看，按顺序查五项：

1. **白名单外的字**：任何不在清单里的文字/乱码 → 重生成（幻觉最常见于大留白页）
2. **错字**：逐字比对；连续 2 次同处错字就把该词改短或挪进标题
3. **橙圈位置**：是否圈对了关键词
4. **风格漂移**：是否跑成照片/3D/扁平，底色是否还是米白纸纹
5. **版式与裁切**：区域划分是否符合描述，边缘文字是否被裁

只重生成不合格页。大留白观点页属「抽卡页」，同提示词重跑 2-3 次选最好。

## 第 5 步 · 组装 PPTX 交付

```bash
python3 ~/.claude/skills/jc-shouhui-ppt/scripts/build_pptx.py slides/ "输出名.pptx"
```

交付时报告：总页数、重生成过哪几页、遗留风险。用户要讲稿时，可另出 `speech.md` 逐页演讲词。

### 交付物目录约定

用户指定的项目目录（未指定时问一句，临时演示放 scratchpad）下建：

```
某某PPT/
├── prompts/     每页提示词 md（留档可复跑）
├── slides/      每页 png
└── 某某.pptx
```

## 灵活变体

- **换主色/水印**：默认水印是「锦成」；只有用户明确指定其他品牌或无水印时，才改风格锁和文字白名单里的水印，其余不动。
- **单页海报/小红书图**：跳过组装，直接交付 PNG（竖版改尺寸参数）。
- **改一页**：改对应 prompts 文件重跑该页，再重跑组装。
- **提炼新风格**：走 `references/style-distill.md`。
