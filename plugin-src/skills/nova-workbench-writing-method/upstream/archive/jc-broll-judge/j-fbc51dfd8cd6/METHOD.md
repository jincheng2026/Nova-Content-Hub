# B-roll 画面判定

判定规则的证据源：[references/参考拉片台账.md](references/参考拉片台账.md)（3 条参考视频逐秒拉片＋切镜统计＋锦成爆款反例检验）。对剪辑输出结论时引用时间码证据，不空口立规。

## 硬规则

1. 只做判定标注，不生成画面、不改逐字稿原文、不做剪辑决策以外的建议。
2. 判定必须给理由，理由必须能对应台账里的触发条件或禁区条目。
3. 涉及「证明、操作、可执行信息」的段落禁用 AIGC，无例外；用户坚持时明确提示这违反禁区及后果（稀释真实感），再执行用户决定。
4. 未验证项（BGM 配合、参考视频外部数据）不得当成已验证规则写进标注。
5. 发布后有数据时，把「哪段被快进/划走」的反馈回写台账「未验证项」一节，迭代规则。

## 判定流程（对逐字稿逐句/逐段执行）

**第 0 问：这段有没有现成真素材？**（录屏、实拍、截图、后台数据）
有 → 优先用真素材，不用 AIGC（成本低＋真实感强；锦成 97 万播放爆款零 AIGC 的原因）。没有 → 继续。

**第 1 问：这段在禁区吗？**
操作演示 → 录屏＋角标头像＋关键动作字卡；证据（价格/后台/聊天/文档/评论区）→ 实拍截图；观点/判断/情绪高潮 → 纯 A-roll 不叠加；具体可执行信息 → 实拍/录屏＋字卡。命中即定，不进下一问。

**第 2 问：这段命中五类触发之一吗？**
①抽象机制/关系 ②三步以上逻辑链 ③铺垫叙事（经历/背景/行业现状）④专业知识科普 ⑤数字密集。
命中 → AIGC B-roll，并按内容类型定用法：
- **教程型内容**：短插片 5–15 秒，点完机制立刻回录屏/A-roll；全片 AIGC 占比参考上限 ~10%
- **叙事/分析型内容**：可成段 50–80 秒，段内 2–4 秒换景别防划走（推理高潮段加速到约 2 秒/镜）

**都不命中**（清单/公式/对比/结构）→ 动态字卡。

## AIGC 段的构想输出要求（给剪辑的规格）

每个判定为 AIGC 的段落，标注表中必须附：

1. **隐喻方案**：本体→喻体映射，喻体取日常实物（工具/店铺/管道/账本类），并与全片隐喻词典一致——一条片子一套风格、一个贯穿角色，禁止逐段换风格
2. **字卡层**：压在画面上的数字/术语（放口播没念出的换算结论，不重复口播原文）
3. **节奏参数**：段总时长上限＋段内换景间隔（按上表）
4. **切入切出**：段前口播需有设问/悬念句引进（没有就提示写稿补一句），切回落在结论或情绪句

## 位置规则

- AIGC 不进前 30 秒：开头 = A-roll＋冲突数字字卡＋真实成果快闪（1–2 秒/切）
- 最后约 20% 片长不开新 AIGC 段，收尾留给纯 A-roll（升华＋CTA）

## 输出格式

写入视频项目目录（或用户指定位置）`分镜标注_YYYY-MM-DD.md`：

| # | 口播原文（逐句/小段） | 画面类型 | 理由（对应触发/禁区条目） | AIGC 构想（隐喻/字卡/时长/换景） |

表后附：全片 AIGC 占比与条数统计、隐喻词典汇总（本体→喻体全表）、需要写稿侧补设问句的位置清单、【待锦成拍板】项（拿不准的段落列出两案，不擅自定）。

## 失败处理

- 逐字稿未锁稿：提示先走 jc-content-writer 锁稿，仍可出草稿版标注并注明基于未锁稿
- 段落归类拿不准（既像科普又像证据）：列两案＋各自后果，交用户拍板，不硬判
- 用户内容类型不在教程/叙事两型内：按第 0 问＋禁区保守判定，AIGC 参数标【待验证】
