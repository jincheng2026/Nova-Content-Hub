# 免费体验发行策略

第一阶段交付免费体验版：不要求登录，不接认证、权益或付费额度；Pro 留待以后明确需求。免费体验采用现有 `AUTH_MODE=disabled` 构建，根配置和默认桌面启动入口都指向 disabled。保留显式 required 模式，只供旧版本兼容和内部受限测试；它仍按现有边界拒绝需要授权的操作。

## 构建入口

| 入口 | 固定模式 | 用途 | 应用 ID |
| --- | --- | --- | --- |
| `dist:local` | disabled | 本地开发，不分发 | `com.novaisland.nova-content-hub.local` |
| `dist:preview` | disabled | 免费体验安装器 | `com.novaisland.nova-content-hub` |
| `dist:testing` | required | 内部受限测试 | `com.novaisland.nova-content-hub.testing` |
| `dist:production` | disabled | 正式发行预留入口，当前必须拒绝 | 不生成安装器 |

preview / production 命令要求根配置也是 disabled；testing 可显式生成 required 构建，不改变免费体验默认配置。命令不得混用通道与模式，不能把 required 包作为免费体验包发行。

以后获得构建与实机验证授权时，在 `workbench` 目录、对应原生系统和架构的 runner 上执行以下入口：

```sh
# Mac Apple Silicon / Intel，分别在对应架构进程中运行
npm run dist:preview -- --platform darwin --arch arm64
npm run dist:preview -- --platform darwin --arch x64

# Windows x64 / ARM64，分别在对应架构进程中运行
npm run dist:preview -- --platform win32 --arch x64
npm run dist:preview -- --platform win32 --arch arm64
```

Mac 输出 DMG，Windows 输出 NSIS；输出目录是 `workbench/release/<platform>-<arch>/preview`。每次仅构建当前原生架构，跨系统、跨架构和 universal 参数均拒绝；Mac universal 与各 Windows 架构的实际验收留在后续验证阶段。

## 保留的发行门禁

免费与正式就绪分别判断。release 继续保持 `prototype=true`、`experimental=true`、`productionReady=false`；preview 不自动发布到云端，不声称已签名、公证或通过系统兼容验收。安装器仍保留已有资源、路径、版本、工具链、桌面与插件配对校验，以及卸载保留用户数据的设置。

production 入口仍检查 Mac Developer ID 与公证配置或 Windows 签名配置，即使配置齐全也拒绝生成正式安装器。完整功能、原生安装器、升级与数据保留、签名及公证等验收完成前不能放开；认证接入不属于第一阶段的放行条件。

本次仅调整源码与相应用例源码，未运行测试、类型检查、构建、打包、探针、应用或联网验证，也未更新任何已生成安装包。以上命令是后续操作说明，不代表已经执行或验收通过。
