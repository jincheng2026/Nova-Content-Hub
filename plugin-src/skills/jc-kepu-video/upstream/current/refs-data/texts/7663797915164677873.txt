我敢说，这是我今年被 AI 颠覆认知最狠的一次。几天前，我还是一个连 PS 都用不明白，想给猫做 IP 却毫无头绪的小白。现在我已经靠豆包做出了一套从 IP 形象到线下门店设计的完整方案，用的就是它新出的办公模式。今天给大家走一遍我的流程，感受一下它是怎么带我们进入生产级 AI 时代的。

在此之前，我先叠个甲，这是我的画工，这是我大学的专业，总之就是和美工设计完全不搭边。但现在在办公模式用创意设计，就能把 IP 形象定好。指令就简单说人话，就像当面和专业设计师对接需求一样。先告诉它我要做什么，给名字，让它有明确的身份锚点，还有明确画风和风格，这样画风就不会跑偏，其余的按照自己的喜好描述就行。

可以看到，整条提示词没有任何一点专业术语，而且说实话，我在敲提示词的时候，脑子里这个 IP 是没有具体样子的，完全就是想到哪就说到哪。但豆包输出的图片确实是戳到我了，特别是这个表情，灵动又传神。它还主动询问我需不需要延展，那我们恭敬不如从命，继续让它生成一套 IP 周边。

看到这个对话，让我真的感觉像和一个人交流，全程大白话。不管是日常用品还是盲盒，整体的温暖调性和 IP 的适配度都拉满，完全就是我想要的感觉。那接下来就是给 IP 产品周边做一个宣传视频了，我这里用的是创意视频。这一步可以想象自己在跟一个广告导演沟通需求，但最重要的是这些限制词，相当于给 AI 上了紧箍咒。只要说清具体使用场景，不管是 TVC 还是漫剧，豆包都能读懂需求，并搭配对应的视频样式，这样生成出来的成片稳定性也会更高。

最让我惊喜的其实是它的音乐踩点很好，整个视频节奏很紧凑，但又看得清，就两个字，丝滑。除了这些，线下相关的也能交给豆包。我生成的逻辑依旧跟前面一样，先生图再生视频，在办公模式的创意设计界面，简单告诉它需求，把 Logo 和线下门店的设计搞定，再换到创意视频，让豆包生成线下门店宣传视频，直接看成片。我全程没有提到想要的风格，但它自己结合上下文，风格依旧一致，省得我反复调整了。

到这里，一套完整的宠物品牌 IP 全案基本就成型了。最颠覆我认知的是，以前我们用 AI，大多是我主动找工具，我自己调参数，我反复改细节。但豆包是 AI 主动适配人的需求，它自带完整的工作场景技能包，不需要我们拼凑功能，这就是生产级 Agent。还想知道更多办公模式的隐藏用法吗？在评论区告诉我，下期继续给你们实测。【片尾提示音】
