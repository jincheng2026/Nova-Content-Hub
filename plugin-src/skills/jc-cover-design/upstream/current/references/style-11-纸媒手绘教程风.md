# 风格十一：纸媒手绘教程风

把整张封面设计成真实的课程海报、工程笔记本或手绘设计稿。人物进入纸媒场景扮演讲师、设计师或工程师，标题像被印刷、书写或盖章在载体上。

## 适合什么

- 零基础教程、系统课程、从 0 到 1 搭建
- 方法论、工具合集、实战复盘
- 需要强调「步骤完整」「可以照着做」的内容

## 视觉特征

- 载体：海报纸、线圈笔记本、工程草图纸三选一，不同时混用
- 背景：白、米白、牛皮纸、橙色等明亮纸张色
- 标题：作为一个完整标题组，占画面 35%～40%，混合超粗印刷体与手写批注体
- 内容：一个中心图表、界面或教程主体，占 30%～40%
- 方法：可选一张双栏方法卡或横向步骤带，占 15%～20%
- 人物：半身可见高度占画布 35%～45%、宽度占 28%～40%，在纸媒场景边缘承担讲师、设计师或工程师角色
- 质感：轻微纸张纹理、油墨边缘、铅笔线或胶带固定感

## 固定

- 画幅：3:4 竖版
- 只选择一种纸媒载体
- 最大标题字块占画面宽度约 60%～80%
- 正文小字不承担关键信息，缩略图只读主标题
- 默认只有标题组、内容主体组、人物组，最多增加 1 张方法卡
- 手绘箭头最多 2 条；贴纸、印章和胶带不承载额外核心信息
- 保留 15%～25% 的安静纸面
- 关键元素距四边至少 10%

## 变量

- 纸媒载体和纸张色
- 人物扮演的角色、动作和位置
- 主标题、副标题、印章角标
- UI、流程图、角色贴纸等证据素材
- 手写批注、箭头、红线的数量和位置

## 提示词模板

```text
3:4 竖版构图。

把整张封面设计成一张真实的[课程海报纸/线圈工程笔记本/手绘设计稿]，纸张为[白色/米黄色/橙色]，
能看到轻微的纸张纤维、印刷油墨边缘和少量手绘批注，整体明亮、清楚、有真实印刷品质感。

主标题拆成[2/3]个大字块：
第一块“[标题第一部分]”位于[位置]，使用[红色手刷粗体/黑色超粗印刷体]；
第二块“[标题第二部分]”位于[位置]，字号最大，占画面宽度约[比例]；
[第三块“[标题第三部分]”做成红色印章或标签，压在主标题下方]。
同一画面只使用两种主要字体，主标题和手写批注层级分明。

[参考图2]被处理成纸面上的唯一内容主视觉，位于[具体位置]，占画面约[30%-40%]，
其中[必须看清的界面区域]清晰可见。
[参考图3或主题内容]被合并成一张[双栏方法卡/横向步骤带]，位于[位置]，占画面约[15%-20%]，
内部使用统一图标和栅格，辅助解释[两个方法/输入到结果/三个步骤]，不拆成独立贴纸。

参考图1的[性别]五官特征，保持五官一致性，只要半身。
人物位于画面[左下/右下]，半身可见高度占画布约[35%-45%]、宽度占[28%-40%]，
扮演一名[讲师/设计师/工程师]，[具体服装或角色道具]，
[轻松微笑/好奇发现/笃定讲解/轻微惊讶]，
[双手或单手的具体动作]指向内容主视觉。

最多用 2 条手绘箭头或红线连接标题、内容主体和方法卡，箭头都指向明确对象。

缩小到手机信息流尺寸后，最大关键词仍可辨认；主体轮廓清楚；
人脸、标题、产品距四边至少 10%；默认 3 个宏观组块，最多 4 个；
内容和证据占 60%-80%，人物可见高度占 35%-45%，保留 15%-25% 安静纸面。
```

## 避坑

- 不同时使用笔记本、报纸、黑板、便利贴四种载体
- 不把正文段落塞进画面
- 不使用蓝紫发光、全息投影或代码雨
- 不让手写批注抢过主标题
- 不把两个方法拆成两张互相竞争的独立卡片
