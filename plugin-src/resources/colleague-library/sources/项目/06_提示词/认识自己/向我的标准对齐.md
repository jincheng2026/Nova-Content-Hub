接下来所有需要判断"好不好、够不够、要不要继续改"的地方，请以我的标准为准，而不是通用的最佳实践或大众平均水平。

如果你还不确定我的标准是什么，请先去看 {{历史决策记录/审美存档/过往作品路径}}，从中总结出我一贯的偏好和判断模式，再据此做判断。如果实在拿不准，把你的判断和理由写出来问我一次，之后类似的情况就不用再问了。
