# 拆解任意参考 PPT → 可复用风格卡

用户要求拆解参考 PPT（.pptx / 一组图 / PDF）的风格时，按本次授权执行本流程。仅要求分析时，交付拆解结论或风格卡内容，不自动保存到共享 Skill、生成测试页或制作 PPT。授权包含共享风格库维护时，才执行第 4 步的风格卡和参考图写入；授权包含试产校准及对应生图后端、必要费用范围时，才执行第 5 步。已有相应授权不重复询问。未完成试产和质检的风格卡注明「未校准」；用户要求交付经校准可用的风格时，仍须完成第 5 步，不能仅交分析就称完成。实际制作 PPT 另按当前请求进入 SKILL.md 主流程。方法综合自本 skill 拆曲率 48 页的实战与 gpt-image2-ppt-skills 模板克隆、visual-style-ppt-skill 风格提炼。

## 第 1 步 · 拿到每页图

- `.pptx`：解压看 `ppt/media/`。整页图型 PPT（本 skill 的目标类型）每页就是一张大图，直接用；传统排版型 PPT 则需渲染（Keynote/LibreOffice 导出每页 PNG），且要先告诉用户「这是排版型 PPT，只能仿视觉气质，不能像素级复刻」。
- 图片/PDF：直接用或按页导出。
- 全部压成 ≤720px 缩略图（sips），分批 Read 抽样看图；48 页看 20-24 页抽样即可覆盖版式。

## 第 2 步 · 风格 DNA 七问（看图时逐项回答）

1. **底**：纸色/底色、肌理、边缘处理？
2. **线与色**：什么画法（钢笔线稿/扁平矢量/摄影）？主色、强调色、辅助色各是什么、各占多少？（给出近似色号）
3. **字**：大标题什么字体气质？正文什么气质？数字/重点怎么强调？
4. **信息元素统一律**：图表、清单、结论分别装在什么道具里？箭头、图标长什么样？——这条是「整套感」的来源，必须找到它的「一律……」句式。
5. **版式骨架**：标题区/主体区/结论区大致占比？底部有没有签名式收口动作？
6. **隐喻习惯**：抽象观点用什么具象场景表达？列出场景词库。
7. **角落细节与水印**：角落放什么小元素？水印在哪、什么样？

## 第 3 步 · 版式归类

把抽样页归入尽量少的版式原型（参考 layouts.md 的 11 种命名），每种记录：结构描述、文字容量、适用/避免、代表页。原型控制在 8-12 种，太多说明归类太细。

## 第 4 步 · 写风格卡

存 `references/styles/<风格名>.md`，结构照抄 style-dna.md：

1. 好看的原因（拆解结论，5-9 条）
2. 参考图声明模板
3. 风格锁 Style Lock（一段可逐字复制的风格提示词：底/画法/色/字/道具/密度/水印）
4. 文字白名单模板（通用，可直接引用 style-dna.md）
5. 配色速查表 + 道具库 + 版式速查表（含每版式参考图路径）

每种版式挑一页原图压成 JPG（质量 85）存 `assets/refs-<风格名>/NN-类型.jpg`。

## 第 5 步 · 试产校准（交付经校准可用风格时必做）

用新风格卡生成 2 页测试（一页密集流程页 + 一页大留白页），带对应参考图，按 SKILL.md 第 4 步质检。发现风格锁被模型「实诚」抄进画面的词句就改写风格锁；发现幻觉就检查白名单是否前置。校准结论回写风格卡。

## 已知铁律（各风格通用）

- 白名单前置 > 白名单后置。
- 风格锁里不写比例字样（「16:9」会被画进图）、不写含示例文字的句子。
- 带对应版式参考图是幻觉的最强解药。
- 大留白页永远是抽卡页。
