# 信息设计 · 高密度不乱 + 画面应景的机制（2026-08-23 拆自曲率 48 页）

曲率这套 PPT 真正的核心竞争力不是画风，是**每页信息量大、传递效率高、画面应景**。机制拆解如下，写页面清单和提示词时逐条执行。

## 一、一页只有一个主张，标题就是结论

标题从不写类目词（「课程介绍」「市场分析」），永远写完整判断句：「平静的海面，养不出强大的水手」「头部只跟头部合作」「FDE可能只有3—5年的寿命」。读者只看标题就完成 80% 的接收，画面全是这句话的证据。

**执行**：每页先写出「这页要让观众记住的一句话」，它就是标题；写不出判断句说明这页该砍或该并。

## 二、三层信息架构（读三遍设计）——高密度不乱的核心

| 层 | 停留时间 | 元素 | 字号 |
|---|---|---|---|
| 结论层 | 1 秒 | 毛笔大标题（+橙圈关键词） | 最大 |
| 骨架层 | 10 秒 | 3-5 个论点：编号木牌①②③、胶囊标签、栏名 | 中 |
| 证据层 | 30 秒+ | 每个论点下的清单、图表、小字标注 | 最小 |

关键规则：**证据层文字必须全部装进道具容器里**（白板上、清单板上、便签上、木牌上），字是道具的「纹理」，不干扰前两层；画面上不允许有游离在容器外的小字。密度全堆在证据层，骨架层永远保持 3-5 个。

**执行**：页面清单不写平铺要点，按「标题 → 骨架（3-5 个短语）→ 每个骨架下挂 0-4 条证据 + 装进什么道具」组织。

## 三、一条明确的视线动线

每页都有唯一的阅读路径：编号①②③、虚线箭头、或线性隐喻本身（水流、道路、传送带、楼梯）。观众的眼睛不用自己找路。

**执行**：提示词里明确写出动线（「从左到右」「绕回形成回路」「虚线箭头从A指向B」）。对比页动线是「左→中分隔物→右→底部结论」。

## 四、应景 = 隐喻做论证，不做装饰

场景不是配图，是论点结构的可视化：先提出论点的**抽象结构**，再找物理世界里天然同构的场景。

| 论点抽象结构 | 同构场景词库 |
|---|---|
| 对比/落差 | 平静泳池 vs 真实港口、两岸、小船 vs 大船、室内 vs 山顶 |
| 集中/头部化 | 灯塔与小店群、山顶与山脚、汇聚的箭头 |
| 流动/过程 | 水流汇合、流水线、道路与路标、桥、楼梯 |
| 分层/结构 | 大楼剖面（楼层=部门）、地层、书架 |
| 循环/飞轮 | 环形传送带、齿轮组、回路箭头 |
| 风险/困境 | 风浪中的船、闸门、断桥、逆风 |
| 协作/共同体 | 同一条船、圆桌、山顶握手、拔河 |
| 筛选/晋级 | 台阶+奖杯、门与门后的团队、漏斗 |

检验标准：把画面遮住只留标题，问「这个场景本身是否就在讲这个道理」；隐喻的物理属性必须对应论点属性（灯塔的高与唯一 = 头部的地位与稀缺）。

**执行**：选隐喻时先写一行「本页论点结构 = X」，再从词库选或造同构场景。

## 五、数字与关键词永远大号橙字

200积分、TOP3、80%、3-5年——一页里最有传播力的量化信息用大号橙/朱红手写，比周围字大一号，不允许淹没在证据层里。

## 六、底部横幅收口

密度再高，底部一条橙描边横幅把整页折叠回一句 ≤20 字的话。观众记不住细节没关系，记住横幅就够。观点强的页必加。

## 分层字数预算（取代旧的「一页 ≤80 字」一刀切）

- 结论层：标题 ≤16 字
- 骨架层：3-5 项，每项 ≤10 字（编号句含序号）
- 证据层：每个骨架下 ≤4 条，每条 ≤8 字，必须装进道具
- 底部横幅：≤20 字

## 后端密度上限（2026-08-23 实测，如实告知用户）

- **Codex 原生 GPT Image（高密度首选）**：在 Codex 里运行本 skill 时直接调原生 `image_generation` 工具，单页 20-40 处文字可行，能复刻曲率原版密度；不需要任何 API key。锦成做曲率级高密度 PPT 默认走 Codex。
- **豆包 Seedream（Claude Code 环境默认）**：单页文字白名单 ≤10 处、单项 ≤8 字最稳（带参考图）；14 处约有 1/3 项出小错。缓解手段：①尺寸开 4096x2304；②长句挂大木牌、小道具里只放 ≤4 字短词；③同提示词抽卡 2-3 次拼最好。
- 按页面密度选环境：多数观点/流程/对比页 Seedream 够用；日程页、多栏证据页等高密度页去 Codex 跑。

## 提示词写作铁律（补充）

- 「」引号在提示词里**只用于要渲染进画面的文字**；描述用词（旧方式、新方式、某某场景）一律不加「」，否则会被画进图（实测踩坑）。
- 橙圈关键词写法：「标题行内最后两个字被橙色椭圆直接圈住，除标题外不要在任何地方重复标题里的字」，防止模型在标题外重写一遍。
