# 人脸参考图选择策略

## 默认原则

- 每次生成默认只使用 1 张人脸参考图，避免多张近似自拍稀释五官一致性。
- 常规、教程、知识类封面使用 `config.md` 的「默认人脸」。
- 严肃、冷静、思考感使用「中性表情」。
- 亲和、推荐、好消息感使用「微笑表情」。
- 强烈大笑或半身姿态图只在构图确实需要时使用，不作为常规默认图。
- 疲劳、风险、消耗、焦虑等负面选题不自动切换成愁眉苦脸；默认仍使用微笑或常规身份图，在提示词中写「好奇发现、笃定讲解、轻微惊讶」。
- 只有用户明确要求个人受挫、痛苦或崩溃叙事时，才允许生成明显负面表情。

## 多参考图编号

- 表情图采用「替换默认人脸」而不是「追加第二张人脸」。
- 图1始终是本次选中的唯一人脸参考图。
- 图2起留给 UI、产品、图标、截图等内容素材。
- 只有用户明确要求融合某张照片的具体姿态时，才允许增加第 2 张人物姿态图，并在提示词中分别限定「五官参考」和「姿态参考」，防止模型混淆。

## 身份安全

- 含有其他真人的风格参考图只用于文字拆解，不与用户人脸图一起输入模型。
- 默认把完整案例转译成文字空间结构，只输入本轮唯一用户身份参考和必要内容素材，一次生成包含人物、标题、主视觉和背景的完整构图。
- 输入隔离不等于画面拆分。不得因为风格图含其他真人，就默认改成无人物背景＋后贴人物。
- 必须输入风格图片时，只能使用不含其他可识别真人、构图完整且没有巨大遮挡块的版本。
- 有匹配动作的真实照片时可直接作为唯一身份与姿态参考；没有匹配姿态时，在完整生图规格中具体描述动作。
- 分开验收「构图是否成立」和「身份是否一致」；构图好不能抵消脸错，脸错也不应误判为风格失败。
- 合成人物时按可见外接框校验：常规半身高度占画布 35%～45%、宽度占 28%～40%，不得只在角落露出一枚小头像。
- 人物可与内容面板边缘重叠 5%～10%，但不遮挡标题关键词和核心证据。
- 人物加入后必须与内容形成一个明确视觉动词：指、托、推、挡、揭、观察、操作或裁判；只把人物贴在空角落不算完成。
- 人物边缘处理、描边、阴影和色温必须服从所选视觉家族，避免像后贴上去。

## 身份修复顺序

完整构图审美通过、只有身份问题时，按以下顺序修复：

1. 局部编辑人物区域，保留标题、主视觉和空间关系。
2. 使用匹配姿态的真实照片替换人物区域，调整裁切、描边、阴影和色温。
3. 单独生成透明人物图层，再确定性合成到原构图。
4. 前三种仍失败时，才启用无人物背景＋真实照片抠图的备用流程。

备用流程不得成为默认工作流；没有用户保留要求时，也不得以保护背景为理由保留丑构图。人物身份问题按上面的顺序局部修复；标题、主视觉或人物互动失败时，在本次授权范围内返工。重新生成完整封面不得改动用户明确锁定或要求「其他不变」的部分；确需扩大修改范围时，先说明冲突并取得明确授权，不降低验收标准。

每种风格最终只保留 1 个版本；修复过程中的失败稿不作为候选交付。

## 当前参考库角色

实际文件名和用途以 `config.md` 为准。若文件缺失，回退到存在的默认人脸；不要猜测或静默改用其他人物图。
