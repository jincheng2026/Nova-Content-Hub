# 选题扩层

## 前提

任何资料都可能找到更大的受众圈层，找不到先怀疑方法。两条硬边界：

- 放大只能从资料里已有的点往外推，资料完全没提的不硬加；
- 放大到某一层接不住时，如实说接不住，建议补资料或停在低一层。

## 1. 盘材料

按 [资料接收](material-intake.md) 的素材清单先盘清材料：能兑现什么、已有表达、记忆点、露过头的大主题。记忆点在后面每一层都要留得住——层扩得再大，丢掉记忆点就成了空话。

## 2. 找放大点、问底气

从五处找资料里还没用足的放大点：数字、成绩、身份权威、反差、用户自己觉得不值一提的事。

再想一层：这类内容观众会不会问「凭什么听你讲」？方法、经验、建议类通常会。资料里没写底气时，列出用户很可能有、又能直接说出口的底气：

- 年限：做这行几年、坚持更新几年；
- 产量：更新多少条、经手或服务过多少单；
- 结果：粉丝、收入、学员或客户成绩，最好能给出处；
- 身份：一听就信的经历或头衔。

菜单里只问 1～2 个最能抬层级的；用户不答也能继续，此时把带底气的层级写成占位（如「〔经手 N 件理赔案〕」），不编数字。

挖不出放大点时，反问一句：「这件事你明明不占优势，为什么还有人愿意听？」答案常常就是放大点。

## 3. 松限定词

把已有表达和主命题里的限定词、行业词、术语逐个拎出来，对每一个问三件事：

- **能不能删**：删掉后原来的人还在，新的人也进得来；
- **能不能换**：换成观众自己的说法，如行业词换成日常用语；
- **能不能换人群或需求**：讲给更大的一群相关的人，或换成他们更在意的需求。

标签越多受众越窄：任何一个标签对方不感兴趣，他就划走了。只有删了就交付不了的限定词才保留，并说清为什么保留。

## 4. 逐层放大

从资料原样开始，每次只改一处，写出 3～4 层。常见放大方式（按需选用，不必每种都用）：

| 方式 | 做什么 | 例子 |
| --- | --- | --- |
| 原样 | 已有表达或整份材料的兑现，不改 | 理赔审核员讲最常见的 5 类拒赔原因 |
| 加底气 | 前面加上让人信的数字或身份 | 〔经手 2000 多件理赔案〕的人讲…… |
| 换说法 | 行业词换成观众自己的词 | 拒赔原因 → 你的保险可能白买了 |
| 挂大主题 | 挂到资料露过头的大主题上 | 理赔避坑 → 家里老人生病，钱怎么才不白花 |
| 换人群 | 讲给更大的一群相关的人 | 给买过保险的人 → 给正准备给父母买保险的人 |
| 往抽象走 | 从具体事件上升到大家都遇到的问题 | 拒赔案例 → 买保险时怎么问，才不被话术带着走 |

每一层都要有真实的扩大：新多了一群人，或同一群人更在意了。只换措辞不算新的一层。

找不到下一层时换角度：同一件事按问题定义、原因、评价、办法各换一种讲法，不硬凑层数。

## 5. 上限校验（内部执行，不进菜单）

每层过四项，任何一项过不去就降一层并记下原因：

- **接不接得住**：资料的哪一段能兑现这一层的承诺，还缺什么；
- **对不对口**：这一层吸引来的人是不是用户想要的观众或客户；用户没说清生意模式时按资料推断并标「未确认」；
- **评论区会不会跑偏**：放到对立、阶层、国家这类话题时，讨论会不会全歪到别处，和用户想讲的无关；
- **像不像空话**：离记忆点太远就空。每层都要能从大问题很快收回到资料本身，收不回的降层。

放大后会引起争议但仍值得讲的，可以建议加一句表明立场的话，冲突本身保留。

## 6. 定稿前自检

- 层与层之间是真实的扩大，不只是换措辞；
- 记忆点在每一层都留得住；
- 没有使用未占位的编造信息；
- 受众描述是具体人群加他们在意什么，不是「所有人」；
- 第 1 层保留资料原样的说法，没有先动手改。
