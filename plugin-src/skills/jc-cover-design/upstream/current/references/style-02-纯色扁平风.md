# 风格二：纯色扁平插画风

严格二维的编辑插画或角色世界。真实人物可以作为唯一摄影元素进入画面，其余元素必须保持同一套平面语言。

## 视觉身份

- 视觉载体：扁平编辑插画、角色贴纸海报、白底涂鸦说明页
- 构图主依据：`examples.md` 中角色互动最接近的完整案例
- 材质辅助：`FF-01`，只学习平面语言，不继承遮挡后的空洞构图
- 绝对主角：一个角色群像、一个扁平道具或一组围绕同一任务行动的对象
- 人物任务：与角色协作、指挥、展示或进入插画世界

## 适合

- Agent 团队、角色协作、概念科普、轻教程、工具合集
- 可以用角色、道具或简单形状说明的内容

## 视觉命题模板

```text
[一组统一角色／一个扁平装置]正在共同完成[动作]，
通过[颜色或位置冲突]表达[结果]。
```

## 材质合同

- 严格二维矢量或手绘平面
- 纯色块、硬边、统一线宽、统一圆角
- 最多 3 个主色＋1 个强调色
- 角色和道具使用一致的白色外描边或深色轮廓
- 真实人物是唯一照片元素，采用与插画一致的白边或硬阴影
- 禁止金属、玻璃、柔光、真实 3D、渐变按钮、发光线、动态模糊

## 标题几何

- 标题占顶部或一侧 28%～38%
- 最大关键词采用满宽大字块或蓝色／黑色框线字块
- 标题边框、箭头和涂鸦使用与插画相同线宽
- 不使用立体浮雕、柔光阴影和金属渐变

## 构图骨架

### A. 白底角色世界

- 白色或极浅底
- 标题在顶部形成框线字块
- 角色群像占中下方 45%～55%
- 人物在一侧与角色互动

### B. 单色编辑海报

- 单一高饱和背景
- 一个巨大平面道具或字符占画面主体
- 标题与道具互相遮挡
- 人物采用硬边抠图，不增加零散图标

## 人物规则

- 常规半身可见高度 35%～45%、宽度 28%～40%
- 人物边缘统一使用白色贴纸描边或硬边阴影
- 手势必须指向具体角色、道具或动作结果

## 硬禁止

- 3D 仪表盘和拟物按钮
- 玻璃卡片、金属边框、柔光投影
- 多套不同线宽的图标
- 纯色背景上散落无任务的小图标
- 用近大远小和动态模糊制造假广告感

## 提示词骨架

```text
3:4 竖版扁平编辑插画。

视觉命题：[一句角色或道具动作]。

背景为[单一纯色／白底]，
[角色群像／扁平装置]占画面约[45%-55%]，
所有角色和道具使用统一[线宽、白边、圆角和色块]，
通过[具体动作]共同表达[内容结果]。

标题“[指定文案及分级]”位于[位置]，
[最大关键词]形成最大平面字块，
标题边框和涂鸦与插画使用同一套线条。

全图严格二维，无渐变、无玻璃、无金属、无真实 3D。

参考图1的用户人物位于[位置]，可见高度约[35%-45%]，
人物采用[白色贴纸描边／硬边阴影]，
执行[协作／指挥／展示]动作，
手势与角色或装置发生明确关系，
标题、人物和插画在同一次构图中形成完整轮廓。
```
