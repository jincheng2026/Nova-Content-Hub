## 本产品必须记录的执行事实

1. 已发现助手、已打开助手、已预填请求、用户已发送、插件已接单是不同事实。
2. 图片不是短链接正文；请求通过固定 ID/hash 指向本次授权的文件，插件须实际读取并校验，不能将“链接已打开”记成“已收到参考图”。
3. 输入由内容 ID、模板版本、本人照与样张、比例、数量和 mutation/request/attempt ID 固定；换助手建立可追溯的后续交接。
4. 真实图片先进入暂存，检查身份/内容归属、文件类型、实际像素、重复 hash、数量和请求关联，正式提交后才成为候选。
5. 用户选定、发布计划、人工登记发布另行保存。停止会话、Hook Stop、文件出现都不能直接代表生成和验收成功。
6. 安装器可以准备本产品插件并提供清晰入口；需要宿主信任的步骤不能通过修改未知用户配置绕过。
