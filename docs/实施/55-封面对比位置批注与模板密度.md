# 封面对比、位置批注与模板密度

日期：2026-10-19。承接 17:00 前直播演示目标，用户追加六图反馈；这批统一为 0.3.13。安装、真实助手修改结果以文末后续记录为准。

## 交付变化

- 模板页去掉常驻照片与默认设置侧栏；“照片与默认设置”打开既有管理弹窗。1280 四列、1500 以上五列，小窗口降列；整组原图、样张数、缩略带、来源、学习还原和人工验收仍保留。描述在列表收紧，完整描述可在预览阅读。
- 封面比例既能选常用值，也能选“自定义比例”填写宽高比；统一计算合法整数尺寸与最低像素，非法或超限比例阻止生成，不把未知比例当预设值。
- 候选按完整图片展示并压紧操作布局；收藏集中靠前，支持只看收藏。勾选 2–4 张后并排比较，可直接收藏与选为封面；原批次编号保持稳定。
- 每张候选可“批注修改”。点击原图添加位置，按原图宽高百分比记录；点在 object-fit 留白上不会添加错误坐标。每个位置与整体要求可编辑，最多 20 个位置；也有键盘可用的中心位置按钮。批注复用候选 note 持久化，普通旧备注完整保留。
- 修改前明确确认：原候选图片、当前显示的模板与人物、当前全局助手及原候选比例。保存批注，附加原图为内容参考资料，生成一张新的候选。复用现有 updateCandidate → attachMaterial → generateCover；不增加第二套桥接或修改旧任务/原图，失败保留草稿，重试复用已附参考。
- 周日程日期待定行与七天列对齐、空间加高，时间/标题分行；日期待定仍单独显示，不虚构午夜时刻。
- 渠道文字/背景颜色使用共用 ColorField：Semi 常用色板、自由 ColorPicker、十六进制输入和实时标签预览。非法颜色阻止保存；busy 阻止编辑，原生系统颜色窗口不再是业务入口。
