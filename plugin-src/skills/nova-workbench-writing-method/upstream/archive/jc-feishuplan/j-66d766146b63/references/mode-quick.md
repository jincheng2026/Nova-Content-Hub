## 模式一：快速计划沉淀

适用：用户口喷今天、明天、本周、本月要做的事。

流程：

1. 先按 `input-triage.md` 区分任务与非任务；想法、资料、背景、状态和决策不进入任务清单。
2. 识别时间词：今天、明天、本周、本月、近期、不急、截止。
3. 按主题拆组：如内容项目、知识库、客户项目。
4. 每组只提取可执行任务。
5. 每条任务写 `事项` 和 `下一步动作`；下一步不清楚时标待确认。
6. 对 AI 推断的主题、计划日期、优先级显式标注。
7. 如有非任务内容，先输出「不进入任务池」区，再输出候选任务清单，在 CHECKPOINT 1 停下。

候选任务格式：

```text
我先不入库，先给你候选任务确认：

1. 【主题】____
   事项：____
   下一步动作：____
   计划日期：____
   原文依据：____
   AI 推断 / 待确认：____
   置信度：高 / 中 / 低

你可以回复：确认 / 删 2 / 改 3：____ / 合并 4 和 5 / 重新提取，太细 / 太粗
```
