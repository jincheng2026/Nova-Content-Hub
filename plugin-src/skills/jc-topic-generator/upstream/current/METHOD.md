# 锦成选题助手

把「读定位 → 读素材 → 出候选选题 → 落盘选题库」这条流程固定下来，可重复执行。

## 选题库结构

- `04_选题库/00_选题总览.md`：全部选题状态的真源，一张总表（编号、选题、来源、状态、发布日期、效果），外加按批次的「生成批次记录」（生成日期、依据、本批已读取素材清单）。
- `04_选题库/{AI教程|AI科普|口播观点|X|vibe知识大赏|视频转图文}/{已做|待做}/Txxx_短名.md`：每个选题一个独立文件，按内容类型和是否做过（✅）分目录（`X/` 放专门发 X 平台的内容，`vibe知识大赏/` 放锦成自己做、发抖音小号的 vibe 知识科普片，`视频转图文/` 放抖音小号的视频转图文），编号 T001 起顺延，文件顶部是状态块（来源/状态/发布日期/效果），正文写选题内容，并单列「参考视频与图文」。
- 来源取值：对标启发 / 自主想法 / 混合来源。本 skill 生成的选题一律标「对标启发」。状态取值：待写 / 草稿 / 已发布，新选题一律「待写」。

## 工作目录

- 默认 vault：`/Users/hejincheng/AIJinCheng/个人IP与内容/第二大脑/`
- 若当前工作目录本身就是一个含 `00_个人背景/`、`02_内容素材/`、`04_选题库/` 的内容 vault，则以当前目录为准。
- vault 的通用规则（只用真实信息、排除 `_` 开头辅助文件、有效内容判定等）以 vault 内 CLAUDE.md / AGENTS.md 为准，本 skill 不重复、不覆盖。

## 模式判定

1. 用户说「我搜集了新内容，帮我生成新选题」或同义表达，且 `04_选题库/00_选题总览.md` 已存在 → 走**增量模式**。
2. 其余情况（首次生成、选题总览不存在）→ 走**首次模式**。
3. 用户只要求改某个已有选题、写正文、起标题 → 不属于本 skill，直接说明并停止。

## 首次模式

1. 读取 `00_个人背景/定位总览_v0.1.md`（或该目录下最新版本的定位总览）。
2. 扫描 `02_内容素材/未参考/*/*/`，按 vault 规则统计尚未支撑正式内容的有效素材数量。
3. **有效内容不足 10 条：立即停止。** 报告当前有效条数、还缺几条，请用户回到关卡 2 补充素材。不生成任何选题。
4. 逐条读取有效内容的 `笔记信息.md`。笔记中嵌入的本地图片（如 `![[01.jpg]]`）必须按嵌入顺序全部读取，图片文字并入该条内容一起理解；图片无法读取时记录具体路径并如实报告，不得跳过或推测。
5. 生成 5—10 个候选选题，第一批优先现阶段能讲清楚的 AI 科普选题，全部采用定位文件确认的内容视角。
6. 落盘：每个选题建一个 `Txxx_短名.md`（格式见下），并创建 `00_选题总览.md`（总表 + 本批生成批次记录）。

## 增量模式

1. 读取现有 `04_选题库/00_选题总览.md`，取出「生成批次记录」里全部已读取素材清单和总表中全部已有选题；去重比对需要细节时再读对应 Txxx 文件。
2. 扫描 `02_内容素材/未参考/*/*/`，找出**不在已读取清单中的**有效内容，即为新内容；默认不从 `已参考/` 重复立题，用户明确要求复用时除外。
3. 新内容为零：停止并告知用户没有未处理的素材。
4. 按首次模式第 4 步读取全部新内容（含嵌入图片）。
5. 基于新内容生成候选选题，并与已有选题逐一比对去重：同一个问题只是更换工具名、数字或近义词的，视为重复，不新增。
6. 新素材充足时生成 5—10 个不同的新选题；材料不足时宁可少生成，并明确说明是素材量不足还是与已有选题重复，不凑数。
7. 落盘新选题：每个新选题建一个 `Txxx_短名.md`（编号接现有最大编号顺延），放进对应类型的 `待做/` 目录（AI 教程、AI 科普、口播观点、X、vibe知识大赏、视频转图文，拿不准时先问用户），在总览表对应类型的待做组末尾各加一行，并在「生成批次记录」追加本批记录（日期、依据、本轮读取的文件）。
8. **禁止删除、改写、重排任何已有选题**，包括已有 Txxx 文件、总览表已有行、编号和生成批次的旧记录。

## 选题文件格式

每个 `Txxx_短名.md` 固定为「状态块 + 选题内容 + 参考视频与图文」：

```markdown
# Txxx 选题名（讲什么，不是标题）

- **来源**：对标启发
- **状态**：待写
- **发布日期**：
- **效果**：

## 选题内容

- **写给谁**：具体人群，对得上定位文件的主要读者
- **解决什么问题**：一个具体问题，能对上定位中的读者卡点或内容支柱
- **备注**：借鉴的角度、与其他选题的依赖或重叠、需当场实测核验的事实（可选）

## 参考视频与图文

- 《作品标题》
  - 类型：视频或图文
  - 平台 / 作者：平台名 / 作者名
  - 作品 ID：`平台作品 ID`
  - 原视频或原内容：可直接打开的稳定作品链接
  - 本地素材：可直接打开的 `笔记信息.md` 相对链接
  - 参考用途：具体说明这条材料用来参考什么（可选）
```

一条参考材料写一组完整信息，不得只写文件路径。没有外部参考材料时，在这一节明确写「无外部参考视频或图文」，并说明选题来自哪里。

总览表每行与对应 Txxx 文件的状态块必须一致；本 skill 只新增，不改已有选题的状态。

## 硬约束

- 选题只表达「准备讲什么」，不优化成夸张标题，不生成正文。
- 素材处理过程（「图片显示」「素材包提取」等字样）不写进选题。
- 每条参考材料必须按对应 `笔记信息.md` 的真实字段填写标题、类型、平台、作者、作品 ID 和作品链接，并附可直接打开的本地笔记链接；不得凭目录名补造信息，不得只留一串本地路径。
- 每个选题的问题、人群与定位文件对得上；定位「暂时不做」清单里的方向不主动立选题，用户明确拍板要做时可以立，并在备注注明拍板日期。
- 缺少关键材料的选题标记「缺素材」。
- 涉及具体数字、价格、工具功能的选题，在备注注明发布前需当场实测核验。

## 完成后报告

告知：生成/追加了多少个选题、哪些存在重复或缺素材风险、本轮新读取了哪些文件；增量模式下额外说明跳过了哪些重复选题及理由。
