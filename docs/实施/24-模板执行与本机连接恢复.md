# 模板执行与本机连接恢复

2026-10-18。继续执行“先开发，再统一测试”。本批只修改源码并人工阅读调用关系；**没有运行测试、类型检查、构建、探针、应用或 AI**。本机已安装的应用仍是[22](22-应用命名图标与Mac本机安装.md)所记录的上一批 arm64 本地实验版，本批源码尚未重新打包、安装或启用宿主插件。

## 完整接线范围

- 模板页新增“学习与还原”：读取整组固定样张，交给设置中唯一选定的助手；传正确模板执行 Skill、库身份和固定任务 ID。内置模板先复制为自己的模板，不改内置包。
- 固定请求记录源版本与包摘要；认领要求声明已阅读全部输入。规则分为固定/可变，每条规则绑定具体样张证据；首张 PNG 还原与规则作为同一结果提交。图片完整解码及尺寸校验后，再核对锁内输入和尝试状态。
- 助手提交仅记作“待人工验收”。桌面对照原图、还原图和规则证据，由用户勾选确认；验收以请求/尝试/源版本/包/结果摘要和编辑令牌共同绑定，生成新的不可变版本。CLI 无 accept 命令。
- 每个模板只允许一个进行中的尝试。界面不再并列提供重复 Agent 跳转；历史只读，已验收请求不可重试，重新学习创建新请求。跨助手继续创建关联尝试并保留历史；源版本改变后允许取消原尝试，继续或验收仍严格要求源版本匹配。
- 模板执行独立 `template` 命令空间，新增 `nova-content-template-execution` Skill；旧三项 contract Skill 保持 `executable:false`。required 模式继续拒绝业务读写，不能用本地开关伪装可信权益。
- 桌面接通十项有限 IPC、preload、utility worker、持久化 pending 和全局恢复入口。请求/尝试两阶段保留固定事务 ID，响应未知先查询同一回执；恢复不自动再次唤起助手。
- 模板 metadata v1 仍可读取，首次学习才升级为 v2；文件库 descriptor 继续 v5。还原、规则、校验报告和输入快照均随整库备份校验；恢复的进行中尝试标记为中断，已提交和已验收结果保留。旧读者必须拒绝更高格式，不能降级覆盖。
- 标签按实际来源显示：内置模板可直接使用；用户模板只有当前版本及包摘要匹配结构化验收记录时，才显示已记录人工验收。手填布尔字段不能代替该记录。
- 设置分别检查封面与模板执行 Skill，共用一个助手选择器。安装状态、宿主是否打开及真实生图能力是不同事实。

## 本机连接损坏恢复

机器连接记录不可读时，主进程只处理固定 userData 下的 `machine-binding.json`，不接收任意路径。用户明确确认后先保留旧原始字节，再通过持久化恢复意图安装空连接；进程中断后继续同一恢复。重连不删除正文、照片、模板、业务库或授权资料，原待处理意图仍留在旧连接备份中。

符号链接、过大文件、无法读取或外部替换均拒绝自动处置。恢复面板在初始化失败时仍可使用，并可导出白名单脱敏诊断。Node 不提供 conditional unlink/openat，私有 userData 下的极窄竞态已在源码标注；不宣称支持不可信共享写者。

## 源码审查后收敛

1. 验收写包后、日志提交前可能留下未登记版本。新验收在锁内复用相同包、保留并跳过冲突孤儿包，避免该模板后续永久卡住。
2. 历史某份还原图丢失不应拖住新尝试。当前目标仍严格校验，其他历史逐项投影为不可用；验收和备份核验不放宽。
3. 历史结果在另一个尝试进行时不允许验收；已验收请求的其他历史尝试不再提供无效重试按钮，避免已知冲突变成全局待恢复操作。
