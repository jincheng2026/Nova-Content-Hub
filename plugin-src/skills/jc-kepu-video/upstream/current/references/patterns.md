# 讲明白的范式

> 2026-09-15。回答一个问题：这些做 AI 科普的人，平常开口是怎么说话的，怎么把一件事讲到观众听懂。
> 怎么拆的：9 个账号 188 条逐字稿全部整篇读完，不挑段落。记的是「说法」，不是内容。同一个说法在两个以上账号、每个账号两条以上视频里出现，才算范式；只有一个人用的放到最后「各人的招」。原话主要引五个讲得最清楚的人（大李、姜学长、向行、阿朱、不喝九），FredTalk、小九、屯点、森森只在他们有独特用法时引。
> 怎么用：写稿时按视频的位置查，开口看第一节，讲一个词看第二节，接不上看第三节，收不住看第四节。每条先说它替观众做了什么，再给原话。原话后面括号是谁说的。

## 一、开口：前三句

**1. 第一句就是观众的处境或原话。** 让观众一开口就认出「这说的是我」。九个账号里没有一个用「大家好我是谁」开场讲科普。
- 「你有没有发现，同样是去用 AI，有的人能够让它去写出非常高质量的内容，有的人嘛，就只能去得到一些很敷衍的回答。」（姜学长）
- 「你可能经常听说大模型这个词，但是却不知道什么意思。」（大李）
- 「我好不容易弄懂 Prompt，怎么又冒出 Agent；我还没摸清 Agent，怎么又蹦出 Skill」（阿朱）
- 「还是有很多人卡在了不知道该怎么做，不知道自己需要哪些模块，不知道怎么跟 AI 沟通，对不对」（不喝九）
- 「如果你刚刚安装好 Codex 啊，你是不是发现，你做的页面永远是这样这样这样，能用，但是蛮丑的」（FredTalk，他 15 条以上都是「如果你刚装好 X」开头）
- 「还在拍这种普通的照片吗？今天就带你做这种创意转场。」（屯点）
- T018 用了阿朱这句。

**2. 紧接一句承诺：几分钟、讲清楚什么、分几块。** 替观众回答「值不值得看完」，顺便把目录摆出来。
- 「今天我们就一个目标：搞懂 AI Agent。把笔拿出来，五分钟教会你。」（大李）
- 「所以今天我就用一条视频说清楚：Skill 是什么，去哪找，怎么装，装哪些。」（姜学长）
- 「每个词我讲两点：为什么出现、解决什么问题。视频时长十八分钟，建议先收藏再看。」（阿朱）
- 「今天我们就花十分钟的时间，跟你讲清楚 AI 的四层逻辑是什么」（向行）
- 「给我两分钟，我教给你四个最简单的神奇指令」（FredTalk）
- T018 有「今天一条线讲清楚十个词」。

**3. 说这个题是观众问的。** 把选题的来源交给观众，观众觉得是自己点的菜。
- 「大家一直在评论区问，老师能不能讲一下」（向行）
- 「最近很多朋友都在问我，为什么我的 AI 助手用着用着就失忆了」（姜学长）
- 「上一期那条工作台的视频，我看了评论还有反馈，然后给大家总结出了这几个常见的问题」（不喝九）
- 「他们都在问我同一个问题，说这个工作台我怎么样既能在电脑上用又能在手机上用呢」（大李）
- 变体是拿身边一个人的麻烦当引子：「我姐姐呢是名小学老师前几天在跟我吐槽马上要开家长会了」（森森，五条都这么开）；「前几天我跟我朋友聊《三国演义》，但是他突然问我」（姜学长）；「比如我前几天帮一个商户做了图片」（向行）。
- T018 没用。第一期没有评论可引，第二期起可以用，身边人的例子现在就能用。

**4. 一句反常识的断言当第一句。** 让人停下来。用一次，不能每条都用。
- 「蒸馏就是 AI 时代的合法抢劫」（大李）
- 「其实让一个人觉得一件事很复杂，最好的方法就是把一个简单的东西给复杂化。」（不喝九）
- 「今天我们来聊一个百分之九十九的人都理解或者认知错的问题：AI 真的会记得你吗？」（姜学长）
- 「很多人的理解是，大语言模型就是一个更聪明的搜索引擎，你问它问题，它从某个数据库里找答案，大错特错。」（阿朱）
- T018 没用。

## 二、讲一个东西

**5. 先演一遍，最后才说「这就叫 X」。** 观众先有感受再有名字，名字挂得住。五个人里四个是这个顺序。
- 「它会把你提问和它回答的内容拆成一小块一小块的片段，这些片段就是大家常见的 token」（不喝九）
- 「那么这个工作手册其实就是 Skill，所以 Skill 的定义就非常清晰了」（大李）
- 「这个服务员，我们给它定义为 API。那你就是客户端，也就是发出请求的人」（姜学长）
- 「今天我问你是或者你不能回答我或，这就叫讲人话，大白话。」（向行）
- T018：幻觉、Agent、MCP、Skill 四段是这个顺序。

**6. 名字给全：英文、中文、一句话定义。** 观众之后在别处看到任何一种写法都能对上。
- 「Benchmark 中文叫做基准测试。说白了，就是给一堆标准的测试题目，让 AI 模型去作答、打分。」（姜学长）
- 「大模型其实是一个简称，它的全称实际上是三个词：大、语言、模型。」（大李）
- 「token，中文也叫做词元」（不喝九）
- 「Token（中文名"词元"）」（阿朱）
- T018 有「Token，中文叫词元」「Vibe 是氛围」。

**7. 一个比方只管一个属性，说完就走。** 观众只要认出那个日常物件，不用理解机制。前缀几乎都是「你可以把它理解成／想象成／相当于」。
- 「上下文窗口就相当于一页写满就要扔掉的便签纸」（姜学长，管「写满就丢」）
- 「你可以把 MCP 理解成 AI 连接外部工具的标准协议，有点像 AI 世界里的 USB-C」（阿朱，管「统一接口」）
- 「其实你把 token 想成钱就好了啊」（向行，管「按量计费」）
- 「你只需要把这个故事中所有的工资全部替换成 Token 你就理解了」（大李，管「按次付」）
- 反面：一段里叠两三个比方（向行讲 API 连用钥匙、电线、基站、桥），观众要换几次脑子。T018 初稿一段里门锁加插头，改掉了。

**8. 把 AI 的部件对应到人和分工。** 观众用「管人」的经验去理解「管 AI」，不用学新规则。五个人全用，分法可以不同，一条视频只能用一种。
- 「大模型就是它的大脑，Agent 就是它的手脚，那刚说的 MCP 和 CLI 就是它的工具……如果没有 Agent，那 AI 就是一个植物人。」（大李）
- 「你可以把装了 Skill 的 AI 想象成一个刚入职的聪明员工，脑子好、学习能力强。你给它一个目标，它能自己想办法，但执行层面上会犯各种奇怪的小错误。」（姜学长）
- 「普通 Agent 更像临时工，你给它一个任务它做一次；Workspace Agent 更像岗位助手」（阿朱）
- 「你可以理解成 agent 是你的脑子，MCP 是你的手和脚，有了手和脚它才可以干活，对不对？」（不喝九）
- T018 用了大李的分法，提示词段「交代新同事」，结尾「招了一个老师」。

**9. 例子里带一个具体的细节：原句、数字、名字。** 有细节观众才信这是真事，也才能照抄。
- 「你输入"我想吃香蕉"，在模型眼里它不是一整句话，而是被拆成我、想、吃、香蕉。」（阿朱）
- 「小张你去把店里的十种牛肉干放到一号货架」（大李）
- 「比如说有个“北京”，它可能给的概率是 92%。还有比如说“北平”，它的概率是 4%」（姜学长）
- 「目前大约是每个月二十几块」（不喝九）
- 「我当天晚上下单了这个呃五千元的电脑」（向行）
- 「我会发给它这段提示，是说：哎，请检查这个项目有没有启动本地的版本管理，如果没有，帮我去建立本地的 Git 存档」（FredTalk，把给 AI 的话整句念出来，前面加一个「哎」）
- T018 有「张总确认了预算五十万」「我爱喝可乐」。

**9b. 把数字换成观众能感知的量。** 时间换成分钟，钱换成物价，大小换成一本书。观众不用懂单位就能判断多少算多。
- 「这是什么概念呢？相当于能够去塞进一本长篇小说，比如塞进《三体》的整本书内容」（姜学长）
- 「一台好的服务器约三十万美元相当于北京的半套房」「相当于两个包子的钱就能搞定一条三十秒视频」（森森）
- 「目前大约是每个月二十几块」（不喝九）
- 「大概花了一分四十八秒的时间，然后这里面就生成了一个网页。」（FredTalk）
- 「这一百万的 Token 大概相当于一部三国演义」（大李）
- T018 没有。Token 段可以补一句「一百万 Token 大概一部三国演义，国内的模型几块钱」。

**10. 错的和对的对着念。** 差别让观众自己听出来，不用解释「要具体」。
- 「错误示范是你去跟 AI 说：「改进标题功能。」……那正确示范呢？……「允许用户点击任何标题来生成右侧的新列，从而创建分支变体，同时保留所有之前的列。」」（姜学长）
- 「你让 AI Agent 帮你整理电脑文件，如果没有 Harness，它可能会误删重要文件；如果有 Harness，系统就可以限制它只能访问某个文件夹」（阿朱）
- 「你会对小张说去整理一下货架……那么换一种方式呢小张你去把店里的十种牛肉干放到一号货架这个安排是不是明显的好多了」（大李）
- 「Windows 的逻辑是一个文件只能放在一个文件夹里……但 Mac 是一个文件可以打好几个标签」（不喝九）
- T018 提示词段「帮我总结一下」对「整理成三部分」。

**11. 先说观众以为的，再说「其实不是」。** 观众记住的是落差。
- 「很多人抱怨 Agent 笨，其实不是他笨，是你压根就没告诉他这个项目是怎么运转的。」（姜学长）
- 「很多人把它理解成"更聪明的聊天机器人"，其实不准确。」（阿朱）
- 「那 AI 就是大模型吗？其实答案是不是的。」（大李）
- 「卡通不是假，卡通是一类风格，你没说你要什么风格，今天豆包给你个卡通图，不是他错了，是他没有猜对你的需求」（向行）
- 「其实很多时候不是 Codex 不够，而是你和它的配合方式没有设置好。」（FredTalk，他的固定句式是「问题不在工具，在方法」）
- T018 幻觉段「不是它故意骗你」。

**12. 自问自答。** 替观众把卡住的那句问出来，问句本身就是停顿。五个人全用，密度差别很大。
- 「为什么不能呢？因为他没有手、没有脚」（大李）
- 「Embedding 是什么？简单说就是把文字变成一串数字。为什么要变数字？因为计算机不懂具体的意思，但能比较数字之间的距离。」（阿朱）
- 「那么 128K 的 Token 到底是被谁偷走了呢？第一部分呢，就是系统提示词。」（姜学长）
- 「AI 是怎么去理解我们发的消息的呢？它会把你提问和它回答的内容拆成一小块一小块的片段」（不喝九）
- 度：一段一次。大李几乎每句都问，姜学长每段一两次。

**13. 替观众把反驳说出来。** 内容转难的地方，先用观众的口气把抵触说出来，再接着讲。
- 「这时候就有聪明的小伙伴问了，你说 Agent 里面除了大模型就是 Harness，那为什么我在使用我的 Agent 的时候我从来没有见过任何一个文件或者任何一个设置叫 Harness 呢」（大李）
- 「一听到这里，很多人可能就会想划走了：“完了，要去编程了，这我哪会？”别着急」（姜学长）
- 「那有人就要问了，老师怎么下载呢？」（向行）
- 「但可能有人会说，为什么要学那么多。」（不喝九）
- 变体是先说自己也不信再翻转：「说实话一开始我也觉得很扯 ai 还能帮人聊情商但 eb 真的做到了」（森森）；「听起来是不是很感人？但如果我告诉你，其实它根本就不记得你，你是不是直接懵了？」（姜学长）。
- T018 用了「你肯定遇到过这种情况」，但没有替观众反驳过。

**14. 明说「这个你不用管」，然后必须接一句「你要做的是」。** 减负担，但不能停在「不用管」。
- 「MCP 和 CLI 具体是什么你完全不需要管它，这是那帮天才科学家们去管的事情」→ 接着画图、点产品（大李）
- 「至于具体怎么拆，你根本不用纠结，明白一件事就行：拆出来的小片段就是 Token。」（阿朱）
- 「那注意力到底是个什么东西？别被这个词唬住，其实特别好懂。」（姜学长）
- 「作为新手来说，我们先学这些够用的就行了，之后再看到一个新词或者教程，就知道它说的是什么了」（不喝九）
- 反面：向行「所有 AI 名词」每个词都以「你知道它是一个协议就够了」收，后面没有下文，是她数据最差的一条。
- T018：「这个你不用管它怎么接，以后看到一个软件写着支持 MCP，就知道 Agent 能用它」。

**15. 钉到观众手边的产品。** 抽象的词讲完，立刻说手机里哪个东西就是它。
- 「豆包的大脑就叫 Doubao，只不过是它的拼音；元宝的大脑以前是 DeepSeek，现在是混元」（大李）
- 「带 DeepSeek 这种后缀的都是大模型」（不喝九）
- 「比如说豆包啊，他能记录会议、他能做图、他能做播客……这都属于豆包这个软件的 Skill」（向行）
- 「如果你是做产品、写代码的，我建议 Superpowers。GitHub 上将近 20 万个 Star」（姜学长）
- T018：豆包、DeepSeek、ChatGPT；WorkBuddy、豆包工作、Codex；飞书。

**16. 拿自己做过的事当证据。** 方法从建议变成经验，例子里要有细节。
- 「我自己呢开了八家新疆特产店……我使用 OpenClaw 做了一个知识库」（大李）
- 「举个我自己的例子。我每天都要出短视频封面……现在我封装成了一个 Skill，输入标题和文稿，两分钟自动出封面。」（姜学长）
- 「比如说我建了一个雅思工作台，还有一个产品经理工作台」（不喝九）
- 「在他的劝说下……我当天晚上下单了这个呃五千元的电脑啊，豆包成功说服了我。」（向行）
- 讲失败也算：「我之前的问题在于，我不知道怎么描述这个部分，我每次都是把我写好的提示词一下子喂给它……正确的做法是由局部到整体」（小九，她数据最好的几条都是先讲自己哪里没做成）。
- T018：被编过人名数字、做 IP 的资料放一个文件夹、几十个 Skill 做封面。

**17. 先报「分几块」，每块开头报「第几个」。** 观众知道有多长、走到哪。
- 「我总共分成了三类啊，前面这类会比较适合新手小白，中间呢，后面呢，就会稍微有点难，我们来由浅到深的去讲。」（向行）
- 「所以这期视频给大家解决三个问题第一 Skill 是什么第二 Skill 由什么构成的第三 Skill 是怎么工作的」（大李）
- 「第一个问题，为什么你的工作台打不开了……第二个问题……第三个问题」（不喝九）
- 「它不是一个具体工具，而是围绕模型构建的几类基础设施的总称，核心一共有四层。第一层，记忆层。」（姜学长）
- T018 没有报数。十个词是一条线不是清单，可以不报。

**18. 先承认抽象，再说「我举个例子你就明白了」。** 观众放下戒备。
- 「听着有一些抽象啊我给你举个例子你就明白了」（大李，六条视频都有这句）
- 「听起来会很复杂，但其实你每天都在用它。」（姜学长）
- 「RAG 全称叫检索增强生成，名字听起来复杂，但逻辑超简单：先检索再生成。」（阿朱）
- T018 没用。

**19. 讲完好处泼冷水。** 说清什么时候不该用、有什么坑，观众才信前面不是吹。
- 「好，讲完循环的概念以后，我现在给你泼盆冷水。大部分讲循环的人，其实很多都只夸它好，不告诉你什么时候它是个坑。」（姜学长）
- 「但要知道，AI 的回答只是根据你的话去进行推断，不是一个绝对完整的标准答案」（不喝九）
- 「但 Agent 越强，风险也越明显：它会犯错，会乱改文件，会误删内容」（阿朱）
- 「但它有个大毛病，它是喜欢写流水账、做流水线的工作啊」（向行）
- T018：幻觉「重要信息一定自己核」、Agent「你授权之后」。

## 三、段与段怎么接

**20. 用上一个的缺口开下一个。** 词变成被需要的东西，观众自己往下等。五个人全用，是最稳的接法。
- 「但 Prompt 再厉害，也只能解决"任务怎么说清楚"，它解决不了另一个更致命的问题：模型不知道的东西它就是不知道……于是下一个 AI 热词登场了：RAG。」（阿朱）
- 「到这里，AI 还只是你问一步它答一步。如果你只想告诉它我最后想要什么，然后让它帮我去分解步骤、帮我去执行，这个就是 agent」（不喝九）
- 「那到这里问题又来了，这三个都是 Agent，这三个都可以让你达到目的，我应该学哪一个呢」（大李）
- 「所以问题来了，128K 的窗口，它不是我们真正能够用到的记忆……那我们还能不能好好地玩 AI 了？」（姜学长）
- T018：Agent、MCP、Skill 段开头都是这个，你录前又补了三处。

**21. 「好，讲完了 X，再来讲 Y」的宣布式过渡。** 直白，不绕。
- 「OK，那讲完了 API 是什么，我们再来聊一聊 API 到底能够做什么。」（姜学长）
- 「好第一趴我们先讲 Skill 是什么」「好，接下来我们来看一下一个 Skill 的示例」（大李）
- 「那第二个呢，就是我们会用到国内比较口语化一点的 AI」（向行）
- 「然后再说一下 Mac 的复制粘贴和剪切」（不喝九）

## 五、口气

**29. 对观众一律「你」，一句里可以连着几个。** 五个人全是。阿朱「我」最少，向行「我」最多，数据都好，说明「你」是必须的，「我」是可选的。

## 六、数据好和数据差的区别

只写在两个以上账号都能看到的。看不出区别的也写，免得误用。

**看得出：**
1. **开头能单独成立，不靠上一集。** 大李三个系列首集全好（3.0 到 3.4 倍），后续「上集我们讲到」开头的全在 0.5 倍以下；姜学长开头不打招呼、第一句就把观众放进句子的三条，全在他前八名。
2. **结尾有能照着做的清单或动作，不是一句世界观。** 姜学长高组 7 条里 6 条是清单，低组多收在「命令行等了四十年」这种句子上；向行三条纯感悟全在最低档；不喝九「AI 焦虑」讲三个道理没有操作，0.3 倍。
3. **替观众做了选择，不是把选择还给观众。** 向行高组五条结尾都是「我推荐前两种」「只用两款」，低组结尾是「你可以略过」「你自己测」；不喝九「要不要花钱」那条几乎每句「可能」「大概」「不一定」，0.1 倍。
4. **讲「你怎么做」，不是「我用了什么感觉」。** 不喝九同题两条，「你就截图发给它」那条 20.7 倍，「我发现它也可以连接手机」的体验记 0.3 倍。
5. **转述论文、报告、数字的视频数据差。** 姜学长低组里五篇论文、用户研究、OCR 都是「文章提到」「研究显示」，同一位置在高组放的是生活比方。
6. **第一句是一个已经发生的状态，不是「今天我要做什么」。** 小九数据最好的五条第一句是「我真的太震惊了」「半个月赚了两千多块钱」，最差的两条是「今天是我学习 AI 的第三天，然后我现在就是一天分两个视频发布」。
7. **每一项都落「适合谁」，比只演示操作数据好。** FredTalk 讲六个 Skill 的两条，按「解决什么、举场景、适合谁」讲的那条是他全账号最高，换成「我先让它安装好，你可以看到」的那条 0.6 倍。

**要诚实说的：** FredTalk 有两条几乎逐字相同的 AGENTS.md 视频，数据差了近六倍；屯点 10 条高低两端说法一样。表达不是唯一变量，选题和时机也在起作用。上面七条是「同一个人、同一套讲法」时能看出的差别，不是保证。

**看不出：** 有没有比方、比方多少；开口是问句还是断言；口头禅；自问自答的密度；有没有社群引导；说不说自己；有没有点产品（森森数据最好的一条反而是唯一不点产品、全靠自造比方的）。这几样高低两组都有，不能拿来解释数据。

## 七、各人独有的招
