# 完整案例 few-shot 库

本文件是运行时必读真源，不是历史归档。12 组完整提示词用于学习具体空间关系；`assets/examples/` 原有 8 张完整成品与 `assets/examples/科技姐聊AI/` 的 25 张完整成品，用于校准标题体量、画面密度、人物互动和整体审美。提示词与成品不要求按编号一一对应。

用户指定「科技姐聊 AI」「科技姐 VI」时，先读取 [科技姐聊 AI：完整案例与五种构图](科技姐聊AI.md)，按其中的原图索引查看完整案例。该参考库包含银白近景操作、俯视全身、微缩搭建、纸面揭起、跨出画框五种结构，原有案例继续用于其他风格。含原作者的图只用于观察和文字转译，不与用户人脸同时输入生图。

每个新方向必须先选 1 个主要案例作为构图锚点，再按 `case-rewrite-policy.md` 改写。重点学习：

- 人物在哪里，手、眼神和身体朝向哪里
- 主视觉多大，正在发生什么
- 标题怎样分级，与人物或道具怎样遮挡
- 前景、中景、后景分别是什么

案例中的旧文案、商标、账号、他人身份和无关装饰不得继承。风格文件负责材质和禁止项；案例负责具体空间结构；用户文案、真实证据和身份规则是硬约束。

以下案例应完整读取，不能只摘几个关键词。

12 组完整示例提示词。用途：生成新提示词前，找同风格或构图最接近的示例做 few-shot 参照，学它的**具体程度**——姿势写到手在哪、道具写到上面有什么内容、空间关系写清楚谁遮挡谁。
