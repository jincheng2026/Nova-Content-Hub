如果你刚刚安装好 Codex，但是不知道 Codex 能做什么，我们先不写代码，或者做项目，今天我就给你分享几个所有小白都可以用 Codex 做的事情，让 Codex 成为你最强的个人助理。

第一件事情，就是清理电脑空间。不知道有没有人跟我一样，就电脑经常没有空间，然后最后发现大半都被这种系统文件、微信聊天记录，或者安装包，以及其他应用的这种很多垃圾文件占据。而这个时候，你要么去买一些外置移动硬盘，但像现在移动硬盘的价格，比去年已经涨了差不多一点五倍；要么就是你只能自己去搜索看哪些文件可以删除。而 Codex 这个时候价值就来了，可以用 Codex 去找电脑里面的垃圾文件，然后去评估它删除的风险，比如说一些重复下载的安装包，或者很久没有打开的大视频，或者已经压缩过的这种临时包，你可以让他去评估，最后标成这种低风险的去优先选。你可以发给 Codex 这段提示词，本质上就是让他去全局进行搜索，然后找出一些文件。我们可以看一下案例，比如说我发给他这段提示词之后，他能够花二十分钟的时间，把我整机的内容都给我读出来，然后给到我一些删除的建议，比如说你让我删除哪些，他可以给到我一些优先级选择，这我觉得完全就可以去替代电脑的清理助手，对吧？

第二件事情，就是让 Codex 整理文件。不知道有多少人跟我一样没有收纳习惯，很多时候文件简直就是乱七八糟，所有的文件都堆在一起，这种截图、表格都堆在桌面。你可以发给 Codex 这段提示词啊，然后可以让他去扫描桌面的路径，然后去帮你做一些归类。比如说我发给他之后，让他去扫描整个桌面的内容，然后他就能够很快地给到我一个桌面整理的对应方案，包括怎么样去整理，然后整理完之后呢，还要留下一个移动记录，方便以后去做回溯。

第三件事情，就是让 Codex 去批量修改文件的名称。有些打工人可能收集了三百个人的收集表，但是每个文件的名字都完全不一样，这个时候如果自己要手动去修改文件名称，就要花非常多的时间，而现在 Codex 就可以自动去处理。这个时候你可以发给 Codex 这段提示词，比如说基于这种命名规则，然后去帮我批量处理。我们可以看一下，这里我这边有三个不同的这种文件，但内容都是一样，但它的文件名不一样，所以说我就给他发了对应的这段提示词之后，然后他就能够快速地梳理一个计划，然后把它完成。你可以看到它预览的这个名称，就是命名规则：原部门加姓名加员工编号，然后他就快速梳理出来了。我们可以看一下整个的效果，它就确实完全按照刚刚那个逻辑去进行梳理，然后把整个文件夹重新打包，重新梳理每个文件的名称，我觉得这个对于打工人而言，简直就是神器，好吧。

第四件事情，就是让 Codex 去转换文件的类别。你是不是还在花大价钱去买一些转写的会员，或者 WPS 的会员？现在通过 Codex，就可以帮你免费进行处理。这里呢，我们给他发一个很简单的提示词，然后可以看一下效果。比如说我这里有三个不同的文件，包括 PDF、PPT、Word 和 Excel，这里不是随便去改后缀，而是 Codex 先判断文件真正属于什么类别，然后基于你的需求去评估，比如说你可以看到它这里生成的这个 Excel 还是非常不错的，然后它去判断用什么模型或者脚本去进行处理，然后给到你一个很完整的最终转换结果。当然最后呢，也要提醒大家注意安全和确认问题，尤其是当 Codex 要动你的文件的时候，需要先跟你确认方案，然后再最终执行。
