# 搜索和筛选

## 记录搜索计划

每次搜索都保存：

- 研究问题。
- 平台和内容类型。
- 关键词组及扩展理由。
- 排序方式。
- 首选时间范围和实际时间范围。
- 每页数量、计划页数、最高请求数。
- 去重键。
- 合格条件和停止条件。

## 扩关键词

从用户原词出发，只增加与研究问题有关的词：

1. 产品名和常见别名。
2. 具体功能。
3. 用户正在解决的问题。
4. 想得到的结果。
5. 目标人群和使用场景。
6. 同类产品或替代做法。

每个扩展词保留来源和理由。不要为了增加样本量加入宽泛热词。

## 抖音 AI 教程默认门槛

先按硬门槛判断，再排序：

```text
platform == douyin
100 <= follower_count <= 20000
digg_count >= 1000
relevance == direct
```

最近 90 天只决定优先级，不降低粉丝、点赞或相关性门槛。

把未合格样本分开保存：

- `anomaly_low_followers`：少于 100 粉，可观察但不并入默认样本。
- `regular_viral_reference`：超过 20,000 粉，可作普通爆款参考。
- `unverified_low_likes`：少于 1,000 赞，不叫已验证爆款。
- `adjacent`：相邻主题，只用于扩展理解。
- `off_topic`：无直接关系，排除。
- `missing_evidence`：缺少粉丝、点赞、来源或相关性证据。

不要降低门槛补齐「10 条」。只有 3 条合格，就直接报告 3 条；0 条时直接报告 0 条。说明已经扩过哪些关键词、排序和时间，不降低门槛，也不要求用户确认这个数量或重新选择样本。

## 相关性判断

每条内容必须有一个相关性标签和一句证据理由：

- `direct`：内容主体直接解决当前研究问题。
- `adjacent`：与人群或场景相关，但主体不是当前问题。
- `off_topic`：只有词面碰巧出现，或主题无关。
- `unknown`：现有标题、正文或字幕不足以判断。

只有 `direct` 能进入默认低粉爆款集合。AI 根据现有内容完成语义判断和筛选，并写出一句可核对的理由；用户可以在结果交付后改判，改判记录为用户确认，不在执行中设置确认门。

## 去重和快照

- 首选平台内容 ID 作为去重键。
- 没有 ID 时，使用规范化来源 URL；仍没有时标为证据不足。
- 同一内容多次出现时保留每次快照，不静默覆盖。
- 输出代表记录时说明使用最新快照还是首次快照。
- 当前粉丝数是采集时快照，不推断发布时粉丝数。

## 排序

只在合格样本中使用透明排序，例如：

1. 点赞数。
2. 收藏数。
3. 分享数。
4. 评论数。

需要计算赞粉比时同时展示原始点赞和粉丝数，不单独用比值证明爆款。分母太小的异常样本不得混入正常排序。

完整研究需要继续深挖时，在合格样本内部先按最近 90 天优先，再结合直接相关性和点赞、收藏、分享等透明指标自动选择最多 3 条。报告中说明选择依据，不让用户先回复「选哪条」才继续。

## 跨平台边界

不同平台的粉丝、播放、点赞、收藏和评论口径不同。没有经过用户确认和真实样本验证，不把抖音门槛直接套到其他平台，也不把不同平台指标放在同一坐标轴比较。
