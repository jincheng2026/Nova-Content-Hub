# 风格六：海报拼贴风

把资料、图谱或成果组织成一个中心内容世界，人物和背景资料只做辅助。拼贴感来自材质与遮挡，不来自四处散落卡片。

## 视觉特征
- 前景：一个中心内容主体或成果，占 35%～50%，带景深或投影
- 辅助信息：只保留一条纵向信息带或一个整合面板，占 15%～20%
- 人物：位于场景边缘，半身可见高度占画布 35%～45%、宽度占 28%～40%
- 后景：最多 2 张低对比资料，丰富但不形成新焦点
- 字体：压在层次之间，白色或描边效果
- 背景：深色，衬托各层次

## 固定
- 画幅：3:4 竖版
- 人物：参考图1
- 建议至少提供一张额外素材（图2）
- 默认只有标题组、中心内容组、人物组，最多增加 1 个辅助信息组
- 内容主体和证据共同占 60%～80%，人物可见高度默认占 35%～45%
- 禁止在画面四周分别散落独立卡片
- 保留 15%～25% 的安静区域
- 关键元素距四边至少留约10%边距

## 变量
- 各元素在前/中/后景的位置
- 叠加方式
- 大字
- 背景色调
- 字体风格

## 权威资料变体

当内容依赖专家、论文、研究图谱或原始资料时：

- 前景只放一个权威锚点：专家人像、论文标题或机构标识
- 中景放 1 张知识图谱、研究流程或核心资料截图
- 辅助证据合并为一条资料带，不拆成多个悬浮窗口
- 后景最多放 2 张低对比原始资料，不要求缩略图可读
- 人物位于下方指向权威锚点，体量小于资料主视觉
- 标题先讲研究对象，再讲教程结果；不要同时堆满专家名、论文名和所有结论

## 提示词模板

```
3:4 竖版构图。

前景：[最大的内容主体/成果/角色/产品]，占画面约[30%-45%]，
[外观、内容、动作和它如何解释选题]，带轻微投影和浮动感。
辅助信息区：把[步骤/结果/资料/图标]合并为一条[纵向信息带/横向流程带/整合面板]，
位于[位置]，占画面约[15%-20%]，内部样式统一，缩小后仍被看成一个组块。
后景：最多 2 张低对比背景资料，轻微模糊，只作为纸张或屏幕质感，
中心主体、辅助信息带和背景资料之间有前后遮挡关系，制造层次和纵深。

参考图1的[性别]五官特征，保持五官一致性，只要半身。
人物位于[左下/右下/场景边缘]，半身可见高度占画布约[35%-45%]、宽度占[28%-40%]，
[轻松微笑/好奇发现/笃定讲解/轻微惊讶/揭秘噤声]，
[具体手势]指向内容主体，人物只做主持人、发现者或引导者。

巨大的中文大字"[封面标题]"，[字体风格]，[颜色效果，建议白色描边或纯白]，
压在内容主体和证据层之间，与多个层次形成遮挡关系，

背景：[深色沉稳色调，衬托各层次]

画面默认只有标题组、中心内容组、人物组，最多增加 1 个辅助信息组；
内容主体和证据占 60%-80%，人物可见高度占 35%-45%，保留 15%-25% 安静区；
所有关键元素距画面四边至少保留约10%边距，丰富但成组。
```
