# 参考视频拆解

先核对原片或实际可读链接、可靠逐字稿与已有分析；拿不到视频时只做文字分析，不能假称看过画面。已有拆解直接复用并补关键缺口。评论仅在当前请求明确允许时使用。

逐段按意思分段，问：观众在问什么；作者要解决什么；这一段的作用与前后怎样接；信任来自什么原话/演示；碰到什么明确想要或担心；怎么讲；画面实际是什么；观众拿到了什么。再补作者的取舍、证据边界和下一条可用做法。每条判断带原话、真实画面时间或评论cid及具体用途；空泛信息密度/节奏紧凑不足以构成判断。

接着看开头、正文、结尾分别回答什么，怎样承接；最后整体看对象、承诺、证明、内容顺序、主动没讲什么、情绪与信任的真实变化。主参考逐条完整分析，辅助参考可只说明差异。多条按同一问题对齐，先后顺序不证明借鉴关系。

用户先拆：AI独立分析先保存为任务候选，不在其完成前展示；收到用户完成信号后读真实提交，分一样的、只有用户看到的、只有AI看到的。主要请用户批后者，编号并附证据；等待其真实反馈后逐条响应。只提反馈/方法调整候选，不自动改Skill或长期判断库。

自检：抽取判断能回到原句或实际时间；数据只描述相关；不预测完播率、不打总分、不用语速/停顿数代替情绪判断；删除对下一条创作无帮助的空话。画面采样精度和覆盖据实说明，不用固定每秒帧数冒充已看完。

完成：一句话价值、逐段、开头/正文/结尾、整体与可借/不可照搬清单齐全；列明主辅参考、事实/推测/未知、缺口和可直接交创作的信息。不替作者定自己的叙事、标题、封面或正文。
