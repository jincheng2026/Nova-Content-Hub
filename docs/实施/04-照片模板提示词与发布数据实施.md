# 照片、模板、提示词与发布数据实施

日期：2026-10-17。状态：本单元代码已合入，主线程集成验证通过；界面、真实生成与发行尚未验收。

## 本轮交付范围

- 共享不可变资产：用户明确选择的本人照片、资料、模板样张、生成图片按实际 SHA256 存储，同字节不重复复制。
- 照片对象独立于资产 hash，保存本人照声明、名称、原文件名和软删除状态；样张人物不作为用户身份。
- 模板组有稳定 ID 与不可变版本包，原始定义和资源映射分开，实际读取通过 hash；PNG 风格与 SVG 结构分开。
- 提示词真实 Markdown 与元信息、软删除恢复；新增面向创作者的 26 条原创内置提示词，旧用户内容由后续迁移保留。
- 内容资料关联、候选登记与显式选封面；候选必须带来源 request/attempt，不自动成为已验收或已选封面。
- 内容内多渠道发布计划；人工登记发布时冻结正文原字节、标题、封面和模板版本，后续编辑不改变历史。

## 核心复用与存储

仅扩展内部有限对象定义 content/prompt/photo/template；同一锁、事务捕获/独占安装、恢复和归档实现继续共用，不向页面暴露任意文件写入。

```text
内容/<uuid>/内容.json + 正文.md
内容/<uuid>/发布快照/<publicationId>/快照.json + 正文.md
提示词/<uuid>/提示词.json + 正文.md
我的照片/<uuid>/照片.json
模板/<id>/模板.json
模板/<id>/版本/<version>/定义.json
资产/sha256/<前2位>/<完整hash>
```

资产与不可变版本/快照包先完整安装，所属对象引用最后通过事务提交。因此提交前失败可以留下未引用文件，不能留下已成功记录指向半个文件。首版不自动清理这些文件，以免误删历史、回收站或发布引用。

新模板包先安装但 metadata 未提交的中断，必须能区分严格标记的未登记包与损坏对象；列表不将未登记包当成可用模板，也不把普通损坏目录悄悄略过。

## 版本与升级

库格式升为 schema 3；内容与事务记录格式独立演进，旧记录和历史字节继续可读取。显式升级先备份根描述文件，先建立旧 v2 拒写屏障，最后发布新描述文件；中断可续行，不部署通用迁移平台。

普通打开不静默升级，较旧程序拒绝写入新库。描述文件备份不能作为整库备份或安全降级方式。

## 内置资源安装

由 `library-seed/` 受控安装器处理应用自带资源，不接收 renderer 任意来源路径。先预检全部资源，再逐组安装：

- 15 个模板组、30 张实际 PNG，实际字节须符合既有生成清单 hash。
- SVG 仅作为结构说明，不混入真实样张数或当作任意网页执行。
- 原定义中的 v3 源图、v4 模板、accepted:false、aiTested:false 均保持，不伪造验证。
- 26 条原创创作者提示词按 builtinKey 去重；不覆盖用户编辑，不复活已删除条目。两个初始化进程竞争同 key 时由核心在锁内阻止重复。
- 模板同 ID/版本/包内容可重入，不同内容冲突。中断后继续缺失项，不宣称全库一次原子安装。

图片字节、类型、哈希校验与真正解码、生图质量是不同层级。当前阶段若未解码必须明确 decoded:false；后续桌面和 CLI 使用同一真实解码能力。
