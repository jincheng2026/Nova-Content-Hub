个人知识库一定要放本地，一定要放本地，一定要放本地。不要放到云端去，一定乖乖听我的，放到本地。

前期视频我跟大家教了如何使用一篇提示词让 WorkBuddy 帮你建好你自己的个人知识库。很多粉丝都已经用上了，并且评价非常的好。这篇提示词和使用教程我已经放到我的知识库里面了，粉丝朋友们在粉丝群里面可以免费的拿去用。

那我就收到了好几个一模一样的问题，他们问：知识库可不可以使用 WorkBuddy 加 ima 的形式去用呢？可以，当然是可以的，但是我非常的不建议这样去用。

我的建议就是，个人知识库一定要放在你的本地电脑上，一定一定要放本地。知识库放本地的这三个好处是 ima 完全给不了你的。

第一个大好处，就是你的知识库在本地，你的 Agent 是完全可控的，它可以完全访问你的这个知识库。在新建知识库的一篇教程里面，第一步就要建立一个在你电脑上的文件夹，对吗？你所有的知识库都在那个文件夹里，那你只需要让 Agent 去访问你这个文件夹，那整个文件夹里面的知识内容，它就完完全全可以自主的访问和调用。

如果你把它放到 ima，那么 Agent 就只能通过 API 或者是 MCP 去访问这个 ima 的知识库，要求知识库给他一些数据。那么知识库给他什么数据，完全取决于 ima 自己。ima 是如何分析你给它的知识的、如何切片的、如何检索的、如何召回的，你的 Agent 完全没有控制力，完全仰仗于 ima 给他什么数据他就用什么数据，那这是完全不可控的。ima 的质量怎么样你完全不可控，你也不可能对它做任何的微调，根据你的需求进行相应的设置都不可能。

尤其是有一些朋友跟我说，它是工程类的知识库、法律类的知识库，这些相对于比较专业的知识库，一定要是自己写自己的规则才是最好用的。放到 ima 去，你这些东西是完全不可控的，那么回答的质量就会差很多。

第二个最大的优点是方便备份和迁移。有很多朋友跟我说，我在自己家电脑上面有一个知识库，这个知识库我想在单位电脑上也要用的，怎么办呢？很简单，如果你在本地，那你就把这个文件夹拿个 U 盘装过去就可以了，或者自己给自己发个邮件就可以了。如果你的知识库是在 ima 云端的，你想备份或者下载整个知识库，那可不是一件容易的事情。

第三，如果你的知识库在本地，你完全熟悉了如何使用和打造你的知识库，我还是非常建议你去升级使用 Obsidian。这是一个完全免费的、目前做个人知识库最牛的一个软件。但是我之前也说过，它的门槛有点高，不太适合新手。新手直接上来就用 Obsidian 的话，大概率也是要被劝退的。

所以我给大家建议的一个路线就是：你先使用 WorkBuddy，用我给你的那个建立知识库的提示词先把你的知识库给打造出来，用起来，用熟练之后，你的知识库已经有很多的知识内容了，你也写好了规则了，这个时候你可以丝滑的转向去使用 Obsidian。但是如果这个时候你的知识库全部在 ima 云端，你是不可能去使用 Obsidian 的，Obsidian 没办法访问。

综上所述呢，知识库一定要放在本地，放在本地。还没有开始建知识库的朋友们，到粉丝群里面去拿我给大家的免费的提示词去用起来，完全掌握了以后去转向使用 Obsidian。具体 Obsidian 怎么用，回头我再给大家做视频。
