# 风格十二：漫画冲突风

把两个明确对象或两股力量设计成一张完整漫画对战海报。红蓝对半和 `VS` 不是风格本身，角色、线条、字效和节奏必须属于同一漫画体系。

## 视觉身份

- 视觉载体：美式网点漫画、扁平对战海报或像素游戏对战页，三选一
- 构图主依据：`examples.md` 中双阵营或强冲突关系最接近的完整案例
- 材质辅助：`CC-01`，只学习漫画语言，不继承遮挡后的空洞构图
- 绝对主角：两个阵营之间的冲突轴
- 人物任务：裁判、挑战者或观众；不是必然站在正中央

## 适合

- 两个产品、模型、方案或版本比较
- 人工与 AI、速度与质量、效率与注意力等明确张力

## 视觉命题模板

```text
[对象A]从[方向]施加[动作]，
[对象B]从[另一方向]形成[反作用]，
两者在[中央冲突轴]相撞。
```

## 漫画体系

### A. 美式网点

- 粗黑轮廓、半调网点、放射线、硬边阴影
- 高饱和红蓝、黄黑或橙青
- 适合角色或强对抗

### B. 扁平对战海报

- 大色块、统一图标、中央闪电切割
- 不使用复杂网点和写实 3D
- 适合产品 Logo 或概念比较

### C. 像素游戏对战

- 像素角色、状态条、关卡字效
- 全图统一像素精度
- 只在内容适合游戏化时使用

一张图只选一种体系。

## 标题几何

- 两个对象名称分别归属两侧
- 中央冲突词、问号或结论是最大字效
- 主文案过长时，冲突句做主锤，其他信息降为顶部引题和底部标签
- 字效使用硬边描线，不使用柔光霓虹

## 人物规则

- 裁判可见高度 40%～48%，但不遮挡双方名称和中央冲突轴
- 挑战者位于一侧时，另一侧必须有体量相当的产品或角色
- 人物服装只保留少量裁判识别元素，不生成廉价整套角色扮演服

## 硬禁止

- 红蓝各占一半后只放一个巨大 `VS`
- 混用写实电影、玻璃 UI、纸媒和漫画
- 双方视觉重量严重失衡
- 无真实比较关系时硬造胜负
- 三个以上主要阵营
- 大量爆炸框、速度线和小标签同时争抢

## 提示词骨架

```text
3:4 竖版[美式网点／扁平对战／像素游戏]漫画海报。

视觉命题：[一句双方动作和冲突]。

左侧[对象A]使用[颜色与造型]，执行[动作]；
右侧[对象B]使用[颜色与造型]，执行[反向动作]；
中央以[闪电／碰撞点／撕裂线]形成唯一冲突轴。

标题“[指定文案及分级]”中，
[冲突词／问句]采用最大漫画字效，
双方名称分别属于各自阵营。

全图只采用一种漫画体系。
参考图1的用户人物作为[裁判／挑战者／观众]，位于[位置]，
可见高度约[40%-48%]，执行一个清楚动作，
双手、视线和身体方向分别响应两个阵营；
人物、冲突轴和标题在同一次构图中形成完整漫画节奏。
```
