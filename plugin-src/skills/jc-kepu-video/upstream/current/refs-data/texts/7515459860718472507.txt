Hello，大家好。今天我们来聊一个真正让模型变得更靠谱、更真实、更具有来源意识的框架，叫作 RAG，Retrieval-Augmented Generation，中文名呢叫作检索增强生成。

这个技术到底有多重要？我先跟你讲一个真实的例子。

前几天我跟我朋友聊《三国演义》，但是他突然问我，关羽过五关斩六将，到底斩的是哪六将，过的是哪五关？我一听，笑了，这还不简单？第一关就是去过荥阳关，去杀太守王植，然后过东岭关去杀卞喜，然后是孔秀，好像是汜水关的。

我当时讲得头头是道，而且还特别强调，我小时候可是看了五遍的《三国演义》全书。但他不信，当场拿着手机查了一下，结果啪啪打我脸。我不光是把顺序搞错了，我还把两个将领的名字给记反了。

所以你看，我这个回答其实犯了两个经典的问题。第一个呢，就是没有来源依据，全是拍脑袋的回答。第二个呢，信息已经过时，我是通过我以前的记忆去说的，其实早就已经不记得了。

你们看到这两个问题，是不是好像有点眼熟？没错，它就是跟我们要讲的大模型的两个经典问题一模一样。第一个呢，就是幻觉，大模型容易瞎编；第二个呢，就是知识老旧，大模型使用以前的记忆，可能根本就不可信。

所以你问大模型这个问题，它可能也会特别自信地去回答，关羽第一关斩的是董卓的部下华雄，然后是某某某某某。你看，是不是比我回答得还更不靠谱？

所以怎么能够去让我们的大模型回答得更准、更有出处、更加可信呢？这就要说到我们主角 RAG 的本质，其实就是让大模型先去检索、先去查，然后再告诉我们答案。

我们把 RAG 这三个词拆开，Retrieval、Augmented 我们先不管，我们先看 Generation，它其实就是生成。生成呢，就是大模型的原始能力。我们去提供问题，大模型基于它之前训练的数据得到的知识，然后去给我们生成答案。

但问题来了，这些回答完全是基于模型的参数和它的训练数据。它不一定能够去告诉你信息的来源，而且它训练的数据是有一个期限的。比如 GPT-3.5，它的知识可能就停留在 2021 年，而且它可能会编造出一套看起来很真实的内容。

那 RAG 是怎么改进呢？其实它的核心很简单，就是在生成之前先让模型去查资料。这个资料或者知识库呢，可能是一个文档的集合，可能是企业内部的文件，也可能是一个 API，甚至是联网搜索的结果。

换句话说呢，它不是去凭空生成回答，而是先去检索：「我找到一个可靠信息了，我再基于这个可靠信息去给你回答。」就像什么呢？就好像你去回答问题之前先去看了百科全书，检索完以后，然后你再去回答这个问题。

那么为什么 RAG 能够去解决当前大模型的硬伤呢？它主要分成两个方面。

第一个呢，就是它的信息能更新。当世界发生变化的时候，比如 NASA 发现了两颗卫星，那这个时候呢，你不需要再去重新训练模型，而只需要去更新你的数据库。模型下次查的时候，就能够去查到最新的数据。

第二个呢，就是模型回答的信息是有出处的。因为现在通过 RAG 以后，模型的回答是建立在检索基础上的。那这样的话，其实模型就能够把检索的内容和它的回答一并去输出，看起来就会可信很多，对不对？这大大降低了幻觉的风险，也减少了编故事的概率。

它的具体工作流其实很简单。用户提供一个 Prompt 去问问题，然后同时呢，我们是有一个数据库的，模型从数据库里面去找答案。然后基于数据库得到的答案和用户输入的 Prompt 问题，最终一并得到一个输出给到用户。

这个时候呢，给到模型的最终 Prompt 也不一样。它包含了系统的指令、用户的问题、检索的信息，最终去生成这个答案。这样其实就构成了一个知识有来源、信息有更新、逻辑有支撑的大模型问答系统。

但我还是要去强调一下，RAG 它不是一个装好就能用的插件工具。它还有两个点需要去做优化。

第一个呢，就是你的 Retrieval 的检索质量。如果你的知识库本身就很烂，更新得很慢，那其实模型查到的这个信息也是老旧的或者是错误的。这个时候，它要么就是答不出来，要么也就只能去编。所以你的知识库一定要有质量，要跟上时代。

第二呢，就是生成策略要能够去理解上下文。模型不能只是去看材料，它需要知道怎么去合理引用，怎么去把它组装起来去进行回答。所以 RAG 的关键，其实就是 Retrieval、检索和 Generation 这两个点都要硬。

你可以这么理解，普通的大语言模型呢，其实就是闭门作答；而基于 RAG 加持的大语言模型呢，其实就是先去检索，再去找答案，相当于开卷考试。

这不仅能够去让模型变得更真实、更可靠，也能够让我们去建立可控的企业级问答系统。比如法律的合规问答，这个是不能瞎说的；医疗的知识助手呢，这种是不能出错的；客服系统呢，它是需要去引用产品文档的。这些都离不开 RAG。

所以在我的观点下，RAG 它并不仅仅是一个技术术语，或者说是一个技术。它代表的是大模型向真实世界靠拢的一个转折点。RAG 让 AI 学会先去看数据，然后再去引用证据，然后再去组织语言，最后给我们回答。这就是 RAG 带来的真正价值。
