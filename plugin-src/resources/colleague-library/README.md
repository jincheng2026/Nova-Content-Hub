全部 111 张 JPEG、16 张 WebP 原字节保留，没有缩略图替代、压缩、转码或去 EXIF。五份完整 `VI拆解.md`、三份 `风格.json`、26 个提示词原文件与两份提示词格式/分类说明同样保留原字节，共 163 个来源文件，29,537,997 字节。`catalog.json.files` 逐一记录相对来源路径、长度、SHA256。图片中的公开作者身份只用于记录出处和理解风格，不进入用户本人照库。

完整来源拆解存入模板的 `designNotes` 和 `rules`，并作为 `structure` 资产绑定不可变模板包。127 张原图全部作为 `style` 资产，沿用既有模板/请求契约。保留来源研究中不同版式分支；生成规则明确本次本人照是唯一身份依据，无照片按无人版处理，旧字标、姓名、内容、数据和事实不继承。

`templates/<stable-builtin-ID>/visual-identity.md` 是五份 VI 的产品路径副本；有原始风格 JSON 的三组另有 `style.json`。`templates/index.json` 将稳定模板 ID、来源路径与 SHA256、规范副本路径与 SHA256，以及每张 K 图的原名与 SHA256 对齐。`sources/` 仍是来源证据；规范副本正文与来源逐字节相同，不是新规则、新版本或新模板包。运行时从固定请求的模板版本与 `packageHash` 读取定义和 `structure` 资产，历史请求不会转读当前索引或最新版本。来源 VI 中的历史 QZ 编号没有与交付 K 图的一一映射证据，不按排序猜配对。

`validation.kind:source-verified-design` 表示来源文件和规则对应关系经过校验；`accepted:false`、`aiTested:false` 保持真实。它不产生模板学习任务、还原产物或人工验收记录。原研究提到的秋芝 90 张、鹿一家 32 张等历史范围超出实际交付的 30 张；报告原文保留，但没有把未交付图片或旧本机链接冒充随包资源。

提示词保存来源 front matter 后的完整正文，首尾空行、段落和最终换行均保留；标题、分类、处境、说明、标签和原始出处进入目录元数据。仅比较正文做去重，比较时忽略行尾格式差异及首尾空白，不改写存储正文。同名不同文不会合并。26 条来源正文彼此不同，也与原 26 条项目原创提示词不同。

重现及与授权来源逐字节核对：

```sh
node plugin-src/scripts/import-colleague-resources.mjs '<交接包的内容工作台目录>'
node plugin-src/scripts/import-colleague-resources.mjs '<交接包的内容工作台目录>' --check
node --test plugin-src/src/lib/library-seed/test/seed.test.mjs
```

`--check` 不写文件；同时核对 163 个来源文件、五份 VI 和三份风格 JSON 的规范副本及独立索引，不执行来源的程序、提示词或代理指令。生成脚本对五组和 26 个提示词来源文件的交付数量做断言，来源变化时先核对再更新清单。

安装与已安装库升级规则见 `../../src/lib/library-seed/README.md`；本目录没有直接修改用户库、宿主缓存或安装程序。
