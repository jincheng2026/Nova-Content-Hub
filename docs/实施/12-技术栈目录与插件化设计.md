## 源码归属

```text
workbench/                       桌面应用
  src/main/                      窗口、IPC、绑定、系统选择器、工作进程
  src/preload/                   有限业务桥；单独编译CJS
  src/renderer/                  React页面、组件、样式
  src/shared/                    IPC合同与有限业务投影类型
  scripts/                       构建、独立产物与真实Electron探针
  test/
plugin-src/                      插件唯一源码
  src/cli.mjs                    contract/cover/hook/doctor分派
  src/content.mjs                不可执行契约与配套配置校验
  src/commands/                  真实cover执行命令
  src/bridge/                    有限交接及Codex/WorkBuddy纯适配
  skills/                        Skill原文与所需references
  references/
  scripts/                       插件构建与依赖一致性检查
file-library/                    唯一CRUD/事务/任务/历史实现
browser-import/                  旧浏览器备份维护迁移
image-validation/                共享完整图片解码
library-maintenance/             备份、核验、恢复入口
library-seed/                    内置图片与提示词安装
builtin-templates/ builtin-prompts/  原创可分发内置资源
schemas/                        对外协议
原型/                           既有浏览器原型，独立保留验证
docs/ assets/ verification/ scripts/
```

没有职责实现时不先建空目录。共享核心的现有目录先保留，不同时进行全库`packages/*`搬迁；根README说明入口。`dist-*`
均为生成物，不作为修改源，历史验证日志保留当时路径。

原生TS从`workbench/src`编译到独立产物的`workbench/dist`，保留main/preload/shared层级；Vite输出`workbench/dist/renderer`
。main/worker在源码和产物都能用`../../../file-library`定位相邻核心。preload只保留允许的Electron require，合同仅type
import；不把sharp或文件核心打进Vite。生产页面按构建清单精确提供hashed资源，无开发服务器或宽泛本机路径回退。

## 插件与桌面之间的调用方向

React → 有限preload → main核验任务/绑定/权益/配套插件 → 插件纯逻辑生成有限LaunchPlan → main受限系统启动口 → 宿主Skill →
唯一插件CLI → 文件核心。

- Skill、命令、宿主路由、payload编码/长度限制、事件表、配对规则归插件源码。bridge不导入Electron/fs/child_process，不读取会话、不启动程序。
- main负责系统协议发现、已选目录、宿主安装事实和实际打开；不接受renderer任意URL，不从安装目录动态加载JS。后续Claude等宿主只增加受审的静态adapter与能力说明。
- 已打开、已预填、用户已发送、插件接单、生成与入库分别记录。Hooks和文件出现都不直接完成业务任务。
- `plugin-src/src/content.mjs`保留不可执行浏览器契约；真实执行归`plugin-src/src/commands/cover.mjs`。唯一CLI用`contract …`
  与`cover …`明确区分；旧`cover-runtime/cli.mjs`只转发，不按参数猜两种context语义，也不把旧浏览器请求自动变成可执行任务。
- 真实执行Skill迁入同一`plugin-src/skills`
  ；旧三个契约Skill保持能力声明。浏览器handoff逻辑归插件唯一来源，旧原型用可校验生成副本；不能复制后两边各改。构建验证发布模式、版本、hash与原生依赖一致性。
