# 对标素材接入

只整理用户已提供或本任务已授权取得的材料，不负责扩展搜索、评价爆款、生成选题或提炼规律。读取当前任务显式Vault和已有素材索引；作品无标题可保留空值，缺失其他字段写未提供。

- 分开记录平台、作品ID、稳定链接、真实标题、正文/描述、作者、发布时间、可见数据、媒体、已有逐字稿及输入来源；原始复制内容完整保留，与整理字段分区，不概括冒充原文。
- 以平台+作品ID、去除时效参数的稳定链接、已检测媒体SHA256三层去重，任一命中先引用原素材；用户要求补充时只交补充候选，不创建第二份。标题/正文/封面文字不得互相替代。
- 本地媒体保持原文件；候选记录原位置、实际读取状态、字节与哈希。只有真实媒体才报告可用；视频需实际探测时长、编码与可解码情况，没有检测能力就标待验收，不把文件存在当可读。
- 图片依顺序读取实际内容；失败记录具体材料ID/路径和缺口，不推测。来源标题、正文、图片文字与口播分别标记。
- 可靠字幕优先复用。缺字幕才经当前受控ASR及授权补齐，保留原识别、复核、校正版、证据和不确定词。ASR提供方不沿用源Skill的强制火山或自动备用。
- 有真实时间来源才生成时间码字幕，文字取校正版，时间取已识别对齐，插值或粗粒度必须说明。核对时间递增、不重叠、不越实际时长、字幕与正文一致；不手估精确时间，不把失败写完成。
- 不搬移素材、不清理原始识别、不执行上游批量补字幕或旧目录脚本。提交reference/允许的artifact候选，由工作台受控采用；依赖schema不能承载的检测证据放artifact.text。

完成：材料稳定身份、原始内容、顺序、去重结果、真实媒体/转写/时间码验收情况和缺口均可追溯。无稳定身份无法去重时仅询问这一关键项；只有标题/截图可暂存候选，不能称完整有效视频入库。
