## 事实、修复与范围

Semi UI 2.104.0 的 DatePicker 默认 `autoSwitchDate: true`。`monthsGridFoundation.handleYearOrMonthChange` 在该项开启时调用 `updateDateAfterChangeYM`，继而 `notifySelectedChange`；应用的 `onChange → selectDay` 随即改变大日历和当天清单。已通过真实 React/Semi/Electron 复现：浏览下一月，2026-10-19当天安排立即变成2026-11-19。

面板正在浏览的月份与业务选中日期是两个不同事实。使用官方 `autoSwitchDate={false}` 保持浏览独立；仍由正常选日事件提交业务日期。大日历 `markWeekend={false}` 取消周末灰底，同时保留今天、选中与相邻月份日期层次。不新增自制日期解析、确认按钮或额外状态，不修改业务数据。
