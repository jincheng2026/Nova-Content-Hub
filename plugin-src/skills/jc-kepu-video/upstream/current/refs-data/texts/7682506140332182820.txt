hello 大家好，相信大家最近都已经被 GPT-6 和这样的 3D 空间模型各种惊艳炫酷的效果刷屏了，我也是这样，相信大家也都很好奇，就是现在新出的 GPT-6 和我们传统看到的 Tripo 这样的 3D 模型，它有什么区别呢？为什么这一次的效果如此惊艳？今天就想和大家详细聊一聊这些不同模型背后的架构。

首先呢，我们先讲一下最传统的、我们以前看到的这种 3D 模型它是怎么做的，这也就是生成的第一条路，也就是 Diffusion 扩散模型的道路，经典的案例就是 Tripo、混元 3D、豆包 3D 这样的模型，它们的底层逻辑都是这个扩散模型 Diffusion，相信大家以前要是玩过 AI 生图，肯定对这个 Stable Diffusion 不陌生，它背后都是一样的逻辑，我们现在看到的各类生图、生视频，以及生 3D 的这种模型，全部都是这个架构，它是怎么样一个逻辑呢？就是它从一堆的马赛克里面不断地去造、去造、去造，然后最终渲染出来一个你想要的图像，或者是视频，或者是 3D 的网格文件，那它这套背后的逻辑其实也就决定了它能做的其实只是生成，而它不能真正理解这个 3D 空间以及这个 3D 物品背后的逻辑，它其实是不行的，它所做的事情只是从海量的数据里面，然后去造，给到你一个你想要的东西。

然后呢，这一次我们看到的 GPT-6 这个模型，它和前面我们提到的第一种路径，其实是完全不同的，我们从 OpenAI 的官方文档可以看到，它说 GPT-6 完全没有生成能力，它从本质上来讲，如果你看过我前面一篇视频讲的 Agent，你就会发现，GPT-6 它的本质是一个 Coding Agent，它是一个纯文本的模型，那为什么它可以生成建模呢？它就是用工具调用，它调用 Blender，然后用自己的文本模型去写 Python 脚本，在 Blender 这个专业软件里面去摆放模型、去打光、去调整相机的位置，然后最终把这个东西渲染出来，渲染出来之后，它再把它部署到这个游戏引擎上面，这样我们就可以在里面去移动、去操作、去体验我们生成出来的模型或者空间。

那对比前面这两种路径，你会发现，第一种 Diffusion 扩散模型，这个原理它其实取代的是「建模」这一个动作，而 GPT-6 这个 Coding Agent 做的，其实是要取代「坐在电脑面前然后去建模、去部署」的这一个人，所以这其实是它们的一个本质区别。

那 GPT-6 这一次，其实我们会发现，它最强的、它想要展示出来的，其实并不是它的 3D 建模能力有多强，这个只是博眼球、它秀出来的一部分，它真正想要展示出来的能力，其实就是它的 Coding Agent、它去调用工具使用这种专业软件的能力，它既然现在已经可以去使用 Blender 和 Unity，那后面它去操纵我们平时使用的各类专业软件，它其实完全都是可以做到的，这才是它真正想要表达的 GPT-6 的核心能力。

然后第三条路径，我就想讲一下也是刷屏的李飞飞的这个 Atlas，这个世界模型，可能大家很多人看到它发出来的那个效果会有点懵，就是它和前面的有什么区别呢？看上去也是生成一个空间建模，感觉好像没有什么厉害的呀，没有什么不一样的，为什么大家吹得那么厉害呢？其实它和前面的区别真的还是蛮大的，就是前面的两种路径，它们做的其实本质来讲都是生成资产、生成模型，而李飞飞这个 Atlas 要做的，其实是生成一个世界。

怎么理解呢？就是你丢给它一张图，它可以仅仅通过这一张图，给你复现出这个相机的运动，以及整个场景空间环境的建模，而你是可以在这个空间里面去探索、去前进的，它是有空间纵深的，然后被遮挡住的物体，你拐到它的背后，你是能看到它背后长什么样子的，你不停地往前走，它会实时地给你生成，它不仅有空间，它还有时间，它是真正理解这个空间中的物理规律，以及空间中各种东西位置之间的这个 3D 关系的，所以这其实是它和前面两种路径最大的区别。

而且从技术上来讲，它和前面的也是完全不一样的，它的训练数据从一开始就不仅仅是单一维度的数据，它有文本、视频、图片，还有 3D 维度的数据，这也可能是以前的模型在训练的时候没有加进去的数据，所以它从训练之初，它的目的就是要让模型去完整地理解这个 3D 物理世界是怎么样的，这也是我们所说的，它后续要去通向空间智能这样一个状态。

然后现在我们聊完了这三种路径，其实你会发现它可以分为两个派别：第一个派别就是前面 Diffusion 扩散模型这类所代表的生成派，它可以很快、很高效，以及成本很低地给你生成各种各样精致的、符合你要求的模型；而第二类，也就是理解派，像 GPT-6 和 Atlas 这样的，它是要真正学会怎么样去打光，怎么样去摆放物体，这个物体在空间关系中是什么样的，它所要符合的物理规律是什么，这些是它要去做的。

那从短期上来看，你不能说哪一个就一定会取代哪一个，因为从短时间上来看的话，如果你需要一个 3D 资产，需要一个很精致的东西、3D 模型，这个扩散模型肯定是首选，那如果你要看谁能走向更远的未来，我其实是更看好这个理解派的，因为毕竟在未来的话，你要达到空间智能，你需要模型可以理解这个椅子摆在教室的什么位置，你走到椅子的背后你能看到什么，再包括桌子上的一瓶水，它打翻了它会怎么样流到地上，这些都是它要真正理解了之后才能做出来的，所以这也是为什么我们说这个 World Model 是现在最火热的一个课题，以及它是通向 AGI 的一把钥匙。
