# 选题生成

先读取context提供的定位（含已有_v0.1版本）、内容主题/支柱/暂不做、有效素材、已有选题和已处理素材记录。没有定位可依据本轮明确人群与目标继续并说明限制，不强制重访；不从默认目录猜库。

首次与增量都先核对素材原文与图片，使用稳定素材ID去重；素材移动不算新增。增量只优先处理新材料，用户明确复用旧材料时记录理由。新材料为零可交真实的无新增结论。

- 按用户本轮目标生成适量候选；原包首次至少10条素材、固定5–10题与AI科普赛道不作为全局门槛。材料少就少给，说明缺口，不凑数。
- 每题写清具体给谁、解决一个什么问题、与定位/内容支柱的关系、本人为什么可讲、来源性质（对标启发/自主想法/混合）及待核验条件。
- 参考逐条包含真实标题、平台、作者、作品ID、稳定链接、本地素材指针及具体用途；缺字段保持未知，不凭目录名补造。没有外部参考明确说明来源。
- 与已有候选逐一比对：同一问题只换工具名、数字或近义词视为重复；列出跳过理由。已有编号、状态、已确认内容、旧批次记录不重排/改写。
- 选题是准备讲什么，不优化为夸张标题、不生成正文。最终标题可空，新建内容可从资料和问题开始。暂不做方向除用户本轮明确选择不主动立题。
- 涉及价格、功能、数字、效果的题注明成稿/发布前实际核验；缺关键证据标缺素材，不假装本人用过。

完成：独立问题候选、来源与去重理由、本轮实际读取材料、事实核验与缺口齐全，以允许的artifact候选交回工作台；编号和正式入库由受控采用决定。
