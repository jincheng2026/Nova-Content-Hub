# 技术红线清单（阶段 3 写第一行代码前必读）

每一条都是已上线项目实际踩过的坑。违反任何一条，大概率返工。

## 字体与外部资源

1. **禁用 Google Fonts 及一切外部字体、外部 CDN 资源**。群成员在国内微信内置浏览器打开，googleapis.com 等域名加载不了，页面白屏或卡死。一律系统字体栈：
   - 中文正文：`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
   - 衬线标题：`Georgia, "Songti SC", "STSong", serif`
   - 等宽：`"SF Mono", Menlo, Consolas, monospace`

## 微信内置浏览器兼容

2. **backdrop-filter 必须带 fallback**：不支持的环境下要有纯色背景兜底（`@supports` 分支或先写纯色再覆盖），否则毛玻璃区域变全透明，文字叠在内容上没法读。
3. **OG meta tags 配齐**：`og:title`、`og:description`、`og:image`（1200×630 静态图放根目录随站部署）、`apple-touch-icon`（180×180）。缺 og:image 微信分享出去没有卡片图，传播折损。分享图生成方法：写同风格临时 HTML，用 Chrome headless 截图（`--headless --screenshot=<路径> --window-size=1200,630 file://<临时html>`）。
4. **pages.dev 共享域名在微信内可能被平台风控拦截**：浏览器能打开不代表微信内能打开。稳定分发要绑独立域名（操作见 pipeline-setup.md 部署节）。

## 移动端

5. **移动端优先**，正文对比度必须够：暗底上正文不低于 #b0b0b0 级别的亮度，禁止为了「高级感」牺牲可读性。
6. **iPhone 底部安全区**：页面底部 padding 加 `env(safe-area-inset-bottom)`，否则内容被 Home 指示条压住。
7. 可点击目标高度 ≥44px。

## 交互实现

8. **展开/收起动画用 JS 读 scrollHeight 算精确高度**，禁止 `max-height: 9999px` 这类大数值方案（过渡时长失真、回收时跳动）。
9. **消息文本的 `\n` 渲染时必须转 `<br>`**：数据里的多行清单、分段内容不做这一步会挤成一坨文字墙。超长内容（约 800 字以上）自动折叠：渐变遮罩 + 「展开全文」按钮。
10. **清掉浏览器默认 focus 蓝框**：交互按钮 `outline: none` 并配 `:focus-visible` 自定义轮廓（保键盘可访问性）。默认蓝框会盖掉设计好的 active 态，观感突兀。
11. **筛选类交互必须有位置反馈**：点标签筛选后平滑滚动到第一个匹配卡片并居中。只做淡入淡出不滚动，用户会认为按钮没反应（实测被用户投诉过）。

## 架构

12. **单文件 index.html**：样式、逻辑、数据（内联 JS 变量）全在一个文件里，部署零构建、零依赖。数据积累超约 3 个月再拆独立 JSON 按需 fetch，提前拆是过度设计。
13. **数据注入点用固定锚**：数据对象声明写成固定字符串锚（如 `const D={`），日更注入脚本靠这个锚定位插入。改锚必须同步改注入脚本。
14. 交付前 headless 渲染自检一遍（Chrome headless 截图或 curl 检查关键内容存在），再和需求逐项核对。

## 可选体验增强（已验证有效，按需采用）

URL hash 直达路由（`#日期`，支持前进后退）、顶部阅读进度条、每日速览目录（当日卡片 ≥4 个时显示）、前一日后一日翻页、往期归档视图（近 7 天 + 往期胶囊）、空状态页（「今天群里比较安静」）、连续金句合并成金句集、长编号清单自动渲染为悬挂编号列表、发言人头像取字素并按昵称哈希固定配色、键盘导航（左右切日期）、`prefers-reduced-motion` 降级。只在真实需求出现时逐项实现，不为了看起来完整全部堆上。
