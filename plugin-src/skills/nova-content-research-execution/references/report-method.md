# 报告交付

本方法使用 [生产产物结构](../../../plugin-src/resources/production-artifacts.md) 规定的导入与提交入口。该链接相对于随包 references 目录；源码检查时对应 plugin-src/resources。

## 报告必须能独立读懂

首屏给少量会改变用户决定的结论及来源入口。随后按任务组织实际范围、关键证据、对照、可尝试的做法、局限和样本明细。账号报告保留账号关联；零样本报告保留真实筛选过程和未满足条件，不补造图表。

每个主要判断配原话/画面依据、解释、未控制因素及适用前提。研究对象的数据、用户自己的素材与 AI 判断分开标明。引用只保留必要片段，完整材料由受控资产或原始来源定位。

作品明细至少能核对平台作品 ID、来源链接、日期、采集时点、指标和缺失状态。图表有对应数表、计数单位、分母和有效样本量。零值与未知分开；只有一条有效数据时用文字或表格，避免制造趋势。

## 适配工作台阅读器

当前阅读器按静态 HTML 交付：核心正文、数字、表格和导航文本在不运行脚本时仍可读。使用内联样式和必要的数据图片；不依赖 JavaScript、CDN、远程字体或本地绝对资源路径显示结论。

从既有报告导入时先确认其关键图表是不是脚本生成。若是，基于可核对的原数据转为静态表格/图片并保留转换说明；拿不到原数据就标明该部分无法完整迁移，不用截图猜数据。多页分别导入，并按 pages 结构提交；没有滚动恢复证据时只称支持页级阅读位置。

阅读器的每个 page 指向一份完整 HTML 资产，不会按 HTML 内的 section、CSS 分页或同名标题自动切片。要交两页，就生成并分别导入两份只包含各自正文的 HTML，pages 中使用各自返回的 assetHash。只有一份包含两节的完整 HTML 时应登记为一页，不能用两个不同页名重复登记同一资产冒充分页。交付前逐项打开页入口，确认每页实际正文与页标题对应，而不是只检查 pages.length。

构造后核对：关闭脚本仍能读到所有关键结论和数值，窄视窗没有正文横向截断，长引文和表格可完整阅读。具备浏览器工具时实际查看；只有静态检查时在结果中标记视觉未验收，不把 HTML 文件存在当成功。

## 导入与产物分工

1. 在当前任务的临时输出目录生成报告，不改同事原文件或另一个内容的正文。
2. 用共同契约的 import 及 purpose:production-report 导入 HTML，使用返回的 hash 构造 report。多页各自保留标题，meta/来源/采集时点放合同允许的位置；现有 schema 不接收的字段写进报告正文或 artifact.data，不强行扩对象。
3. 可复用参考另交 research 的完整 references 对象；新账号另交 accounts 候选。报告展示账号不等于已创建对标墙记录。
4. 将筛选条件、实际作品/评论数、所用来源、原数据摘要或 hash、生成时间及检查范围纳入报告证据说明。更改输入后重新计算并生成，不能单独改图上的数字。
5. 费用使用受控服务的实际记录：请求数、缓存命中、usage、已知金额依据和 unknown 分开；宿主费用不可读时保留未知。本地运行不虚报硬件成本为零。

固定评论模式 `reference-card` 的 `render-report` 返回静态 HTML 主路径及 SHA256；用该路径执行 import，提交导入回执中的 assetHash。`sourceMarkdown` 是原 Markdown 的路径/hash，和 findingsHash 一起保留在报告伴随证据中。HTML 只是同一 L2 快卡的阅读形式，钩子未知和本人判断待填写仍保留。旧 `.md` 结果显式重新 render 后再交付，原回执继续对应原字节。

资料备注中的预算、权限、工具开通状态只表示记录当时的状态，不代表当前配置。当前任务权限以冻结 request 为准，后续实际调用还受工作台当前设置控制；不能从一条历史备注宣称当前预算仍关闭。面向用户的报告以研究问题与证据为主，内部工具枚举、宿主诊断和任务令牌不充当研究结论。文字分析由当前 Agent 完成，不建议通过打开 model API 权限来继续研究。

## 提交检查

- 合格与排除样本总数能对上去重明细；评论分母和层级覆盖明确。
- 每个来源链接、原句和时间码都来自已取得的证据，临时媒体签名、凭据、私人文件路径不进入报告。
- 原始资料与分析结果分开；报告不带指示用户或 Agent 执行的隐藏命令。
- 产物大小和字段符合当前合同；导入 hash 实际存在。
- submit 后读取 status，核对任务/attempt/receipt；报告回传、任务验收、账号与参考采用分别说明。
