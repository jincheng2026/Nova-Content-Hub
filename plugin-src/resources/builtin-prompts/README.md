# 创作者内置提示词

`catalog.json` 包含 26
条面向日常内容工作的原创提示词，覆盖选题判断、标题与封面、内容结构、表达打磨、事实核对、渠道改写、发布检查与复盘。第一性原理、反向拆解等通用方法在这里用于具体创作任务；正文不沿用原型中的他人提示词、个人资料或私人笔记。

这是独立内容目录，不改变原型、用户已保存的提示词或正文，也不包含页面与模型调用。`provenance`
记录该条文案由项目原创撰写，不代表用户输入的素材也获得了使用授权。

## 使用

1. 根据 `when` 选择任务，阅读 `summary` 确认用途。
2. 用当前内容、目标读者、目标渠道等已知信息填入正文中的 `{{名称|简单填写提示}}`。每条只有 1–3
   项；当前内容可以是选题、草稿、素材或复盘记录，以提示为准。不知道的内容可以写“待确认”。
3. 将填好后的完整正文交给 AI。先审阅候选结果，再决定是否用于作品。核对类任务需要真实来源；AI 无法访问来源时，应输出待核实项。

变量只在 `body` 中声明，不另存变量列表。`id` 是稳定标识，`version` 是单条文案版本；目录顶层的 `version` 表示目录发布版本，
`schemaVersion` 表示文件结构版本。接入程序应保留用户自建或修改的条目，不通过同名标题推断它们可以被覆盖。

## 校验

```sh
node --test plugin-src/tests/resources/*.test.mjs
```
