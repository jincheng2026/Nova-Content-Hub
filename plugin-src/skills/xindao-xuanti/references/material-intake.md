# 资料接收与开题判断

## 收什么

四类资料都可以单独或混合给，收到后先归位再判断：

| 资料类型 | 特点 | 处理 |
| --- | --- | --- |
| 一句话灵感 | 只有方向没有细节 | 记为起点；缺事实时按下面「缺资料」处理 |
| 素材与笔记 | 经历、数字、整理好的表格、逐字稿片段 | 主要开题材料，按「素材清单」建记录 |
| 已验收的调研结果 | 工作台里已验收的报告、账号研究 | 作为背景与人群证据引用，注明来源任务 |
| 雷达收录候选 | 已收录的对标作品与指标快照 | 只作参照；别人的经历和数字不能写成用户自己的 |

混合资料先分清：哪些是用户自己的事实，哪些是外部参照。外部参照只能说明「别人讲过什么、讲得好不好」，不能写成用户自己的经历或底气。

## 素材清单（内部记录，不给用户）

读完整资料后，先在内部写清八项，后面扩层全靠它：

1. **能兑现什么**：整份材料看完整能拿走的是一套方法、一份清单、一个判断、一个故事，还是一种体验；几样组合时分开记。
2. **已有表达**：用户已经写好的说法或标题，原样记下；它是第一层候选的底稿，不先动手改。
3. **记忆点**：最容易让人停下来的具体细节——数字、反常做法、亲历现场、原话。
4. **露过头的大主题**：材料里已经碰到的、大多数人都在意的事，如赚钱、工作、家庭、健康、孩子、自我价值。扩层只能往这些已经出现过的主题上靠。
5. **谁在看**：已有受众或用户描述的目标人群，包括他们正在意什么。
6. **事实分层**：亲历事实、用户自述、合理推断、未知，四类分开记；给用户的判断只能站在有依据的部分。
7. **公开边界**：用户明确说不能讲的、涉密或涉隐私的内容，记为禁区，候选不得使用。
8. **已排除方向**：用户已经否掉的想法和原因，避免重复推荐。

## 缺资料

- 开题最低条件：至少有一个具体事实、经历或数字。只有情绪和口号的资料开不了题。
- 只追问一项最关键的材料，并说清「有了它，选题能落到哪」。不列清单式索要，不从热门话题里凭空猜题。
- 工作台模式下资料经 context 读取；同一批资料在本轮对话里已出现的不重复要。
- 用户暂不补充时，按现有资料能做多少做多少，如实标注受限处，不阻塞。
