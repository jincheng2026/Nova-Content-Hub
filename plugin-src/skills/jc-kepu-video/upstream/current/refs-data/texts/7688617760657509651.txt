最近呢，在AI圈有个词儿特别火，叫做Personal Agent。那就在这个月呢，Meta把自己的个人Agent Muse发出来了，一上线就冲到了美区App Store的免费榜第一。OpenAI呢也在筹备自己的下一代个人Agent，海外这几家都在往一个懂你的Agent这个方向挤。Personal Agent这一波，我个人感觉是真的起来了。那国内呢？千问这次在2026 年的云栖大会上给出了一个非常明确的答案，就是他们宣布将加速打造 personal agent，基于个人全域终身的 context，为每位用户打造深度理解自己的专属 agent。

那什么叫做打造 personal agent 呢？我觉得这对于千问来讲是一个非常大的进步啊！大部分人现在用 AI 呢，说白了就是问个问题，识个图，搜个东西啊，一次需求一次服务，哎呀问完就散了。但是 personal agent 不一样，它并不是一个更好的 AI 助手，而是 agent 的下一个形态。在你授权了之后，它就会围绕你一个人来积累长期的 context，把健康、理财、出行、学习这些原本割裂的场景串起来，同一个 agent 跟着你跨场景、跨人生阶段，一直服务你一个人。

那千问凭什么可以做到这个呢？我们先看它已经落地的东西啊。千问呢，大家都知道是基于阿里的生态，目前确实是可以做到从搜索到决策，再到支付，再到履约四个环节全部跑通。而且是开放给普通用户的。那我在出差的时候，让他帮我打个车、点个外卖或者买个东西，他都是可以直接下单、直接付掉的，全程不需要跳到别的 App 上。这和最近国外很火的逻辑是非常不同的。如果你用过就知道了，它本质上还是在用操作浏览器的逻辑，就是我们选择了一个商品之后，他自己去操作浏览器下单。

我们并不是说这种方式不行啊，其实它更加通用，而且它能解决很多问题。但是相应的代价就是速度更慢，不够稳定。而千问呢，它是有淘宝这个生态的加持，效率就会快很多。说到底啊，AI购物、AI打车这些能力，实际上是已经在为personal agent来铺路了。先把能办事的这步给他走通了，然后再往懂你的这个方向去走。比如说健康啊，在我们授权了之后呢，像苹果、华为、高驰这些智能手表，还有欧泰硅基【疑似：欧泰硅基】这些动态血糖仪，都可以接进千问睡眠、运动、心率、血糖这些健康数据，全部统一汇总到我们的健康档案里面，变成我们个人的健康 context。

那这个点我觉得它是最能说明问题的。以前我问他说，哎，为什么我最近训练状态会这么差，或者怎么提升精力，他只能从网上找一篇通用的文章来给我们回答。但是它现在是可以拿我们连续几周的心率、睡眠和运动量来进行回答，而且还给我们出一份健康周报。所以我自己天天戴这个手表，这个是我打算长期用下去的，是非常关键。那还有一个呢，就是理财。千问接入了国泰海通、易方达基金等二十多个金融机构、券商、基金、保险都有。通过智能体和 Skill 能够帮我们查行情、读研报。

连上我们自己的基金账户以后，还可以直接问它说：“哎，昨天我为什么亏了？哪几只是拖累最大？”从公共的行情走到你个人的持仓。投资小白也是一样啊，从我的账户现在是什么情况开始，一层一层往下问，基金、行业、风险，是从我们自己的资产出发去了解这些专业的信息。这几件事情呢，都有个共同点，就是它并不是多了一块功能，而是多了一块我们自己的 context。手表接进来，它能多懂一点我们的身体；账户接进来，它多懂你一点钱。这就是从一次性的工具往围绕个人长期服务走的样子了。

不管我们是拿 AI 干活的，还是问生活里面的事，它都围着你一个人转，而且越用越懂你。所以，国内谁最有可能会把 personal agent 来做好呢？看现有的产品，我个人的判断是千问啊，像购物、打车都已经把路给铺好了，健康、理财、学习、开放平台这次又全部都接上了。底下还有最新的模型 Context 和 Harness 这些建设托着，它是走在正确路上的那一个。
