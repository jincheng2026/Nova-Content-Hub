# 共用分页与每页数量

日期：2026-10-20。用户在最终收口目标中补充：内容管理、内容合集管理需要分页，并在统一分页组件中选择每页20、50、100条；其他随时间增长的数据列表采用同样设计，组件使用Semi UI。

## 需求与范围

- 复用现有`PaginationBar`与`DataTable`，使用本地锁定版本Semi Pagination的尺寸切换功能，不新增依赖。
- 默认每页20条，可切换50、100；页码、总数、范围与实际切片保持一致。
- 各列表独立保存当前页面内的每页数量；切换数量回第一页，保留搜索、筛选、草稿、跨页勾选。
- 空列表或不足一页时仍能调整每页数量，避免选择100后丢失切回20的入口；无多余翻页/跳页控件。
- 新的显式计划定位按当前每页数量计算目标页；改数量不能被旧焦点副作用立即跳回其他页。
- 内容、合集入口/组内内容/成员管理、提示词、模板及管理、资料附件/照片/渠道、日程当天清单、发布计划/历史、封面候选/生成/尝试记录和现有选择弹窗均核对。
- 总览固定摘要、日历月周网格和图片逐张预览不改成数据列表分页。不新增跨会话偏好或全局设置。
