## 根因

减少动态此前使用 `animation:none!important`，Semi 的受控选项需要关闭动画结束后触发 `onChange`，因而既不提交新值，也残留隐藏中的弹层。改为极短的动画/过渡，保留必要生命周期且不恢复可感知运动。

管理写入和后续快照刷新此前共用整页 `acting`；写入返回后仍等待全库读取，后台工作进程失联会让操作队列长期不返回。修复已通过 45 项相关回归、类型检查和真实 App/React/Semi/Electron 的合成桥探针：保存后故意挂起全库读取，恢复按钮和设置仍可操作；读取失败可见，下一次恢复只提交一次并使用新 CAS token。只读截止不覆盖重型备份校验和写入。
