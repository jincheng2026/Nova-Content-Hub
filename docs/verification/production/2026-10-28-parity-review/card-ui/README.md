3. 「全部与合集」仍为表格；是否纳入默认卡片的最终范围由主线程收敛。
4. 卡片为内容驱动的矩形网格，而非固定正方形。1280 viewport 实测宽 326.66px，高约 225–451px，同一行等高。若用户「方块」意指卡片呈现，此事实不单独判为错误；若指几何正方形，当前未满足。
5. 本次完整通过运行未覆盖类型筛选、键盘遍历/焦点返回、空库、长摘要展开、系统减少动画和 T046；后续增补运行单独记录。T046 的已有专用 detail probe 不在本次通过声明内。
