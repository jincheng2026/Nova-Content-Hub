# 0.3.25 UI and assistant handoff verification

The requested prompt presentation is now a compact Semi Card/List grid. Search, category/status/favourite/trash filters, deterministic sorting, twenty items per page, variable filling, copying, editing, recovery and optimistic concurrency remain on their existing paths. Cards use four/three/two/one columns at the checked desktop and narrow widths. Only the current page is mounted, including with 10,000 prompts.

The shared Semi pager now shows a count for zero or one page and retains page numbers, previous/next and the quick jumper for multiple pages. Its real nested input and list items are bounded inside narrow containers. Keyboard checks use Electron input events, including Enter/Space page selection and Enter in the jumper without submitting a parent form. Numeric items that Semi creates after mount receive the same accessibility attributes as the initial controls.

Page inspection also found and fixed collection artwork escaping its card, inconsistent content-thumbnail alignment, wrapped member dates, a redundant default expansion icon on publication tables, and Semi TextArea wrappers that were taller than their real editing/preview area. Explicit plan-detail and history-snapshot buttons still control expansion. Long prompt text remains editable and scrollable to its end.

The previous requested repairs are included: overview placeholders and recent-content rows, bounded monthly calendar events, the explicit all/cancelled schedule filter, and compact settings with a separate Semi help tab. Settings forms stay mounted while switching tabs and retain their dirty-close guard. Reminder storage errors have priority over generic notification advice in both settings views.

Assistant launch text describes generation, a matching saved annotation refinement, or template study/restoration, with bounded title/template hints and the real execution Skill. The fixed handoff request remains authoritative. Names never replace its identity, attempt, version or hash checks; the URL budget shortens optional hints first. No body text, annotation text or photograph metadata is added to the URL. Handoff code was committed separately as `e99c939`.
