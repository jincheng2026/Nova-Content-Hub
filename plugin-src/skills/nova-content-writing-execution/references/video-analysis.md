# 视频与多参考拆解

## 证据准备

读原片及可靠字幕/校正版。先说明本轮实际看过的范围：全文、画面、音频和已授权评论各自是否可用。只有文字时可做表达分析，画面项保留待看；标题或简介只支持发布表达。

画面可用时先连续看完，再围绕开场、转折、结果出现和证明段回看。允许使用当前宿主可用的本地查看/抽帧能力；记录实际覆盖区间和关键帧时间，快剪或关键细节需要更密地核查。抽帧数量不替代看懂，也不因没有工具就声称已看原片。

## 按意思分段，再逐段判断

每段围绕一个观众问题划分；不强行把并列清单解释成连续操作链。先在后台检查以下角度，输出只保留有证据、会影响后续创作的判断：

| 角度 | 要得到的具体答案 |
| --- | --- |
| 观众的问题 | 看到这里的人此刻想问哪句话，前段是否已经回答 |
| 作者的难处 | 放这一段是为了消除什么理解障碍或疑虑 |
| 前后衔接 | 哪句承接上文、哪句把问题带向下文 |
| 信任依据 | 来自作者亲历、实际操作、结果、可验证来源，还是借用身份 |
| 需要与顾虑 | 原文实际触及的期待或担心；没有就不补造 |
| 表达办法 | 什么例子、顺序、类比或删减让这段更容易理解 |
| 画面作用 | 真人、录屏、结果、图示分别在证明什么、帮助理解什么 |
| 实际收获 | 看完知道什么、能做什么，感受到的价值与独立复现能力分开 |
| 证据风险 | 核心事实、数字或承诺是否有来源，有无实质矛盾 |
| 必要性 | 删除后会少掉什么，长度是否服务本段目的 |
| 全片位置 | 这里的情绪、画面与信息变化怎样影响整体阅读/观看 |

每条输出包含来源 ID、原句或准确转述、可靠时间范围（若有）、判断及下一条可用的方法。引号原文逐字核对；截短用明确省略，不把改写放进引号。泛称“节奏好”“信息多”时必须补具体句子/画面及作用，否则删去。

## 开头、正文、结尾与整片

汇总观众问题如何接续、首次可信证据何时出现、结果展示是否支撑承诺、作者主动省略什么，以及整体给人的印象。判断也体现在选了哪些例子、没讲哪些内容，不只来自“我认为”。

解释观众可能为何停下、继续、相信或保存，但没有留存或对照证据时不把可能作用写成实际原因。互动构成只描述数字，不能从收藏多推断每个人都为了某个提示词而收藏。

教程同时拆口播与屏幕操作/结果画面如何配合，指出真正必须展示的动作。口播聚焦观点、经历、例子和语气；画面对理解无影响时不用硬凑镜头表。

## 多参考与人工先拆分支

用户点名的每条完整拆；顺带辅助参考只说明它提供的不同方法。按段落作用对齐，而非强按第几句；共有讲法合并，差异保留谁在哪句/哪帧做得更清楚。相同措辞不证明借鉴关系，发布时间未知不排列原创先后。

用户说先自己拆时，AI 分析先保存在本任务临时候选中，不提前给出答案。等用户完成后回读其结果，分同样看到、用户独有、AI 独有；重点呈现 AI 独有判断和证据供其批注。同样部分简写，用户独有观点保留。纠正走反馈候选，不自行改长期拆法或技能。

## 创作交接

交 analysis：一段概述、逐段证据、开头/正文/结尾及整体、主辅参考分工、能借的方法、不能复制的身份/经历/结果、事实与推断边界、关键缺口。详细多参考证据保留在 text/data，参考已有的 analysis 字段可由对应参考产物更新。

完成前抽查三条重要判断能定位原句或画面；每个重复模式有独立作品；每条建议说清适用前提。暂不替用户生成自己的全文或包装，除非冻结请求已经包含这些阶段。需要本地原片定位但当前页面无播放器时给原片资产与时间证据，不声称点击即播放。
