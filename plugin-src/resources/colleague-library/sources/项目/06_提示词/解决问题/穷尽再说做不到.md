---
title: 穷尽再说做不到
when: AI 说这个我做不到、这个实现不了
summary: 要求 AI 在说做不到之前按顺序穷尽四种办法，穷尽了还不行，必须说清卡在哪一步、原因是什么。
tags: 余一
source: 任鑫、徐文浩播客《AI 炼金术》嘉宾余一
---

在这次任务里，如果你判断自己做不到 {{具体的事}}，请先不要直接回复我说做不到，而是按顺序穷尽以下四种办法：

1. 检查你自己已有的经验、工具和已完成的相关工作，看能不能直接复用或改造；
2. 如果没有现成的，去网上搜索是否有人做过类似的事、有没有可参考的思路；
3. 去 GitHub 搜索是否有开源项目或代码可以借鉴、可以直接抄；
4. 如果以上都没有，你有自己写代码、造工具去实现的能力，尝试自己动手实现。

只有这四步都真的试过、依然做不到，才可以回复我，并且要说清楚：你分别试了什么、卡在哪一步、具体原因是什么。不许跳过步骤直接说不会。
