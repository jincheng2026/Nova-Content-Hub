就在刚刚,DeepSeek 终于发布了它的第一个多模态模型,以前 DeepSeek 再厉害,也像一个蒙眼的大侠,现在它终于是能够看见的了,而 Workbuddy 还没有官方配置,现在一分钟教你如何设置。

整体的调用方式都基本不变,价格也跟刚刚涨价后的价格一样,没有因为增加视觉能力而单独再涨价。图片会被折算成输入的 token,系统会自动按照尺寸去自动缩放,每张图片单独去计算,最高按照三百八十四个 token 计算。

那怎么使用呢?也非常简单。我们打开 DeepSeek 的这个接入文档,我们这里可以看到它新增的模型,就叫 DeepSeek Vision 这个模型。然后我们可以进入到 API Key 增加的这个界面,创建 API Key,比如输入 test,这里面它就会创建对应的 API Key,你就可以把你的 API Key、你的 URL 和你要配置的模型都发给它,你就会发现它很快配置好。配置完了之后,你这里面就可以去选择 DeepSeek Vision 这个模型,然后随便截张图发给它,问它比如说,哎,这是什么?你可以看到,之前是发不出去的,配置好了之后,它就可以完整地去识别你所要的内容。
