# 桌面功能批次实现记录

日期：2026-10-18。按用户要求，先完成旅游工作台式 Agent 交接，再连续开发桌面功能。本批仅进行源码实现、接线和源码审阅，**未运行测试、类型检查、构建、探针、宿主生成或安装验证**。下面的“实现”均不代表已验收。

## 本批源码范围

| 用户流程 | 实现内容 |
| --- | --- |
| 去助手生成 | 封面表单直接保存固定任务并跳转所选助手；带正确执行 Skill、库位置和短交接定位；先检查助手与配套插件。系统打开失败保留任务，活跃任务只有一个继续入口。 |
| 提示词 | 新建、编辑、停用、回收和恢复；粘贴或原生选择文本文件导入后确认；分类、变量填写、复制；左侧预览、右侧填写。 |
| 多图模板 | 原生选择最多50张、合计256MiB，逐张完整解码、摘要核对；名称、说明和自然语言规则确认；新建模板、非内置模板新增不可变版本；切换版本、回收和恢复。样张数与输出张数独立，不伪造验收或实测标志。 |
| 照片与默认值 | 导入、名称、本人声明、回收恢复；默认照片/模板/张数实际用于生成初始值；手动选择不被刷新覆盖，失效选择明确阻止生成；保留无人物路径。 |
| 内容资料 | 日期、渠道、偏好模板、示例标记；原生导入图片、UTF-8文本或PDF，确认后附加；预览、导出、移除；生成时只带用户明确勾选的资料。 |
| 合集与发布 | 合集正文、成员、日期和渠道；内容/合集排期、改期、取消和重新安排；记录实际发布、注明原因更正或撤回，保留历史快照。 |
| 总览与日历 | 共用发布事实投影，包含内容和合集；区分计划与实际发布；日历月/周/日及管理入口。 |
| 候选管理 | 收藏、编号、备注、版本归属；选封面与导出保留。 |
| 工作空间配置 | 个人介绍、品牌标记、渠道管理、提示词分类、自定义比例；业务资料仍写原生文件库。 |
| 备份恢复 | 原生目录选择、完整备份检查、恢复到唯一新文件夹、恢复核验及保留现场重新开始；不覆盖或自动切换原库。 |
| 本机偏好 | 减少动画、用户主动设置开机启动、每天提醒开关和时刻；反馈系统实际状态。本机偏好不混入业务库。 |
| 原生提醒 | 与总览共用发布事实、当天摘要、持久化每日防重复、唤醒重查、点击回日历、通知显示反馈。没有自动发布能力。 |
| 安装引导 | 打开当前助手、展示并复制匹配的本地插件市场位置、双系统手动安装升级说明；白名单脱敏诊断导出。无自动绕过系统安全命令或修改宿主配置。 |
| 品牌与打包 | 桌面导航复用用户提供的蓝色 N 图标；增加PNG静态资源和CSP白名单；构建时生成并携带匹配的完整插件市场，单独保留随包Node和启动脚本。未实际执行新打包。 |

所有新增业务写入均为有限操作、固定事务ID和编辑令牌，不接受任意方法名/路径/JSON补丁。写前持久化待处理输入，丢失响应后先查原事务；冲突不自动重试。新增恢复类型与种子操作均进入同一互斥边界。

## 源码收敛

- 主线程检查实际接线和调用关系；Astra high 只读审阅文件边界、队列和事务恢复。
- 修复明确的历史附件缺失拖住整库快照与已提交事务恢复问题：保留附件身份与删除状态，投影为不可用；实际读取、导出或生成仍严格拒绝不可用资料。库身份和锁冲突继续抛出。
- 插件市场复制保持相对链接，避免带入构建机器绝对路径。
- 管理弹窗支持暂时收起并保留输入，返回全局恢复入口；离开或关闭前保护未保存编辑。源码实现尚待统一交互验收。
- 不改变已有用户格式化，不修改旅游参考项目、同事库或真实业务库，不安装新版插件或替换当前应用。
