今天我想带大家走进模型的内部，看一看模型拿到 Token 以后是怎么处理的，到底经历了什么，才会做下一个词的预测。

之前有给大家讲过 Token 这个概念，中文名已经定义了，叫作词元。这个你可以把它理解为是 LLM，也就是大语言模型的货币。

OK，那文字，比如说一个中文“你好”，进入大模型之前，它会转成 Token，然后给到模型，让模型去理解。但是把文字转成 Token，只是我们开展和大模型交互的故事开头。

好，那我首先再给大家强调，大语言模型的工作方式就是，你每次给这个 LLM 发一段文字，比如说你给它发一个“你”，它只会做一件事情，就是预测下一个词。比如说，预测出来“你”后面要跟的是“好”。

再举一个比较详细的比方。假设你给定的输入是“中国的首都是”，喂给大语言模型。那模型其实不是在理解“中国的首都”，它是干嘛呢？它是基于“中国的首都是”这个前面的输入，给出后面词汇表里面每一个词的概率。

比如说有个“北京”，它可能给的概率是 92%。还有比如说“北平”，它的概率是 4%，可能还有“上海”，概率是 2%。通过这一系列的概率词汇表，最后找出概率最高的词，追加到输入里，那就是“北京”，对吧？

好，拿着“北京”输入以后，输入给大模型的前面变成“中国的首都是北京”，那后面再接什么呢？可能要接一个逗号，对吧？通过这样的标点符号，再循环一次预测，这个就叫作自回归生成。

这个听起来很简单。OK，我前面拿到这句话，然后预测下一个词，预测完下一个词，再预测下一个词，一直循环往下预测。

OK，虽然简单，但是现代 AI 的各种能力，你看到的比如说做 Coding、写代码、做翻译、去做推理，都是从中涌现出来的。就可能前面比较平，突然一下，它的能力往上飙升了。

OK，那理解这一点，我们就能够理解 LLM 的基础。接下来，我们就沿着一个 Token 到底是怎么一步一步从模型里面被预测出来的，来给大家剖析一下，把模型的内部拆解出来看一看。

首先，第一步就是把编号变成一个坐标。比如说一个词“你”进入模型的时候，它会转成一个数字编号，比如说它就是 15738 这样的一个数字编号。还有“好”，可能是 18725。

OK，但是这个数字本身不携带任何意义。你不能通过这两个编号的加减法，来判断“你”和“好”之间到底距离有多远。这个概念叫作语义距离。

模型做的第一件事，就是把这个编号查表，转成一个高维向量，这个叫作 Embedding 的过程。所以向量可以理解成一个多维空间里面的坐标。在这里，因为空间关系，我可能就画个三维的。

在这个坐标里面，语义相近的词，坐标也就更接近。我举个例子，比如说“国王”和“王后”这两个点的距离可能更接近一点，然后和“苹果”的距离反而会更远一点。

而且这个空间是有方向的。比如说，“国王”减去“男性”的向量，然后再加上“女性”的向量，得到一个非常接近“王后”的点。这个其实就是很简单的、我们以前学的向量运算。

但是这个不是人为设计的规则，是通过模型训练构建的几何结构或者空间坐标系。

光有这样的语义理解还不够。为什么呢？因为我举个有意思的例子，比如说“我咬了狗”和“狗咬了我”，它们的概念是不是完全不一样？因为顺序不一样。它们都是四个字，都是一样的字，但是表达的意思就是不一样的。

所以大家能想到是什么？既然 Embedding 不携带位置信息，那我们就给每个向量叠加一个叫作位置编码的东西，叫作 Position Encoding，缩写叫作 PE，告诉模型这个词到底是属于句子里面的第几个。

OK，经过这一步，每个 Token 就会携带两类信息。第一类信息，就是它是什么；第二个，就是这个位置在哪里。

OK，当你的每一个词有了语义信息和位置信息以后，下一个问题就是，模型到底怎么理解上下文？它毕竟不能只光靠这个词的向量。

OK，我举个英文的例子，就是“The animal didn't cross the street because it was too tired.”好，那我们来看这个“it”到底指的是“animal”，还是指“street”？那我们人一眼就能看出来，对吧？“it”指的就是“animal”。

但模型怎么做呢？模型应用的机制叫作 Self-Attention。所以 Self-Attention 要做的方法，就是让每一个词询问其他所有词，找到跟自己关系最密切的那个。

所以它的工作原理，就是每一个 Token 进入注意力层的时候，会生成 Q、K、V 三个向量。Q 代表 Query，它的意思就是“我在找什么”；K 就是 Key，“我能提供什么”；V 就是 Value，“如果我被选中，那我能贡献什么内容”。

OK，那计算过程，就是把“it”的 Q 向量，分别和句子里面每一个词的 K 向量做点积，得到一组注意力分数。注意力分数越高，就说明两个词的相关性越强。

然后再经过 Softmax 归一化，当成权重。之后用这些权重再乘以 V 向量，然后做加权求和。那结果就是，“it”的向量被更新了，它不再只是代表“it”本身，而是混入了“animal”的信息。这个就是代词和它所指代关系被关联起来的方式。

OK，更多 Self-Attention 的工作原理和公式，大家也可以去网上看，很多文章都写得特别清楚。

OK，那再讲一下，实际上模型会运行很多组 Q、K、V，我们叫作多头注意力，叫作 Multi-Head Attention。它有很多 Attention Head，每组 Head 都是独立计算。

那为什么需要这么多头呢？就是因为我有不同的注意力头，是不是能够关注不同的信息？比如，有的注意力头捕捉的是语法依赖，有的可能捕捉的是语义关联，有的可能捕捉的是指代关系。最后把各组结果拼接起来，得到一个更加丰富的上下文表示。

另外还有一个关键约束，就是在生成文本的时候，每个词只能看到它前面的词，不能提前看到未来。这个通过什么呢？这个叫作 Causal Masking，叫作因果掩码。

那具体实现，就是比如说当前预测这个词的时候，把后面这些词的注意力分数直接设成负无穷。OK，那它经过 Softmax 层以后，就直接变成了零。好，那就达到了信息只会从前往后流动的目的。

这个设计是为了保证模型在训练和推理的时候行为一致。除了自回归以外，还有一个叫作自编码的方式，那它可能是在前面可以拿到信息，后面也可以拿到信息。

好，那讲完 Self-Attention，解决了词和词之间交流的问题，但每个词自身的信息还需要进一步加工。紧跟在注意力层后面的是什么呢？是一个 FFN，一个前馈神经网络。

它不处理词和词之间的关系，而是对每个 Token 的向量做独立的非线性变换。那相当于让模型在这一步消化刚才吸收的上下文，提炼出更加有用的表示。

所以你可以这么区分 FFN 和 Self-Attention：注意力层负责在词之间找到它们的路由信息；前馈层，也就是 FFN，负责对每个词的表示做深度加工。这两个层合在一起，就叫作一个 Transformer Block。

那现在大模型会有很多这样的 Transformer Block，然后把它们堆叠在一起，可能会堆几十个或者上百层。每一层都在上一层的基础上继续提炼。

有研究发现，每一层对最终预测准确性的贡献是均等的，从第一层到最后一层，每一层都按照相同的乘积因子改善预测质量。这个规律比较跨架构、跨规模，是普遍成立的。

最后，当所有的 Block 走完以后，最后一个 Token 的向量会经过什么？会经过一个线性层。经过线性层以后，会被投射成一个巨大的列表，它那里有很多维度。比如说，假设有 63376 个维度，那这个维度就等于词汇表大小。

然后列表里每个位置对应一个 Token，对应的数值叫作 Logit，就是模型认为这个词出现在这里的原始得分。经过 Softmax 以后，就把这 63376 个 Logit 转换成加起来等于 1 的概率分布了。

然后概率分布以后，也并不是直接选最高的几个就完事了。这里还有几种常见的策略。

第一种叫作贪心搜索，每次就选概率最高的。这个速度快，但是很容易单调、重复。

第二个叫作温度，这个大家也很熟了，Temperature。这个温度参数控制概率分布的平坦程度。如果你的温度越高，整个概率分布会越平坦；温度越低，概率分布会越陡峭。平坦代表概率越分散，输出就会越随机、越有创意；温度越低，输出就越确定、越保守。

所以大家自己用模型，可能会调这个温度。大家就可以知道，写诗的话，我是不是可以把温度调高，让它发挥创意？那如果我只是写代码，我可能把温度调低，让它更加准确。

OK，还有什么呢？还有 Top-K 或者 Top-P 采样。Top-K 就是从概率最高的几个地方，比如说“北京”“北平”还有等等，做一个随机采样。这个例子可能有点问题，有些可能是 50%、40% 等等，在概率很相近的情况下，做一个整体采样。

那两者都是保留多样性，同时也过滤掉那些概率极低或者语义奇怪的词。

所以整个流程串起来，就是从用户输入文字，然后给到 Tokenizer，切分成 Token 的编号；然后再给到 Embedding，把这个编号转成高维向量；再给到 N 个 Transformer Block；再给到线性层，得到高维的 Logit；然后再给到 Softmax，转成概率分布；再给到采样策略，选出下一个 Token；最后把这个 Token 解码回文字，再追加到输入，循环往复。

所以，基本上就是这一整套机制。这一整套机制看下来，本质上就是统计规律的极致压缩。

LLM 不是一个知识数据库。比如说，当它生成“北京”的时候，不是因为它知道中国的首都是北京，而是在数万亿的 Token 里面，发现“中国的首都”后面跟“北京”的频率和概率很高。

那模型学到的是语言的统计模式，而不是事实本身。这个其实也能够让我们 Get 到幻觉的根源。当训练数据里面的统计模式和真实世界产生偏差的时候，模型并没有内置的纠错机制，它只是在输出听起来最合理的下一个词。

所以理解这一点，你就能够更清楚地知道什么时候该信任模型的输出，什么时候应该对它保持警惕。这个比你记住任何一些参数细节要有用得多。
