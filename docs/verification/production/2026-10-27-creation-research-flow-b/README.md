## 实施范围

- 单正文真源下的稳定段落、逐段来源/用途/画面、拆分/合并/明确删除、全文新增段补齐及可撤销的旧关联核对。完整输入基于稳定锚点，不把未保存的新段逐键冻结。
- 教程录屏的位置、提示词、预期、注意事项、制作分工、可选镜头、旧镜头重新关联与画面脚本；通读/录完确认继续绑定正文版本。
- 已接受回执的采用记录持久保存；整篇任务必须包含正文、拆解、叙事与完整包装，不把单正文冒充整套。审稿/历史恢复精确迁移或载入待核对草稿，保留输入和关联。
- 独立研究及账号分析的已验收资料进入已有/新建内容，双CAS、来源回执、版本冲突及事务恢复；同URL不同证据不静默跳过。报告摘要明确区别于原始逐字稿。
- 新建调研继续保留；深度要求覆盖人群需求、原话和作品证据、行动角度及缺口。兼容锦成元数据date/type/pages阅读顺序，未知采集时间不冒充导入时间。
- 报告正文仍在隔离iframe，页头提供受控来源核查目录；不开放报告脚本到应用权限。
- 雷达先筛已返回候选池再限最终数量，不增加接口、翻页或REQ。逐来源保留时间、旧产物保留原语义；最新观察按时间选，保留加入/拒绝决定；有证据的可借鉴角度进入选题参考。
- 规范抖音作品URL经TikHub详情回执→受控下载→attempt媒体授权→本地/云端ASR；不接任意URL/path/hash。终态撤销工具使用权，保留人工采用证据；report/research/transcript及历史采用统一核验媒体归属。
- 发布源码复制白名单与凭据扫描覆盖随包插件、桌面stage、原生负载和最终resources；阻断个人Key、本机加密设置、真实库、日志和fixture。全新配置无Key，原机升级保留本机配置。
