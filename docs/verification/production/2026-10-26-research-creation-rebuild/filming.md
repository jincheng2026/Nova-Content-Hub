# 教程画面与录制清单验收

2026-10-26，在研究创作工作树完成最小拍摄辅助能力。当前正文仍为原唯一真源；分镜只保存原句引用、画面或动作、录屏／本人口播／后期分工及完成状态，不自动修改正文、剪辑或发布。

`ProductionCreation.filming` 是可选字段，旧资料缺失时合法；界面只显示空清单，不因读取而向旧资料补写字段。新资料默认空清单。分镜最多 200 条，ID 唯一，新建或修改引用必须在本次正文唯一出现。正文后续修改导致原句不再匹配时，旧分镜仍保留并提示核对。

通读与录完由用户明确点击，分别保存 `readThroughBodyHash`、`recordedBodyHash`。新写入的确认 hash 必须等于此次提交正文的 SHA256；已有旧 hash 允许保留供辨别版本，但只有与当前正文一致才显示有效。正文变化后，页面显示需要重新通读／录完确认。修改清单清除录完确认；未完成的分镜存在时录完按钮禁用。HTML 绑定当前可编辑正文 hash；React 绑定当前已保存正文 hash。两处均通过原保存入口提交，并保留既有 CAS 与冲突处理。
