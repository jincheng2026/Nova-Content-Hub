AI 创作的人都知道，Agent 很容易完成第一步，但真正困难的是把一整支视频做完。每一次小修改都可能让前后的节点全崩。所以 LibTV 把过去半年打磨的每一项专业能力，全部集结为 Agent 的能力，不追求一步到位，而是先把改这件事做好。更牛的是，我们还能根据自己的创作习惯跟需求去创建 Skill。现在我们一起体验一下，从创作属于自己的 Skill 到交付视频的全流程。

进入 LibTV，点击 Skill 广场，找到我的，就可以创建我们的 Skill。在这里输入自己的需求，也可以像我一样上传提前准备好的 MD 文件。我发现以前用其他工具做产品广告的时候，它根本不理解我的产品，只会一股脑生成视频。所以这里我要求，当我说帮我做一个广告或者类似指令时，Agent 要立即反问，要推广什么产品、核心卖点是什么、目标受众是谁，这样才能从第一步就把视频的核心给稳住。再把其他需求也写完之后，直接点击保存，我们就可以点开这个 Skill 来用了。

现在来试验一下，帮我做一个广告。它是不是直接按照前面的设置来反问我了？而且它还给了我双视图的自由，在故事板视图里，我可以尽情发挥创意和规划节奏；切换到节点视图，又能精准修改镜头的参数或者构图。比如我觉得双语字幕会更加好看，按照以前肯定只能重新生成整条视频，但现在在故事板一句大白话就能搞定，其他画面完全没有受到影响。剧本、角色、场景、视频，Agent 全程会帮我跑。

如果我是小白，不会创建 Skill 怎么办？没关系，在 LibTV 的 Skill Hub，我们可以看到有非常多专业创作者沉淀好的 Skill，涵盖短剧、漫剧、产品广告、音乐 MV 等，相当于你有一百条专业生产线可以随时调用，就算是小白也可以直接上手。

这次体验完，我最大的感受就是真正好的 Agent 就应该像 LibTV 一样，它让专业的视频创作者终于不用再被复杂的软件拖累效率，也让第一次做视频的新手拥有完成高质量作品的能力。抖音。
