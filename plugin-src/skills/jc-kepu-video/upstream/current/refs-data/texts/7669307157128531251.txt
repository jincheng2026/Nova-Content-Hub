上一期那条工作台的视频，我看了评论还有反馈，然后给大家总结出了这几个常见的问题，还有对应解决的提示词。

第一个问题，为什么你的工作台打不开了，显示的是这个页面？因为你现在打开的是会休眠的临时预览链接，你要是想长期打开，就给 AI 发这段提示词。

第二个问题，为什么数据突然没了，为什么电脑端和手机端不同步？因为你现在还是把数据存储在本地，存在当前设备的浏览器里面，如果你换设备或者清理缓存，就可能看不到原来那些记录了。所以先给工作台加入"导入备份"和"导出备份"，如果想跨设备同步，就发这段提示词。

第三个问题，怎么把工作台直接放在桌面上？首先你现在做到的只是一个网页，它不是一个原生 App，我的建议是还是从方便的角度来说，去浏览器里面找这个"可以添加到桌面"的快捷方式，基本上每一个浏览器都会有，只不过不同的手机品牌、不同的浏览器它的位置不太一样，然后就是发这个提示词。

第四个问题，为什么你继续修改了以后，它之前的页面都变空白了？因为这个可能是某段代码运行失败了，但它并不代表着你要推翻重来，让它去读取报错和备份，去修复那一小块有问题的部分，然后就是发这个提示词。

第五个问题，怎么连接 AI 助手，API 怎么配置，这个东西会不会收费，API 是什么？API 就是让你连接 AI 大模型的一个服务端口，基本上所有的平台都会按照实际使用量收费。当你选好平台以后，创建一个 API key，但要注意，这个 API key 你不要泄露给任何人，别人要是知道了这个 key，就可以拿去使用，所以一定要保护好你 API key 的隐私。然后在你的工作台里面配置这样一个功能，让 AI 教你如何把你刚刚拿到的 API key 填写在这个功能里面，你就可以用了。
