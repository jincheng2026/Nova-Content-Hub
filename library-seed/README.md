# 正式本地库的内置资源安装

`installBuiltins(library, bundleRoot?)` 将已交付的 15 个模板组、30 张真实风格 PNG、结构 SVG 和 26 条原创创作者提示词安装到本地库。供桌面
main 的受控初始化调用；`bundleRoot` 由应用资源目录提供，不向 renderer 暴露任意来源路径。

安装前检查所有 PNG 的实际字节和已有生成清单哈希。风格样张与结构图分开；保留原始 definition、来源版本、`accepted:false` 与
`aiTested:false`。文件进入不可变资产库，模板通过可信 hash 引用。字节一致不代表模型生成、人物替换或跨比例质量已验收。

模板按 ID/版本/包内容重复安装；同版内容变化应由文件核心拒绝。提示词按 builtinKey
检查当前与回收站，已有编辑和删除优先，不在启动时覆盖用户正文或复活已删条目。新用户只安装原创创作者提示词，原型已有提示词仍通过后续备份迁移保留，不静默替换。

各模板/提示词逐项提交；安装中断后可重新运行，不宣称全库原子安装。后续内置提示词升级须独立设计“可更新/用户已修改/用户已删除”的处理，本版本不自动覆盖它们。

验证：`node --test library-seed/test/*.test.mjs`。测试使用临时库，真实导入模板字节，不接触用户库或发起生图。
