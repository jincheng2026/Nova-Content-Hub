# Mac安全替换安装与0.3.4

日期：2026-10-19。继续“本机Mac先可用；每个最新Mac版本实际重新安装”的优先级。本轮处理0.3.3原生替换中途失败、正式目录只留下部分应用的问题，不把上一轮的手工完整复制称为自动安装修复。

## 问题与取舍

已确认的缺口是旧应用先被移走，复制失败后缺少完整性校验、旧版保全和中断恢复。Electron随包类型文档也明确说明原生替换默认将旧应用移入废纸篓。之前失败现场保留；导致该次原生复制失败的底层系统原因仍未查明。磁盘空间不足没有证据支持。

本轮停止使用`app.moveToApplicationsFolder()`执行替换。Astra high负责方案及关键风险审查，Sol high唯一负责安装模块、调用面和测试，主线程检查实际diff、版本装配与本机安装。没有新增依赖或通用安装器框架。

## 实际安装策略

固定正式路径为`/Applications/自媒体工作台.app`，不接受界面传入任意安装路径；仅允许覆盖相同发行渠道的bundle ID，目标链接、未知应用、无法确认的运行状态和恢复记录均拒绝自动切换。

先读取原应用的完整内容清单，在Applications同一文件系统的私有唯一目录中暂存新版。使用系统`ditto`保留Mac复制元数据；校验源与副本整树文件内容、目录、内部相对链接和执行位，源及副本分别执行codesign深严格完整性验证，复制期间发生变化则停止。它不意味着Developer ID签名、公证或全部ACL/xattr逐项相等。

初始记录先写入并同步，才通过排他硬链接发布安装声明；声明固定暂存目录身份。首次记录发布前中断只留下保全的私有目录，不阻断再次安装。运行中的另一安装过程不能被接管，未知声明不会被覆盖或删除。

完整副本验证后，再次核对原应用未运行且身份未变，将旧应用保存在事务目录的`previous.app`，随后将完整新版改名至正式路径。从正式可执行文件重启，不继承DMG或开发参数；窗口载入后才记录安装完成。复制失败不动旧版，切换失败尽量恢复原路径，恢复失败保留可核验的旧应用和记录。重开安装包可依据已固定的目录身份恢复，不要求终端命令。

两次rename并非一次整体原子交换：恰好在两者之间退出，正式路径可能暂时不存在；下次打开安装包恢复。旧版应用保全不等于内容库降级或数据回滚。旧应用与孤立暂存目录本轮不自动删除，会占用磁盘。
