# 0.3.35 五组模板、图片展示与新手拆解流程

## 范围

- 新库只安装同事五组：AI大白话19、Seven研究社23、秋芝30、科技姐聊AI25、鹿一家30，共127张；提示词52条。旧自制内置退出推荐，历史引用、自建模板和原文件保留；来源与工作副本归组但可明确切换实际版本。
- 管理与生成共用真实叠图卡片，常规三列，手动6/12/24分页及搜索筛选。真实图片完整等比展示、小圆角；图集原图矩形，不改原图字节；悬停/焦点轮播在离开、后台、失焦时停止，系统减少动画仍生效。
- 导入只需选图或文件夹、模板名称；其他要求折叠。保存后固定模板ID再启动当前助手，失败可继续同一任务。内置拆解自动建立或复用工作副本；沿用CAS、固定请求、pending恢复和人工确认。
- 拆解来源与本次AI结果分别标识；结果提交/人工确认后，或显式打开模板目录时生成可重建Markdown。写失败只警告，不将已提交操作改成失败；普通启动和读取不写报告。
- 公共视觉指南吸收本地cover-vi和固定gbro方法，保留现有规则JSON与回执边界，不引入后台自动生图或自动验收。AGENTS包含设计入口、代理规范和原平台交付要求。

## 定向验收

- native/renderer类型检查通过；核心、种子、目录、安全导入共30/30，交付示例与导出3/3。
- 两个真实React/Semi/Electron隔离probe通过，截图见cards/和onboarding/。覆盖手动分页与选择保留、来源副本、悬停计时/清理、横竖和极端比例、原图组、系统减少动画、导入/启动失败同ID、真实状态、人工确认/CAS、文件夹、窄窗与报告警告保留。
- Astra只读风险审查发现根目录临时报告残留和legacy默认fallback，均已修复并加入回归；报告警告刷新丢失同步修复。
- 以上使用临时库或内存bridge，无真实助手/生图调用、无用户库业务写入；不等于最终安装验收。最终包/安装/系统展示记录后补，按根AGENTS要求执行。

## 发布边界

目标为darwin-arm64预览交付，沿用用户接受的临时签名；无Developer ID/公证，Intel/Windows原生验收不在本轮。冻结源码、SHA256和最终安装信息以本目录随后生成的记录为准。
