# 风格十四：无人物功能演示风

不出现真人，让产品、设备、机器人或界面直接演示「它正在做什么」。用动作关系代替人物表情，适合功能本身比个人出镜更重要的技术选题。

## 适合什么

- Agent 执行动作、自动化工作流
- 手机控制电脑、设备连接、数据传输
- 机器人、硬件、新功能演示
- 强行放人物会挤压产品空间的选题

## 视觉特征

- 主体：单个产品或一组明确协作关系，占画面 50%～70%
- 动作：点击、连接、传输、打包、控制、转换等必须可视化
- 标题：位于上方或侧面，不覆盖动作发生区
- 证据：真实界面、设备细节、输入与输出状态
- 背景：深色或中性色，帮助主体轮廓清楚
- 人物：完全不出现

## 固定

- 画幅：3:4 竖版
- 不使用人脸参考图
- 只演示一个核心功能
- 必须明确动作的发起方、接收方、方向和结果
- 不用抽象光效代替实际动作
- 关键元素距四边至少 10%

## 变量

- 主体产品或设备
- 功能动作和输入输出关系
- 产品截图、设备图或角色图
- 标题位置和强调词
- 背景色调和少量方向线

## 提示词模板

```text
3:4 竖版构图。

画面全部由产品、设备、界面和功能动作组成，产品是唯一主角。

画面主角是[产品/设备/机器人/界面]，位于画面[中央/中下方]，占画面约[比例]，
[主体外观、材质、屏幕内容和朝向]清晰可见。

它正在执行一个明确动作：
[发起方]从[具体位置]发出[文件/指令/数据/物体]，
沿着[从左到右/从上到下/弧线]移动到[接收方]，
[接收方]显示[完成状态、结果画面或具体变化]。
动作路径用少量实线箭头、速度线或连续状态卡表示，每一段都指向明确对象。

[如有图1：参考图1作为主产品或界面，保持产品外观和内容结构。]
[如有图2：参考图2作为接收端或结果画面，位于主产品的[具体方位]。]

主标题“[封面标题]”位于画面[上方/左侧]，拆成[1/2]个字块，
其中“[核心动作或结果]”字号最大，使用[字体和颜色]；
[品牌名]作为小标签放在标题上方，宽度约为主标题的25%。

背景为[深藏青/深灰/中性浅色]，主体轮廓与背景对比清楚，
背景只保留少量与功能有关的界面线框，画面干净克制。

缩小到手机信息流尺寸后，核心动作、产品轮廓和最大关键词仍可辨认；
标题和产品距四边至少 10%；画面只有 1 个核心功能、1 条动作路径和 1 个结果区。
```

## 避坑

- 不为了账号露出强行加入人物
- 不同时演示多个功能
- 不用一束发光线代替含义不明的数据传输
- 不让标题遮挡动作起点、终点或结果
