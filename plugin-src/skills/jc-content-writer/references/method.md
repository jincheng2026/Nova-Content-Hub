# 素材到本人逐字稿

以当前contentId、最新正文及用户手改为唯一基准。先读适用定位、当前问题、全部相关来源/图片、已采纳判断与本期可用写法；缺规律不阻塞，参考候选不能覆盖用户已确认事实。本轮未要求新选题时不强制回选题库。

1. 素材包区分来源、引用与用途、图片文字、作者判断、市场写法及待核查。视频博主经验不是普遍事实，参考的数字不能写成本人的成绩。
2. 需要作者独有经历或硬判断时一次问一个关键问题，原话整理标本人回答，不编观点、情绪与故事。已有明确材料或用户要求直接给稿时沿用，避免重复访谈。用户明确指定素材包确认节点时，等待真实确认后推进。
3. 初稿只解决一个问题，先给可读完整稿，再给来源/待核查清单。开头直接说明问题，正文以普通话解释术语与实际意义，结尾收束为具体判断或行动；导流与公开边界依当前定位与授权。
4. 抄结构不抄句子，标明参考用途和表达变化；不虚构我测试过/学员案例。缺少事实保留待核查，重要事实冲突先解决。
5. 修改建议基于最新原句及位置，提供改前、改后、理由、依据；保留上下文，不把脱离原文清单当改稿。用户亲自改稿保留原样，旧版本保留，不能并行另建当前稿。
6. 明确锁稿的文字逐字保留。标题、封面和简介独立候选与确认，不能暗改正文。提交draft/建议/资料候选后工作台人工采用，禁止直接搬移素材或重写引用。

完成：素材出处、本人回答、事实与判断、当前完整稿、逐句建议及待核查均可追溯，固定请求与当前正文版本一致。最终发布事实另按真实成片/发布资料核对，不以录制前稿冒充成片。
