# 自媒体模板与生成流程升级

更新：2026-10-17。本轮实现以通用自媒体为主体，AI 专业内容占少量；先完善浏览器原型及插件契约，真实 Electron 另行实施。

## 从事实重新推导

| 类别       | 本轮结论                                                                                                                                |
|------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| 已确认事实 | 封面首先需要表达内容结构；图片、模板规则、生成任务和验收结果不是同一种数据。浏览器、外部 Agent 与未来桌面应用分属不同执行环境。         |
| 未验证假设 | 漂亮示例能稳定被模型还原；3:4 规则换成其他比例仍然好看；AI 风格一定是蓝紫霓虹；切换助手会自动带走完整聊天。上述假设均不能作为验收事实。 |
| 真正目标   | 通用创作者能找到适合内容的模板；AI 公司能通过工具实测、流程与证据表达专业性；每次生成的输入、引用和人工判断可以追溯。                   |
| 现实约束   | 浏览器使用有限本地存储；真实目录、接单回执、授权与自动回写尚未接入。外部公开图片的可访问性不等于可分发许可。                            |

只换配色、给模板起科技名、把同一占位图反复摆放，都是表面修补。本轮改为“内容场景 → 区域与规则 → 本次文案及参考角色 →
真实结果 → 逐项验收”。模板数量服务于场景覆盖，不能代替生成质量证明。

## 实际使用与数据流

1. 在模板页按“通用自媒体 / AI 专业”和内容场景筛选，查看适用范围、区域拆解、变量与验收点。
2. 内置原创设计可以创建生成请求，但仍显示 AI 还原未验证。自导入模板需保存可追溯规则、导入真实还原图并人工验收。
3. 为具体内容填写标题、比例和数量，明确选择参考。切换模板清空参考选择；候选仅来自本内容已选/收藏图片，账号素材须显式标记可用。
4. 生成出口将模板说明和本次提示固化为 request v1 的规则快照；引用使用稳定 ID 和版本，不把大图、令牌或真实目录塞进 JSON。请求仍限
   16 KiB，超限明确报错。
5. 新任务采用当前全局助手。历史任务保留原助手，跨助手需显式交接；结构化摘要不能代替完整聊天和实际图片附件。
6. 收到真实结果后再导入。还原任务和评审都绑定模板版本及具体图片，不能用旧任务验收后来替换的图；评审时变化则重新确认。
7. 改规则保存历史并使原还原结论失效。升级内置设计需显式操作；已保存的同版可信草稿可“更新参考资产”，仅补参考而不替换规则、评审与旧任务。

本次新增 `template-design.schema.json`，供目录和工作区共同约束上述可选扩展，五份 Schema 随各独立 Skill 交付。结构校验不替代可信
manifest、跨字段绑定、引用范围与 UTF-8 容量检查。

## 验证与下一步

统一验证入口是 `npm run verify`：检查目录与生成物、原型和存储模型、插件、独立 Schema，以及鉴权/免鉴权构建包中的真实资源和实际
CLI。额外逐套构造全部 12 个生成请求；检查 6 张 PNG 真实尺寸、字节、提示文件和参考 ID。页面回调使用隔离 DOM；24 张 SVG
已通过完整画面联系表检查，6 张 AI 图已目视检查。文件和概念样图检查不能证明模型还原稳定性。

主线程最终实跑： **81 项原型/工作区 + 20 项插件 + 18 项 Schema/双构建联调，共 119 项通过、0 失败**。Astra
有界审查发现的旧任务误验新图、旧版本结果被标新版本两项 P2 已修复，4 条新增动作链回归通过，并完成针对这两项的独立复核。405
份文本文件扫描未发现已清除的原隐私姓名；六张参考的 SHA256 与生成记录一致。

这条路径成立的前提：具备实际生图工具、可提供合法主体材料、有人进行逐项验收；进入 Electron
后再由主进程提供受控目录、可信授权、接单回执和原子登记。浏览器演示无法替代这些能力。

**验证第一步：**用“AI
工具实测”模板，分别输入短标题、长标题和另一个主题，选定同一张风格参考；通过当前全局助手取得真实结果，逐项记录文字/布局偏差和返工原因，确认提示快照与导出图片能一一对应。之后再选一套通用模板做相同试验。只有真实还原与换题都经过检查，才进入可复用模板验收；本轮六张概念图不代替这一步。

未接通的部分：浏览器自动唤起后的接单/回传、真实权益校验、Electron 文件库与跨平台安装升级。插件仍是预接入契约，全部输出
`executable:false`。

## 模板组更新（v4）

当前模板是多图组：15 套内置每套 2 张 PNG，共 30 张；旧 SVG 保留为独立结构资产。新增一张与原样张共享视觉语言、构图有所变化的参考，以便批量生成综合学习整组。v3
原目录完整保存于 `plugin-src/resources/builtin-templates/legacy-v3.json`。

列表显示组数量和缩略带；详情支持原图组翻阅。生成默认选择整组真实样张，本人照是独立身份输入，切模板保留本人和本内容候选。更多参考可取消，界面明确显示实际选中数和整组总数；生成数量独立设置。32
张参考超限拒绝提交且不截断。交接需导出全部参考图并整组附给助手，按稳定 ID 命名且按请求原版本解析。新图仍为 `accepted:false`
，并不宣称本人替换、换标题或跨比例生图已验收。
