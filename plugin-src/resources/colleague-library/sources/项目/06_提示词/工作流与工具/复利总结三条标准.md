{{任务名}}已经完成，现在做一次总结，必须同时满足以下三条标准，缺一条就重写：

1. **压缩到通用层**：不要写只在这个项目里才有用的细节，要提炼出换一个项目、换一个场景也能用的原则或方法。
2. **站在上次经验基础上**：如果这类任务之前做过，要说清楚这次比上次好在哪里，还有哪些地方可以在下次继续叠加，不要每次从零开始想。
3. **必须指向下一次的具体行动**：每一条总结都要能回答"下次遇到类似情况，我会做什么不同的事"。如果一条总结回答不出这个问题，就删掉重写，不要写没有行动改变的漂亮话。

写完之后，你自己判断：这次的经验值不值得写成一条可以直接复用的 skill？如果值得，直接写出来。
