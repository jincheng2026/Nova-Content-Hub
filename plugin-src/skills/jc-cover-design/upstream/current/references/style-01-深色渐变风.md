# 风格一：电影事件隐喻风

旧名「深色渐变风」。深色只是事件场景的结果，不是风格本身。该风格把抽象观点翻译成一张正在发生的电影事件。

## 视觉身份

- 视觉载体：电影海报、新闻事件定格、纪实概念摄影
- 构图主依据：`examples.md` 中动作关系最接近的完整案例
- 材质辅助：`CM-01`，只做文字拆解，不继承遮挡后的空洞构图
- 绝对主角：一个巨大的事件、物件或动作
- 人物任务：观察、见证、阻挡、揭秘或参与事件
- 标题：进入暗部负形，或沿事件方向形成行动字块

## 适合

- 抽象机制、反直觉观点、行业加速、风险、过载、转折
- 能被翻译成火箭、流水线、洪流、闸门、燃烧、坠落、开门等动作的内容

## 不适合

- 需要看清大量真实 UI 的产品教程
- 只有功能列表、没有事件关系的内容

## 视觉命题模板

```text
[巨大主体]正在[明确动作]，
[另一个对象]因此发生[冲突／结果]，
观众记住的轮廓是[单一轮廓]。
```

例：

> 高速任务传送带不断把待判断事项推向一扇人脑闸门，闸门被压到红色过载。

## 材质合同

- 写实或准写实电影摄影
- 深色来自夜景、烟雾、背光、工业空间或巨大暗部
- 主色最多 2 种，另加 1 个行动强调色
- 允许真实火焰、烟雾、运动模糊、硬边轮廓光
- 不出现玻璃 UI、悬浮面板、功能图标栏、HUD、代码雨
- 不用柔和蓝紫渐变代替场景

## 标题几何

- 标题占画面约 28%～38%
- 最大冲突词或结果词占标题重量 50% 以上
- 标题放在事件留下的暗部负形中，不横跨最复杂区域
- 可以使用粗黑体、工业字、红色行动笔刷；不使用发光描边
- 引题和副标题并入同一个标题组

## 构图骨架

### A. 垂直事件

- 巨大主体从下向上或从上向下贯穿画面
- 标题位于另一侧暗部
- 人物位于下方边缘，观察或指向事件

### B. 对角事件

- 事件沿左下到右上或左上到右下运动
- 标题顺着动作方向排布
- 人物与事件形成阻挡、揭示或见证关系

## 人物规则

- 常规半身可见高度 35%～45%、宽度 28%～40%
- 人物不得只是站在角落指向一块面板
- 眼神、手势和身体方向必须响应事件

## 硬禁止

- 深蓝渐变＋蓝色发光边缘
- 仪表盘、盾牌、靶心、功能图标
- 多张证据卡片
- 用一块黑色大屏冒充电影事件
- 标题、人物、内容平均分成三段

## 提示词骨架

```text
3:4 竖版电影事件海报。

视觉命题：[一句具体事件]。

[场景时间、空间、光线]，
[巨大主体]位于[位置]，正在[动作]，
[动作造成的冲突或结果]清楚可见，
整个画面只有一个事件焦点，轮廓在手机缩略图中仍可辨认。

参考图1的用户人物位于[位置]，可见高度约[35%-45%]，
执行[观察／阻挡／揭示／参与]动作，
手势、视线和身体方向共同响应事件，
人物、事件和标题在同一次构图中形成遮挡与纵深。

材质为写实电影摄影，[主色]为主，[强调色]只用于[行动／结果]。
不放任何 UI 面板和功能图标。

标题组位于[暗部负形位置]：
“[指定文案及分级]”，
[最大关键词]形成最大字块，其余文案降为引题和副标题，
身份与参考图1一致。
```
