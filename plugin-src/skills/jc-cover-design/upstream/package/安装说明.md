# 四个 Skill 安装说明

压缩包里有四个 Skill：

- `jc-zhuanxie`：把本地音视频转成校正过错别字的逐字稿，用火山引擎豆包语音。
- `jc-review-page`：把一份原稿和一批修改建议做成左右两栏的审稿网页，可以在页面上直接改字、逐条采纳。
- `jc-cover-design`：生成 3:4 竖版中文视频封面，带 14 种风格和案例图。
- `jc-kepu-video`：写 AI 科普短视频稿，先定叙事、再定框架、再一段一段写。

## 怎么装

把下面这段话复制，连同这个压缩包一起发给你自己的 AI（Claude Code 或 Codex 都行）：

```text
帮我安装同事发来的 4 个 Skill：jc-zhuanxie、jc-review-page、jc-cover-design、jc-kepu-video，压缩包叫 jc-skills-4个.zip（我刚发给你；找不到就去「下载」文件夹和桌面找这个名字）。

1. 先查清楚你是 Claude Code 还是 Codex，以及你读取 Skill 的目录（Claude Code 是 ~/.claude/skills/，Codex 是 ~/.codex/skills/ 或 ~/.agents/skills/，以实际为准）。这台电脑上两个都装了就两边都装。
2. 解压后把四个 Skill 文件夹原样放进 Skill 目录。已经有同名 Skill 的，先把旧的改名备份，再放新的。
3. 这些 Skill 是从原作者电脑上拷来的，里面写死了 /Users/hejincheng/ 开头的路径。凡是指向 Skill 自己脚本的路径，改成这台电脑上的实际安装位置；指向原作者资料库的路径（「第二大脑」「内容数据统计」这类）不要改，等用到时告诉我那部分资料不在这台电脑上。
4. 检查并补齐依赖：python3 和 ffmpeg（转写要用），缺什么直接装，需要我输电脑密码时提醒我。
5. 运行 python3 <jc-zhuanxie 所在目录>/scripts/volc_asr.py --check，看转写能不能用。不能用的话，停下来用一句话告诉我：去火山引擎控制台开通豆包语音「录音文件识别标准版 2.0」，复制它的 API Key 发给你（注意不是 ark- 开头的方舟密钥）。我发给你以后，写进 ~/.config/secrets/volc-speech.env，格式是 VOLC_SPEECH_API_KEY=密钥，回复里不要显示密钥，然后再跑一次 --check。
6. 验收：用 jc-review-page 的脚本做一个有三条修改建议的测试审稿页，在浏览器里打开给我看；volc_asr.py --check 通过；在新会话里确认这四个 Skill 都能被识别到。

做完只告诉我结果：装在哪、哪几个已经能直接用、还差什么。
```

## 用之前要知道的

- **转写要自己的密钥。** 压缩包里不带任何密钥。`jc-zhuanxie` 需要火山引擎豆包语音的 API Key，按量计费，测试时只截几十秒的片段。原作者电脑上还有一个本地备用转写模型，你的电脑没装也不影响，火山能用就行。
- **封面默认用原作者本人的照片。** `jc-cover-design/assets/` 里的 `my-face*.JPG`、`my-face.png` 是锦成的照片，封面人物默认就是他。要给别人做封面，把这几张换成那个人的照片，并改 `jc-cover-design/config.md` 里的说明。生图需要你的 AI 能调用生图工具（原配置是 GPT-Image 2）。
- **科普写稿用来搜参考的逐字稿已经带上了。** `jc-kepu-video` 每写一段前，会用 `scripts/find_refs.py` 找别人怎么讲这一处。压缩包里的 `jc-kepu-video/refs-data/` 是 53 个对标账号、520 条逐字稿的纯文字副本（2026-10-28 导出），脚本在你电脑上找不到原作者的素材库时会自动改读这份，不用另外设置。装好后可以让 AI 跑一下 `python3 <jc-kepu-video 所在目录>/scripts/find_refs.py --stats`，最后一行显示「共 520 条逐字稿，53 个账号」就是能用了。这份副本不会自动更新，原作者素材库里新加的逐字稿要重新导出一次再发给你。`references/patterns.md`（35 条「讲明白的范式」）也已随包带上。
- **有些地方会提到别的 Skill。** 比如「教程视频交给 jc-jiaocheng-video」「发布收尾交给 jc-publish-closeout」，这些没有打包，只是告诉 AI 哪类活不归这个 Skill 管，不装也不影响这四个使用。
