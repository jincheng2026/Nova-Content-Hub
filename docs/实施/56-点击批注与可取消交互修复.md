## 本轮实际问题与修复

- **复选框无法取消**：Semi Checkbox 自己处理点击，外层原生 label 又把点击转发给内部 input，一次鼠标点击触发两次。移除12处外层 label 激活，文字和样张图直接作为 Checkbox children。收藏筛选、比较、本人声明、资料、内容/合集渠道使用同一正确方式；只看收藏属于视图切换，不写库，不因收起备注而永久锁住。
- **批注偏位和图片显示**：点击检测与标记使用同一个真实原图容器，完整 contain 展示。点击处就近弹出输入，确认/取消；右侧只列已确认位置，可编辑/删除，整体要求选填。未确认的浮动填写也可收起恢复。历史图片、候选与发布快照不覆盖。
- **模板排版**：1280宽窗口五列图片画廊，图片下只有名称/组数；详情收纳版本、说明、学习与还原，悬停和键盘焦点可使用模板。横图以模糊背景填充但完整原图不裁切。照片/默认配置保留弹窗入口。
- **输入提示对齐**：清除通用原生 input padding 对 Semi 固定高度输入的干扰，搜索文字垂直居中、左对齐。
- **内容读取性能**：自动读封面返回实时 assets/content 后，不再紧接一次无必要的全库扫描。保持串行队列、状态检查及前台/外部文件变化完整刷新；没有增加持久缓存。实际隔离 Electron 同一场景，workspace 3→2、library 4→3、assets 5→4；不把并发机器波动包装成固定耗时提升。
