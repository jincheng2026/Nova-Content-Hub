# 都市暮光叠字摄影风

## 风格拆解

1. **底**：整页使用全幅摄影画面，不铺纯色底；上部用浅灰蓝到淡粉紫的暮光雾化渐变形成留白，下部保留清晰、密集的真实场景。
2. **线与色**：摄影质感清晰克制，阴影以深海军蓝、蓝绿色为主，高光带少量珊瑚粉和淡紫色。整体低饱和、冷色占约 80%，暖色只出现在天际和局部灯光。
3. **字**：核心标题使用超大号、极粗、现代无衬线字，横跨画面中上部，并以低透明度叠在景物上；辅助文字小而疏，居中排布，字距较宽。
4. **信息元素统一律**：不用手绘卡片、图标和装饰道具；论点直接压在画面留白或暗部，用细线、透明度和位置建立层级。
5. **版式骨架**：上部约 35% 是雾化留白和标题，下部约 65% 是主体摄影场景；画面最外缘用极细深蓝边线收住，结论放在底部窄条区域。
6. **隐喻习惯**：使用真实、具有尺度感的场景承载抽象关系，如牌桌、赛场、道路、楼群、桥梁、会议室和生产现场；不照搬参考图里的城市或地标。
7. **角落与水印**：不放盆栽、图钉等手账装饰；左下角保留小号、低透明度「锦成」水印。

## 风格锁 Style Lock

```text
高端城市杂志开场页与品牌纪录片海报结合的中文知识幻灯片，整页采用电影级真实摄影。画面以深海军蓝、蓝绿色和冷灰色为主，远处暮光加入少量淡粉紫与珊瑚色，低饱和、高动态范围，空气中有柔和薄雾。画面上部较亮、较空，下部细节清晰、层次密集。核心标题使用超大号极粗现代无衬线字体，低透明度横跨画面中上部，与真实场景发生叠压；其他文字使用纤细、克制、字距较宽的现代中文字体。信息直接排在留白和暗部，不使用卡片、手绘图标或装饰插画。画面最外缘只有极细深蓝边线。左下角有小号、低透明度「锦成」水印。
```

## 配色与视觉元素

| 用途 | 颜色 | 近似值 |
| --- | --- | --- |
| 深色主体 | 深海军蓝 | `#12385A` |
| 冷色中间调 | 蓝绿色 | `#246B83` |
| 雾化天空 | 浅灰蓝 | `#D9E3EE` |
| 暮光高光 | 淡粉紫 | `#E5BAC8` |
| 正文 | 雾白或深蓝 | `#EEF3F7` / `#234E73` |
