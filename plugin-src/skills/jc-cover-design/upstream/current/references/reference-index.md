# 参考来源索引

参考分三层，优先级不得颠倒。

## A. 完整案例：默认主依据

- `references/examples.md`：12 组完整提示词，负责空间关系和动作细节。
- `assets/examples/`：8 张完整成品，负责整体审美、标题体量、密度和视觉层次。

先用 `view_image` 观察完整成品。含其他真人时，只转译成文字案例卡，不与用户人脸一起输入模型。

## B. 风格文件：材质与边界

对应 `style-XX-*.md` 负责规定材质、字体、色彩功能和禁止项。风格文件不能替代完整案例的空间骨架。

## 使用边界

- 完整案例只学习关系，不复制博主身份、账号标识和逐字标题。
- 含其他真人的原始案例只用 `view_image` 观察和文字拆解。
- 安全图不是「可直接输入」的自动许可；先检查是否仍残留可识别人脸或破坏构图。
- 真人封面默认输入用户唯一身份参考和必要内容素材，用文字描述案例结构，整体生成。
- 风格 6、11 的已通过用户成品是本 Skill 的黄金基线；修改这两个模板时必须先证明不会降低现有质量。
