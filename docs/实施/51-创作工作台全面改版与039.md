## 本轮产品行为

- 总览：日期、当天已发进度、本周数量；左侧下一条及今明日队列，右侧创作待办和内容/合集。发布、复制与下载分开，发布按钮进入真实计划管理，不自动发平台。
- 内容：新建内容、新建合集；合集封面/成员数量/日期，内容列表展示封面、渠道、计划时间与发布进度；没有旅游物料字段。合集编辑、成员、回收继续走原核心。
- 日程：可见名称统一为“日程”，内部 calendar 路由与 IPC 保持兼容。月格显示少量时间与标题，周七列显示图文；分钟明确时显示 HH:mm，仅日期保留“时间待定”。新计划默认可编辑的 09:00 与本机时区，必须保存才写入。明确时刻以本机时区投影，原计划、发布快照及其原时区不被改写；本地分钟保留原记录时区，不推算未知时刻。
- 设置：两列个人信息/照片/内容库和插件、全局助手/本机偏好；无需账号。昵称、方向、目标读者与介绍使用既有 profile 和 marks，保留其他标记及头像引用。照片导入默认未声明为本人；生成仍由用户明确选择。技术恢复与排错折叠，保护未保存填写。
- 封面：按请求/尝试批次保留全部候选，统一编号，选用、收藏、备注、下载清楚。缩略图使用同源模糊背景和完整原图，保持原图字节。唯一当前全局助手继续入口，模板/人物/张数/比例为主体，额外要求与资料折叠；资料默认不带。
- 提示词：由内容进入后可直接“返回关联内容正文”，重新读取最新保存内容并命中正文页；关联由用户明确指定，失效不偷换，正文/提示词草稿 guard 保留。助手答案不会自动写回正文。
- 内置资源：五组127张同事非测试样张与26条提示词完整吸收；加原资源合计20组模板、157张风格图、52条提示词。来源、字节与边界见 [50](50-内置模板与提示词全量吸收.md)。不复制本人照片与私人背景，不伪造 AI 或人工验收。
- 设计方法：核对 huashu-design 固定提交和 MIT 许可，按需吸收证据、阅读层级、构图分支和生成复查方法，未安装上游或运行其脚本。见 [49](49-参考工作台与设计能力吸收方案.md)。
- 品牌：Dock/安装/导航保持批准的 N 品牌；macOS 菜单栏新增透明单色 N，18/36 像素并按系统 Template 方式着色，Windows继续彩色托盘。
