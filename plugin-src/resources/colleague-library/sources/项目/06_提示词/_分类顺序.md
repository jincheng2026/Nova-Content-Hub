# 分类顺序

工作台「提示词」页的分类栏按这里的顺序从左到右排，表示一条从提问到产出再到回看自己的流程。改顺序只改这个文件；这里没写到的分类会排在最后。破折号后面是这一步在做什么，页面上悬停分类会显示。

1. 问清问题 — 先搞清自己到底在问什么
2. 写提示词 — 把想清楚的问题写成 AI 能执行的提示词
3. 学习 — 弄懂陌生的概念、作品和领域，核查说法真假
4. 解决问题 — 多视角、回到本质、跨领域找解法
5. 思考与决策 — 方案都有道理时，用框架做决定或先做小实验
6. 内容创作 — 把决定做成标题、开头、脚本和人设
7. 工作流与工具 — 恢复工作状态、打包工具，把事做完
8. 认识自己 — 回头看自己的天赋和人生方向
