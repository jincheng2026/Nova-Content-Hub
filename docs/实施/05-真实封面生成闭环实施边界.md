# 真实封面生成闭环：下一实施单元

日期：2026-10-17。状态：Astra high 只读设计已收敛，尚未实现或验收。旧原型的请求包继续 `executable:false`，不得修改标记来冒充正式执行器。

## 要验证的实际业务

一条内容选好模板组、本人照或“这次不放人物”，固定文字、准确像素和数量；宿主接单并读取真实文件，生成图片后交回，工作台完整校验整批，登记为待人工挑选的候选。打开助手、预填、Stop Hook 和文件出现都不是生图完成证据。

首个消费者采用独立实验运行 CLI 与配套 Skill，供后续 Electron 主进程共用。库根必须由显式绑定或 CLI 参数提供，不从 cwd、深链或请求中的任意路径推断。鉴权构建缺少可信校验时拒绝执行；测试许可和免鉴权实验构建不能代替正式权益。

## 保存与提交

- 不新增另一份可变任务真源。内容记录保存 `coverJobs` 的引用和有限状态；完整请求、正文快照、尝试交接、原始回执与校验报告在 `内容/<id>/封面任务/<requestId>/` 下保存为不可变包。
- 请求固定库/内容 ID、正文原字节 hash、标题、资料、模板 ID/版本/packageHash、选入样张 hash、本人照 ID/hash 或 null、实际提示文字、准确尺寸、数量和格式。宿主读实际图片后才记接单，不能只收到文件名。
- 请求输入变化新建 request；相同输入重试或换宿主新建 attempt，记录来源并在同一内容事务中切换唯一 activeAttempt。历史输出、候选与已选封面保留；旧尝试迟到不得并入新轮次。
- 不可信收件只接收固定字段与收件目录内文件名；拒绝绝对路径、穿越、URL、symlink 和未知字段。先稳定复制，再真实完整解码，限制字节/像素与动画，核对准确尺寸、数量、hash 去重和归属。
- 回执、核心校验报告与全部资产先安装；全部候选和 attempt 完成状态在一笔 content 事务中登记。相同回执返回原候选；同 attempt 换回执冲突。少图、多图、坏图、旧尝试和输入过期保留现场并返回具体错误，不部分登记。
- 技术通过只证明文件与请求一致，人物、文字和视觉质量仍待用户确认。不能沿用目前 `decoded:false` 的 header 检测冒充完整解码。

核心只增加创建请求/尝试、接单、读取上下文、整批提交、失败、取消的业务入口，继续复用现有锁、事务和恢复。不得向插件或页面开放通用 JSON 编辑。新增持久状态必须明确内容/库版本兼容与旧写入器屏障，不增加通用迁移框架。

## 必须取得的证据

先用真实临时库验证正常整批、重复回执、输入变更、重试/换宿主、迟到结果、坏图/截断图、尺寸/数量、路径边界与提交前崩溃。然后分别证明两个宿主可以调用随包 CLI、读取选入参考图片、取得真实生成本地文件并调用提交。手动下载上传可以作为明确的备用方式，但不能记录成自动闭环验收通过。

最终仍按 Windows × WorkBuddy、Windows × Codex、macOS × WorkBuddy、macOS × Codex 四组合复验，并验证安装、权限拒绝、中断、重开和升级。此单元不替代整库备份、原型数据迁移、正式授权、Electron 页面、安全与发行验收。
