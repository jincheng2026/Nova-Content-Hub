# 收藏构图参考：源码组件核验

制作封面在模板样张下提供「参考构图（选填，来自收藏）」：当前库中活跃内容与合集的收藏候选，按现有列表组件分页、缩略图懒加载，默认不勾选。选值固定来源类型、来源 ID、候选 ID 与资产摘要；切换内容清空，刷新保留。

仅点击生成时重新读取库，核验来源仍活跃、仍收藏且摘要未变，并保持目标内容的原 editToken 冲突保护。明确所选原图通过现有 attachMaterial 保存为本篇 reference 资料，名称稳定且不猜扩展名；已有同角色、名称、摘要的可用资料直接复用，逐份续接返回的新 token。部分添加后失败保留选择，重试跳过已添加项。普通生成和批注修改使用同一规则；批注原图继续独立保留。取消勾选后不自动带入之前保存的构图资料。

prompt 明确收藏图只参考构图；模板管风格，本人照片独立，禁止照抄旧标题或人物。选中来源失效或缩略图加载失败时保留明确选择、阻止生成并允许取消。资料总数在写入前检查 100 份上限；普通生成与批注修改的完整 prompt 均在任何附加资料写入前检查 30000 字上限。

验证命令（退出 0）：

```sh
node workbench/scripts/cover-composition-ui-probe.mjs
npm run typecheck:renderer --prefix workbench
node --check workbench/scripts/cover-composition-ui-probe.mjs
```

一个 1280×860 实际 React/Semi/CoverPanel 窗口，以独立 Electron 用户目录和合成 bridge 验证：空选无附加读取／写入；跨内容与合集显式选择；25 项只挂载一页 20 张；两次添加的第二次失败后保留第一份并去重重试、串联 editToken；取消不夹带旧资料；刷新与生成前取消收藏的失效保护；外部目标编辑不能跳过 CAS；图片失败保留选择并可取消。[两项勾选布局](selected-favorites.png)。

范围：组件交互、参数与合成 CAS 续接。未执行真实助手生成、真实库写入、全量测试或其他平台／安装包验收；后台现有资料与固定请求链路的真实核验由独立 native 检查负责。
