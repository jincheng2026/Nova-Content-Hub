# 首次配置

## 选定内容项目根目录

本 Skill 不带任何其他人的项目路径。三种方式选一种：

1. 让用户明确给出内容项目根目录，验证目录存在且可写后，再设为 `JC_CONTENT_ROOT`。
2. 给当前进程设置 `JC_CONTENT_ROOT` 环境变量。
3. 每次调用脚本时明确传入 `--visible-root` 和 `--inbox-root`。

不得把项目路径写死成开发者的用户名或主目录。只有用户明确确认当前工作目录就是项目根目录时，才可使用默认 cwd。

## 只读体检

在项目根目录中执行：

```bash
python3 <jc-chendian 安装目录>/scripts/capture_decision.py --list-pending
```

首次返回 `[]` 就是正常。这个检查不创建文件。

## 写入验收

只在当前会话确实已有用户确认的内容时写入。首次成功后必须回读：

- `内容数据统计/待发布沉淀/<内容包>/内容.md`；
- `内容数据统计/待发布沉淀/<内容包>/.system/manifest.json`。

成功信号：同一内容再次追加会命中原 `content_id`，完全重复调用不新增事件。
