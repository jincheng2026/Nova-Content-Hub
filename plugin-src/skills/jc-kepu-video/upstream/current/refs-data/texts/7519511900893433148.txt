Hello，大家好。今天还是想去跟大家聊一下 AI Agent，重点呢去聊一下 AI Agent 的三个核心能力。

第一个呢，就是经验学习，意思就是 AI Agent 根据过往的交互来调整它下一步的行为模式。

第二个呢，就是工具调用，通过调用外部的功能来拓展自身的能力边界。

第三个呢，就是规划能力，制定多步骤的计划，然后再去动态调整。

这三项能力呢，构成了构建高级 AI Agent 的一个基础，每一项都涉及到复杂的技术创新和解决方案。

首先来讲一下根据经验来调整行为的模式。Agent 呢，先拿到用户的一个目标以及当前的一个环境观测，这样呢，它就能够去给出自己的第一步行动。得到第一步行动以后，它就会产生第二个观测。得到第二个观测，然后 Agent 会反思这个观测或者这个行为，是不是能够去达到我们的目标。如果达不到，OK，我再去换第二个行动。

当你开始重复跟它交互更多内容的时候，那么你就会有新的观测三，然后再是执行三，然后再是观测四，然后执行四，等等等等，一直到可能一千。

那这样的话，AI Agent 因为它是需要去通过记忆，或者说通过它的经验去做下一步判断的。OK，那我需要去把所有的这些内容给当作我们的经验，作为判断。但我之前有讲过，其实大模型它是没有记忆的，它需要的是一个上下文窗口。我们目前可能最多的就是 128K，但当 Agent 和我们交互的内容越来越多的时候，它肯定会超过 128K。

所以那中间就会涉及到几个我们需要去改进的点。

第一个点就是，我怎么去把跟我当前行为相关的内容给找到。比如说我们执行 Action 1 的时候，我们从这些经验里面去找，找到跟我们 Action 1 相关的一个内容，然后把它给放到我们的 Context Window 里面。其实这个就叫作 RAG，就是从我们以前的知识库，或者从以前的内容里面，去检索出跟我们相关、跟当前执行相关的内容，然后放到上下文窗口，当作我们的条件。OK，这是第一步，就是检索。

第二步很重要的就是，因为我这边会涉及到一个知识库，那怎么去把关键的信息给放到知识库里面，这也是个很关键的因素。我们不可能每一个琐事都把它给放到知识库。比如说我跟 AI Agent 去聊「你好、我好」，一直聊了一千轮，我不可能把这些都放进去。

我更多的是会把「明天我可能会约一个朋友吃饭」，或者说「明天我想去写一个 PPT」这样的一个信息，把它给放到我们的知识库里面。这样的话，在我下一次跟 AI Agent 做交互的时候，我就能够从这个数据库里面找到最有效的信息来解决我们的问题。所以这个涉及到的就是写入的方式。

第三个关键点就是，我们可以把这个知识库重新构建得格式更好。比如说当前我可能是一个文本一个文本地构建，但是我们其实可以通过知识图谱这样的方式去做构建。

这个就是经验学习的几个关键点。第一个就是，我在做下一步执行的时候，需要通过一个很好的手段，去把跟我当前执行相关的内容给检索出来，也就是 RAG。第二个就是，我自己是有一个知识库的，但是我需要去让我的知识库里面有足够有效的信息，而不是各种的冗余信息，所以我们的写入也需要有一定策略。第三个呢，就是针对这个知识库，我们可以通过不同的构建方式，比如说通过知识图谱或者通过各种数据库的方式去做优化。

OK，第二个我要讲的 AI Agent 的关键点呢，就是工具调用。有经验，或者说我有一个非常厉害的大语言模型的大脑，其实还不够。我们还需要它有一个能够去调用外部工具的能力，因为外部工具能够极大地去拓展 AI Agent 的能力边界，让它能够去执行原本没法去完成的内容。

而且呢，当我们有一些私域的数据，或者说我们企业有一些关键的信息的时候，我们需要自己去定制化地开发一些工具去获取这些信息。那这个时候，AI Agent 能够真实地去为我们赋能。

另外，以人来作比方，我们都会用，比如说用笔、用锤子、用各种的工具。其实 AI Agent 用工具，就相当于希望 AI 能够像人一样去做到各种的事情。

我们举几个大语言模型一直在用的工具。第一个呢，就是搜索引擎。比如你现在用 GPT 或者用 DeepSeek，它其中有个 Web 选项，其实这个就相当于你去调用搜索引擎。

第二个呢，就是编程环境。比如说我们可以用 Python、C、C++ 去灵活地执行计算和数据处理。

第三呢，大语言模型它是一个 AI 模型，但是它也能够去调用其他的 AI 模型。比如 Claude 4.0 是 3.7 的一个迭代版本，但是它可能写代码的能力并没有 3.7 高。那这样的话，Claude 4.0 可以作为一个大脑，然后在执行任务碰到需要去写代码的时候，它可能会调用 Claude 3.7 去做。

第四个呢，就是它会去调用 API。比如说各种去查天气、写邮件的 API，然后能让 AI Agent 确实地去做到我们真正需要它做的事情。

第三个点就是 AI Agent 的规划能力。这个是 AI Agent 的一个智慧核心，它主要包含四块。

第一个呢，就是去做分析，通过对用户目标的分析来理解最终期望去达到的一个状态。

第二个呢，就是去制定计划。比如说针对这个目标，我可能会去定，我先第一步做什么，第二步做什么，第三步做什么。

OK，制定完计划以后，第三步就是执行。比如说一、二、三步我列好了，然后去做一、二、三步就好了。

之后可能会发现，我做完一、二步，发现我的目标跑偏了，那这个时候应该怎么办？这个时候就需要去调整了，去调整我们的这个计划，然后可能会换一个执行方式。

举个例子，比如我想让它去写一个我去上海的旅游计划，然后我有几个需求。第一个，我需要去打卡所有上海的景点。另外呢，我需要我的景点规划，每次我走的路不超过五公里。第三个，我在上海订的酒店可能不超过五百块钱。

我给了 AI Agent 这个目标以后，AI Agent 会给我去列出一个很详细的规划。比如它会去写第一步去哪里，然后第二步去哪里，一直到第 N 步去哪里。

但是可能在上海会碰到一些交通修路，或者说一些管制的情况。那这个时候，我们比如说执行到 Action 2 的时候，可能发现我们的目标已经跑偏了。那这个时候怎么办？AI Agent 立刻就需要去制定一个 Plan 2，这个呢，就相当于另一个执行序列，Action 2'、Action 3'，一直到 Action N'。然后呢，通过循环反复地去调整，可能会有 Plan 3，一直到 Plan N，从而最终能够去达到我们想要的目标。

所以最后总结一下，Agent 它是有三个要素。

第一个就是经验。经验呢，能够去让 AI Agent 有足够的知识，能够知道我是一个什么样的人，我会给它去提出什么样的需求，然后它怎么去满足我的需求。所以这里会涉及到几个方面。第一个就是从我过去的交互里面去做检索。第二个就是我跟它过去的交互需要去写入库，怎么去高效写入库。第三个就是我们的这个数据库需要一个很好的呈现方式，比如说需要有个 Graph 或者图，然后能够快速地去做检索以及快速地去做整理。

第二个要素呢，就是工具。工具是能够去让 AI Agent 拓展它能力的一个关键因素。只有 AI Agent 能够去调用工具了，我们才能够去定义它作为一个真正的助理。比如当这个 AI Agent 不能去调用 API 的时候，我想让它去发邮件，它也只能去给我写一个好的邮件，但是它并不能帮我发出来，最后一步还是需要我去做。

第三个呢，就是规划。规划是 AI Agent 的一个智慧核心。像我们人类一样，我们去做每一个事情的时候，自己都会在脑海里面去想一、二、三步，然后可能在第二步的时候遇到了突发情况，我们需要去灵活调整我们的一、二、三步。那对于 AI Agent 来说其实也是一样，我们需要有一个很强的规划能力，可以去应对不同场景的调整，然后最终去达到我们的目标。

OK，所以这就是整个 AI Agent 的三个要素。如果大家能够去把这三个要素设计得非常完善的话，其实我觉得就已经离一个很好的企业级 AI Agent 不远了。
