# 对照页怎么用

只在全篇段落都定了以后用，为的是让锦成一段一屏地通读、改稿、批注。样子照 `05_内容草稿/已做/T018_七个AI词一条线/T018_逐字稿对照.html`：左边是几位博主讲这一处的原文（只读），右边蓝框是锦成版（直接改，自动保存），同一种颜色是同一类讲法，点句子能看每个人各自怎么讲，下划线是连续字词相同，黄色区是批注。没有通用版。

## 逐字稿.md 的格式

```markdown
# T0xx 题名
## 段：开头
### 锦成版
（这一段定稿）
### 大李
（他讲这一处的原文摘录）
### 姜学长
（同上）
### 不喝九
没有讲过
## 段：大模型
……
```

段按框架顺序，段名和框架一致；参考列的顺序按第一次出现的顺序；某列缺省或写「没有讲过」就显示为空。参考原文用第 3 步摆过的那几段，不另找。

## 标句子在做哪类讲法

参考原文里用 `{{类|文字}}` 标，页面按类上色，右上角可以隐藏。十类：叫法（给它什么名字）、比喻（拿什么打比方）、定义（一句话说它是什么）、场景（从观众熟悉的一件事进）、对照（以前怎样现在怎样）、产品（点名手边产品）、判断（要不要用、要不要花钱）、我（说自己的经历）、过渡（接到下一个词）、动作（让观众做一件事）。一句只标一类，不嵌套。锦成版不用标，页面会拿参考里标过的句子去对。类名写错脚本会报错并列出可用的类。

## 生成和启动

```bash
python3 ~/.claude/skills/jc-kepu-video/scripts/make_compare_page.py 逐字稿.md 对照页.html
python3 ~/.claude/skills/jc-kepu-video/scripts/compare_server.py --page 对照页.html --port 8767
```

`python3 ~/.claude/skills/jc-kepu-video/scripts/register_page.py <内容包> 对照页.html <端口>` 只把 `对照页服务.py` 复制进内容包并打印启动命令，不再登记第二大脑首页。生成后手动起服务，在聊天里给锦成链接；起之前用 lsof 看一眼端口有没有被占用。

对照页已经存在时再生成，会保留锦成版、批注、历史和 revision，只更新参考和标注。页面：一段一屏，顶部段落导航和「通读全文」；右边锦成版默认可编辑，改了 1.2 秒后自动保存；「看同色对照」切到只读视图看颜色和下划线；批注区默认收起，点「写批注」；批注里写了像稿子的文字会提示「挪到锦成版」。

## 读回

```bash
python3 ~/.claude/skills/jc-kepu-video/scripts/compare_server.py --page 对照页.html --dump
```

输出每段的锦成版、批注、生成时的底稿和改动历史。AI 拿它写改稿日志、最终稿和提词器版。

## 注意

- 只在本机 127.0.0.1 开，不挂公网。
- AI 只读锦成版，不改。
- 一个内容包一个端口，同时开两个页面换端口。
- 服务不常驻，锦成说「继续改 T0xx」时先检查端口再起。
