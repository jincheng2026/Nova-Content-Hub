# 调研方法

适用于账号研究、选题搜索、作品表现对照和已获授权的评论研究。报告提交读同目录的 [报告交付](report-method.md)。

## 1. 固定研究问题与采集范围

从冻结请求和已有材料提取：要支持的创作决定、平台、账号/关键词、时间范围、内容类型、目标样本及最高请求数。仅当用户要求按粉丝量或作品表现筛选时，记录其相应门槛；缺失值保留未知，原资料中的粉丝区间、美元上限或付费次数不能替代本任务设置。

已有账号、用户提供文件和当前内容引用先读，再决定是否需要采集。按共同契约的“按需澄清”解决会实质改变研究范围的决策；选样前核对所需口径已明确，或该字段与本轮目标无关。

搜索词围绕产品别名、具体动作、遇到的问题、期望结果、使用场景和可比较做法扩展。每组记扩展理由、排序、实际日期范围、游标和停止条件；同参数已有可信结果先复用。工具支持的平台/端点以共同契约和本机描述为准，其他平台可分析用户资料，不能因服务商有产品宣传就承诺可采集。

本步完成：可用一句话解释研究要帮助用户决定什么，并有可回查的实际范围与请求上限。

## 2. 选样与分母

1. 用平台作品 ID 去重，缺 ID 时用规范化来源 URL；记录它与工作台参考 UUID 的对应关系。账号用稳定账号 ID，昵称只用于显示。
2. 每条留平台、来源、作者、发布日期、采集时点、原始指标及缺失项。采集时粉丝数不代表作品发布时粉丝数，缺失指标不补零。
3. 分开判断主题是否直接相关、数据是否满足请求门槛、证据是否完整。写一句可回到原文的相关性理由。邻近选题、门槛外、数据缺失各自保留排除原因。
4. 在合格集合内按任务目的选样，列真实点赞/收藏/分享等指标及日期。比值同时给分子分母；没有可靠播放数据不计算互动率、完播率或留存率。
5. 达到目标、预算用完或继续搜索难以增加独立合格样本时停止。只有三条就报三条，没有合格样本就交零样本报告，说明实际尝试和缺口。

不把同一内容搬运、切片或转写版本算成多个独立证据。重复采集保留时点，代表记录说明采用哪个快照。跨平台指标分别计算，不能直接排成同一表现榜。

## 3. 从内容解释账号

先按真实作品整理互斥的主要内容方向；形式、工具、场景可作辅助标签。每个需要下表达结论的方向，读取一到两条代表作品的完整正文/复核字幕和适用画面；没有原文的方向明确缺口。

按三层回答并附证据：

- 身份与视角：账号如何介绍自己、凭什么获得信任。自述经历标为自述，未核实的不升级为事实。
- 持续价值：实际面向什么场景中的人，提供理解、判断、方法还是结果，关注后能持续得到什么。
- 内容选择：反复讲什么、怎样呈现、主动省略什么；简介/置顶/封面宣称是否与作品一致。

一个模式至少需要两条独立作品支持；只有一条时写单次观察。每条判断用“实际原话或画面→可能作用→成立条件→用户可测试的做法”组织。商业入口、作者宣称和可验证交易分别记录，不补收入或转化数字。

给用户的建议分可借的方法和不宜照搬的前提。个性化建议引用本人的真实定位/材料；缺这些输入时只给通用候选，不替用户编造权威身份。

## 4. 高表现与普通作品对照

优先同平台、同账号、同类型和接近发布日期的作品。说明观察截止日、作品积累时长和为什么可比，再列原始指标。样本足够时可算同期中位数；自定义时间窗和排除目标自身的规则必须公开，样本不足就不输出倍数。

对照主题、开头、推进顺序、证明、画面和已授权评论。每个差异写出双方证据，以及至少一个未控制因素，如话题热度、发布时间、账号增长或分发变化。结论落到下一条只测试哪一个可改变的做法；不同数据本身不能证明某句话带来了传播。

多条同题原稿按段落作用对齐，允许一对多或位置变化。分别记录保留、补充、删去、换例子、重排与新增事实。文字相近不等于逻辑相同，文字改写也不等于新增事实已经证实。

## 5. 评论需求分支

仅在本任务评论已授权时执行。先复用合法已有材料，追加分页仍受冻结预算限制；未授权时报告“本轮未采集评论”，继续其他研究。

保留评论所属作品、评论 ID、层级、父级/根级、原话、时间、赞数和实际回复覆盖。层级未知就标未知；没有拉到回复不等于没有回复。去掉无关噪声后，每条给一个主类用于统计，可再加辅助标签；含义不清单列，不靠关键词强行归类。

把具体困难、使用结果、质疑、领取口令和购买表达区分开。领取口令数量不等于真实需求人数，获赞不等于提问人数。问题合并时仍保留代表原话与涉及作品数。

每个问题分别核对正片是否回答、可见回复是否回答、是否还缺关键条件。作者礼貌回应或私信入口不算已解决。不能仅凭抽样写“从没人教”或推断付费意愿。

完成时列：顶层条数、回复条数、层级未知、噪声、未分类、统计分母、各主类数量与比例、是否还有未采页面。默认以已知顶层且排除噪声的评论作主类分母；改变口径必须明示。

## 6. 交付前判定

重要结论逐条区分原始事实、计算结果、分析推断、用户确认和待验证。抽查所有引用能在来源中找到；每个重复模式有独立证据，每个统计可从去重明细复算。核心资料拿不到时交范围受限的结果，而非把标题和数据包装成完整内容拆解。
