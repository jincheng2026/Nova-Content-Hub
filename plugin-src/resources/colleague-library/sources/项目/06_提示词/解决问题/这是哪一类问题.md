关于刚才这次出的问题：{{具体错误描述}}。

先不要只回答这一次具体错在哪、怎么改这一处。请往上退一步想清楚：

1. 这个问题背后到底属于哪一类问题？换句话说，如果类似的情况用不同的方式出现，会不会踩到同一个坑？
2. 这一类问题背后最根本的原因是什么？
3. 给出一个能防住这一整类问题的做法（比如一条新规则、一处检查点、一个自动化步骤），而不是只针对这一次的补丁。

把找到的根本原因和防住整类问题的做法写清楚，如果值得，写成一条可以直接复用的规则。
