# 风格十三：深色工具实测风

面向真实工具、设备和技术过程的深色编辑海报。它不是电影事件，也不是通用仪表盘。

## 视觉身份

- 视觉载体：深色科技媒体封面、真实设备实测海报、单一工具操作场景
- 构图主依据：`examples.md` 中产品操作关系最接近的完整案例
- 材质辅助：`DT-01`
- 绝对主角：一个真实产品、设备、终端窗口或清楚的技术过程
- 人物任务：操作、展示、检查或指向真实结果

## 与其他风格的边界

- 与风格 1：风格 1 是完整电影事件；本风格是工具或技术过程。
- 与风格 3A：风格 3A 强调真实产品证据和结果；本风格强调深色媒体包装与操作氛围。
- 与风格 3B：本风格不以统计图表为主。

## 使用条件

推荐池必须至少满足一项：

- 有真实产品或设备素材
- 有真实终端、代码、操作过程或结果截图
- 有可以明确画出的技术装置和动作

若只有抽象观点且没有真实工具，不进入推荐池。用户明确要求实验时，只能使用单一技术装置隐喻，不得生成假后台。

## 材质合同

- 黑色、深灰或深藏青作为大面积暗部
- 一个产品或设备具有清楚硬轮廓
- 允许窄边冷色轮廓光，但不使用满屏霓虹
- 允许真实屏幕、终端、手机、电脑和设备材质
- 辅助信息只来自真实操作过程，最多一条
- 禁止玻璃卡片墙、HUD、代码雨和多块仪表盘

## 标题几何

- 标题占画面 32%～42%
- 2～3 行紧凑字块
- 最大利益词、产品名或动作词占标题重量 50% 以上
- 主色以白色为主，只使用 1 个高饱和强调色
- 品牌标签只有真实品牌存在时才出现

## 构图骨架

### A. 设备英雄

- 单个设备或屏幕斜向占据中下方 45%～60%
- 标题压在上方暗部
- 人物从一侧操作或指向设备

### B. 真实操作

- 一个真实主窗口占画面主体
- 过程与结果在窗口内部或一条真实证据带中呈现
- 人物与鼠标、键盘、手持设备形成操作动作

## 人物规则

- 常规半身可见高度 35%～42%、宽度 28%～36%
- 人物必须操作或展示具体产品区域
- 不遮挡真实结果、产品名称和标题关键词

## 硬禁止

- 无产品时虚构 SaaS 后台
- 蓝色平板＋三块小指标成为默认主视觉
- 靶心、盾牌、漏斗和仪表组成证据列
- 深色渐变背景上漂浮无来源窗口
- 使用超过一个高饱和强调色
