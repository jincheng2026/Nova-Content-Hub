## 已确认的问题与修复

- 同名应用入口来自安装版与被 Spotlight 索引的原始构建 `.app`。先精确核对路径，再保留字节移动项目构建输出；系统索引只剩 `/Applications/自媒体工作台.app`，用户独立确认只显示一个图标。发行脚本在构建及插件完整性验证成功后归档原始 Mac 输出，DMG 路径保持稳定。旧安装恢复副本没有删除。
- 覆盖安装固定使用正式 bundle ID 和 Applications 目标；开发/受限测试版名称独立。完成事务后不因目标移走或删除而复活旧版本；仅正式 bundle 可确认正式安装事务。0.3.20 独立启动已确认完成，旧应用及内容库保持可恢复。
- 原库的空保护记录触发 LOCK_UNCERTAIN。未删除锁或关闭保护：完整保留原库，通过既有备份/还原校验创建恢复库，并由安装版正常 openLibrary 采用。恢复库可读取 3 篇内容、21 个模板和 54 条提示词（包含用户已有项目）。记录见对应恢复收据。
- 单文件图片/资料导出统一对目标父目录做真实路径校验，拒绝写入内容库内部及其别名，防止原图或业务文件被覆盖。

## 合集范围

合集只是内容的分类入口，类似文件夹：显示名称、成员数、成员封面；打开后显示统一的组内内容列表，支持组内搜索和点击进入单篇详情。单篇返回合集保留查询。正文、封面制作和发布管理仍在单篇详情。

新建与重命名只填写名称；管理成员、移出和回收合集不删除原内容。沿用现有 collection/memberIds，不迁移或清空旧正文、渠道、日期、历史发布字段。未改变的历史停用渠道允许保留，真正改变渠道仍校验有效性，mutation digest 和 CAS 保护保持不变。

新增页面审查发现的并发边界必须随功能验证：编辑器固定打开时的对象及 token；刷新不以新 token 提交旧成员/旧名称；外部回收合集不销毁未保存输入。不能只测正常保存。

给同事的导出目录只含安装镜像、安装使用说明和 SHA256 校验文件；内置 20 个模板、52 条提示词及科技姐模板的两张真实示例封面。研发记录、测试脚本、诊断库、安装恢复事务和真实验收临时库留在工作区，不随交付导出。

## 0.3.22 回收站与增长管理

合集回收后，内容页回收站原先只展示单篇内容，导致已回收合集没有入口。现在同时展示回收内容和回收合集，支持按名称搜索和恢复合集。恢复沿用原有成员关系，不改写成员正文、封面或计划；成员自身已回收时明确提示先处理成员。用户的回收操作没有自动撤销。

管理成员改为标准表格，支持名称与正文搜索、已选/未选筛选、排序、每页20/50/100项及直接跳页。完整选择独立于当前页面和搜索结果，保存继续使用打开时的CAS token。列表局部滚动，搜索、分页和保存入口保持可见。

内容、合集、照片、资料、候选、生成历史、提示词、模板、发布计划及历史均限制当前页面挂载数量；增长型选择器支持搜索和虚拟滚动。日历只构建可见日期的事件，密集日期显示完整数量入口，并分页查看当天清单；总览保留完整日程入口。发布快照与学习样张按需挂载。未改变锁、原图校验、事务恢复或权限边界。

性能证据分两层：真实React/Semi/Electron合成DTO测试用于验证DOM数量和交互；真实文件库测试另测100/500/1000条内容、每篇约2KiB正文与2条发布计划。1000条内容的三接口完整读取三轮为3.68/2.21/2.25秒，使用操作系统暖缓存，包含内置模板样张，但不包含大量生成图片。分页限制DOM，不等于磁盘读取已分页，也不是冷启动或任意数据规模的承诺。保留文件库完整校验，不以缓存掩盖外部修改。
