# JC Cover Copy

## 目标

只解决「封面上写什么」，不负责生图，不把视频标题原样搬到封面。

优先输入：

1. 定稿逐字稿或 SRT；
2. 已确定的主标题；
3. 视频里最核心的冲突、结果或判断；
4. 用户已指定的字词与禁用表达；
5. `锦成知识库/01-业务库/锦成IP内容/08-数据复盘.md`「已发布视频台账」最近 10 行：历史
   封面文字与对应 7 天数据，作为「哪类封面有效」的基线；只带结论，不整表复述。确有
   需要时才顺 `[[逐字稿条目]]` 指针取完整封面文字，最多 2 条。

输入缺少逐字稿时，不补写未经提供的事实。

## 生成流程

1. 用一句话概括：观众只看封面必须记住什么。
2. 找出一个最强张力来源：反差、损失、身份、结果或冲突，只选一个。
3. 生成 3 个不同角度的候选，不做同一句换词：
   - 判断型：直接露出作者最强判断；
   - 冲突型：突出前后反差或两种力量；
   - 结果型：突出真实可兑现的结果。
4. 按「缩略图可读性、与标题互补、忠于内容、像锦成本人」排序，选 1 个主方案。

## 硬规则

- 主文案默认 6～14 个汉字；确有必要可到 18 个字。
- 默认 1～2 行，每行只表达一个短语；不得堆成段落。
- 不使用「震惊」「必看」「速看」「干货满满」等廉价词。
- 不虚构数字、结果、身份、科学结论和因果关系。
- 不把标题完整复制到封面；标题负责让人想点，封面负责让人一眼看懂冲突。
- 用户指定文字时逐字保留，任何修改必须先说明。
- 交给 `jc-cover-design` 时，主方案文字即锁定文字，生图阶段不得擅改。

## 输出与落盘

默认输出：

```markdown
# 封面文字

## 主方案

<最终封面文字，保留实际换行>

## 一句话依据

<为什么这句最适合当前视频>

## 备选

1. <判断型或冲突型>
2. <另一种真实角度>

## 设计交接

- 锁定文字：<逐字重复主方案>
- 建议强调：<1 个最大关键词>
- 不可出现：<视频中没有的事实或视觉误导>
```

发布前由用户确认。进入正式档案时，把最终采用的真实封面文字写入当前视频的
`内容.md`「发布素材」章节；不再创建独立 `cover-copy.md`。发布后不得重新生成并冒充
已发布版本。
