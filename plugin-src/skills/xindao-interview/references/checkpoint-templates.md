# 定位检查点字段

逻辑文件为定位总览与账号包装，实际存储由共同契约中的受控checkpoint决定。以下是artifact文字的组织方式，不自行增加受校验的checkpoint/schema字段。

定位总览：
- 当前的我：状态、身份阶段、真实经历、能力及事实、熟悉的人和场景、正在学习实践、每周可用时间、表达视角、公开边界。
- 账号要说什么：状态、主题、主要读者、当前困难、讲法、可兑现价值、本人依据、一句话定位。
- 内容边界：状态、核心主题、内容支柱与依据、起步方向、扩展方向、暂不做与理由、查证规则。
- 主页呈现：状态、选定方案指针。
- 待确认：未完成字段及问题，没有则写无。
- 本次确认：全部确认/仍有待确认，真实日期，确认原话依据。

账号包装只保存用户选定方案：平台、采用方案、选择事实依据、看过对标后调整状态；头像形式/画面/避免事项；昵称及理由；简介全文、事实锚点和顺序；背景图文字和视觉；与定位一致、身份数字有依据、导流/效果承诺与最可记住真实信息的核对；待确认和本次确认日期。

每关状态可为未开始、仍有待确认、已确认(日期)。原_v0.1文件无逐关状态时，从末尾本次确认和实际字段识别，不因此新建一份。保留用户其他手写内容与历史版本；checkpoint部分更新只覆盖已确认的本关。
