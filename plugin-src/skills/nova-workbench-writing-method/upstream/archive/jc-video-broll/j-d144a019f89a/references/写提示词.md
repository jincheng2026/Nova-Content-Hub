# 写提示词

> 署名：「时间段每段不少于 3 秒」「接触后写出看得见的结果，加『禁止没接触就……』」两处写法改编自 Serge Shima 的 visual-skills（https://github.com/smixs/visual-skills ，`video/references/seedance-25.md` 第 6、11 节），许可 CC BY 4.0（https://creativecommons.org/licenses/by/4.0/ ），已译成中文并改写。
> 其余来源：视频提示词结构改自火山引擎官方 sd25-pe；四样输入和改法表部分行借自 PJ Ace 的写提示词 Skill；镜头说明改自 kaomei、zenstory（MIT）；问题表部分行改自 higgsfield（MIT）、Square-Zero-Labs（Apache-2.0）；「生成时长和成片用时分开写」只借 omni-tvc-prompts 的结构，没有搬用原文。

只写提示词，不调用生成、不评价成片。

## 输入：每次只给四样

1. 这句口播要表达什么：逐字原句，加一句情绪。
2. 画面里有谁、碰哪些东西：登记表里的 @名字。
3. 要几个镜头：默认 1 个。
4. 每张参考图管什么：默认从登记表「管什么、不管什么」两列带出。

## 输出：一份镜头说明，8 项

1. 口播原句
2. 用途：开头抓人 / 中段讲概念 / 平淡段拉注意力
3. 一句话事件：静音看画面，能说出「谁做了什么，结果怎样」
4. 开始状态和结束状态
5. 用到的图（@名字）和固定特征
6. 首帧提示词
7. 视频提示词
8. 给 Flova 的规格一行和本镜预算一行：模型、分辨率、画幅（跟成片）、生成几秒；成片用几秒、最多生成几次、什么算够用

## 首帧提示词固定写法

给 Flova 里的 GPT Image 2.5 Sunburst 出图模型。

```
<固定画风文字，原样粘贴>
@图片1 是角色参考，只采用<角色>的外观、服装和比例，不采用图里的姿势、道具和背景。
<角色固定特征，逐字>。
场景：<一句，只说在哪，当代、干净、维护良好>。
这一刻：<动作开始前一瞬间的状态，留出动作距离和空位，结果还没发生>。
画面里只有这些道具：<逐个写，数量写死>。
构图：<具体取景，例如主体到腰、头在画面上三分之一>，主体大并在画面中间，背景简单虚化，<画幅跟成片>。
画面里不出现任何文字、标志和界面字。
```

- 两个角色时，每个角色一张图、各写一句「只采用……不采用……」，固定特征各自逐字写。
- 用画风图时加一句：「@图片N 只采用材质、光线、颜色和氛围，不采用其中的人物、道具和构图。」
- 只列这一镜要碰的道具；写具体取景，不只写「中景」；不写夸奖词，媒介写成事实。

## 视频提示词固定写法

给 Seedance 2.5。

```
【生成目标】<角色>在<场景>里<一个动作>，结束时<看得见的结果>。
【参考素材】
@图片1作为首帧。
@图片2 只用于<角色>的外观和比例，不作为视频中的任何一帧，不改变首帧构图。
@图片3 只采用材质、光线、颜色和氛围，不采用其中的人物、道具和构图。
【事件】
开始时：<首帧里的状态>。
主要事件：<接近，接触，看得见的结果>；禁止没接触就<出结果>。
结束时：<结果>，人物和物体保持静止约 1 秒。
【保持一致】全程只有<数量和主体>，只有<谁>在动，同一主体始终是同一个，不重复、不分裂。<机位一句：固定机位，或只轻微跟随>。
真实微缩实拍，不是 3D 渲染。无背景音乐，只保留动作音；画面不显示字幕、文字或标牌。
```

- 固定画风文字每条都原样贴，放在【生成目标】前面；角色固定特征接在对应那张角色图的一句后面，逐字照登记表。
- 首帧已确认时只写运动、不复述画面，约 150 个汉字（不算固定画风文字和固定特征）。
- 画幅、时长、分辨率不写进正文，写在给 Flova 指令的第一行。
- 时间段默认不写数字。两个以上动作要卡先后才写，每段不少于 3 秒，主动作放第一段，不留只有运镜的空窗。

## 简单镜头四句写法

平淡段新做时用。

```
@图片1作为首帧，<角色>和参考图保持一致。
<运镜一句>。
<这 4 秒发生的一个变化>。
真实微缩实拍，不是 3D 渲染。无背景音乐，画面不显示文字。
```

## 给 Flova 的指令格式

```
Seedance 2.5，480p，<画幅>，5 秒。
以下提示词原样使用，不改写、不翻译：
<视频提示词>
```

出首帧时第一行换成「GPT Image 2.5 Sunburst，1K，<画幅>」。

## 出稿前自检 10 条

AI 自己做，只把没过的项告诉锦成。

1. 一条提示词只做一件事、一个主要动作。
2. 每张图只写一句管什么，没用上的图不上传。
3. 首帧单独一句「@图片1作为首帧」，不弱化成「构图参考」。
4. 有开始状态和结束状态，结束时停约 1 秒。
5. 没有「改成、修改、替换、删除、延长」这类词；画幅、时长、分辨率不在正文里。
6. 没有这四类难动作：食指点按、多人同时动作、「停止、熄灭」这类看不见的状态、3 秒内要做完的一连串动作。有的话按这个顺序改：难的部分摆进首帧、换物件来承担变化、拆两镜、换成停留、改字卡或口播就好。
7. 静音看能一句话说出谁做了什么、结果怎样。
8. 首帧里只有这一镜要碰的道具。
9. 没加「4K、超清、杰作」这类夸奖词，没写长串「不要」清单；否定只写配乐字幕一句、相邻风格一句、这一镜最可能出的一条错。
10. 固定画风文字一字未改；贴给 Seedance 的提示词不超过 4500 个字符，@图片 这类引用也算在内。

## 锦成原话和改法表

一次只改一处。这里是已经写进规则的一批；锦成新的否决原话先记进 `锦成原话和改法表.md`，同一改法出现两次再写进上面的自检。

| 锦成的原话 | 改哪一处 |
|---|---|
| 「看不懂在演什么」「要先学图例」 | 回画面计划换比喻，换成观众本来就懂的生活物件；不改提示词 |
| 「像流程图」「无聊」 | 换事件：要有谁碰了什么、结果改变了处境；不换画风 |
| 「中途变暗又变亮」 | 光只在开头出现，动作中不变 |
| 「动作不对」「表情不够生动」 | 加一张真实姿势照片，只采用动作姿态 |
| 「冒出真人手」「手变成夹具」 | 固定画风文字里手那一行；首帧重出 |
| 「金黄油亮」「满桌凸点」 | 固定画风文字里光和材质两行 |
| 「像塑料」「像 3D」 | 读回 Flova 实际用的提示词有没有被改写；删夸奖词；查固定画风文字第一句 |
| 「理解错情绪」「换了人」 | 给逐字原句加一句情绪；人物参考图写成最优先 |
| 「多了个东西，人去碰它」 | 回首帧删掉那个道具 |
| 「动作太晚」 | 剪辑裁掉空等；下次主动作放第一段 |
| 「手握成拳了」 | 首帧里先把手势摆好，或拆成中景抬手加特写按下两镜 |
| 「停不下来」 | 结束状态在首帧或尾帧里给看得见的证据（阀门回到关闭角度这类） |
| 「全景里看不清」 | 全景只做结果收尾，交接动作用近景 |
| 「太短」 | 生成 5 秒，剪辑只用 2 到 3 秒 |
| 「太飘、没分量」 | 写清接触点和东西的重量 |
| 「演得假」 | 写这一刻要达到什么目的，不写情绪名词 |
| 「背景太乱或太空」 | 背景只留一个具体细节 |

## 出了什么问题怎么改的表

AI 检查时查，看到什么先做什么，每次只改一处。

| 看到的问题 | 先做什么 |
|---|---|
| 出了配乐或字幕 | 不重新生成；剪辑去音轨，字幕用 Flova 去字幕或裁掉 |
| 画面里有假字 | 回首帧重做，不用视频提示词修 |
| 轻微漂移，不影响意思 | 照样用 |
| 动作晚了 1 秒左右 | 剪辑裁空等；下次主动作放第一段、每段不少于 3 秒 |
| 只有推镜、发光、晃动，没有动作 | 这一镜塞得太多，拆两镜，每镜一个动作 |
| 动作没做完 | 删一个动作或拆两镜 |
| 多人不同步 | 拆镜，或写成有先后、不整齐 |
| 没碰到就结束了 | 终点写接触点，不写距离；加「禁止没接触就……」 |
| 取景跑偏 | 写具体取景（到腰、头在上三分之一） |
| 旁边的东西跟着动 | 首帧删掉不相关的道具；「保持一致」那句写明只有谁在动 |
| 手势错 | 设计时就避开；非要不可，首帧摆好手并改成特写 |
| 角色变了 | 查角色图「管什么」那句和固定特征有没有逐字写 |
| 画风滑向 CG | 读回 Flova 实际用的提示词，看有没有被改成 3D 渲染方向 |
| 首帧和确认过的不一样 | 核对 @图片 编号和上传顺序；偏差小就靠剪辑吸收 |
| 提交报错，被当成编辑任务 | 删掉「改成、修改、替换」这类词 |
| 两镜接处机位跳一下 | 剪切点放在运镜静止处 |
