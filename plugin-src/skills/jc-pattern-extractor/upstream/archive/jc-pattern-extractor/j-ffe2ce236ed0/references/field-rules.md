# 六字段细则

汇总文件每条素材只有以下六个字段，其他信息一律回素材目录的 笔记信息.md 查看。

## 1. 素材文件

写素材目录的当前相对路径（如 `02_内容素材/未参考/小红书/小红书_什么是 Skill？_6a6611ae000000000301e16b/`）。素材从「未参考」移到「已参考」后同步更新这里；规律文件引用素材时只用「素材编号《标题》（平台）」。

## 2. 平台与形式

平台 + 视频/图文 + 时长，如「小红书 视频 8分29秒」。时长缺失写「未采集」；图文笔记无时长字段，写「抖音 图文（时长不适用）」，不算缺口。

## 3. 标题

- 小红书：抄笔记标题原文。
- 抖音：标题（item_title）和描述（caption）是两个独立字段，社媒助手复制的「视频描述」是两者拼接后的结果。标题必须用 TikHub `fetch_one_video` 返回的 `item_title` 核实；作者未设独立标题（item_title 为空）时，抄视频描述第一句并注明「取自视频描述」。
- 核实过的标题注明核实方式和日期。

## 4. 平台文案

- 小红书：抄笔记正文全文原文，保留话题标签，不改写不删减。
- 抖音：抄 `caption` 字段（去掉标题后的真实描述）；描述只有话题标签时如实记录并注明。

## 5. 封面/首帧文字

- 按素材目录里的图片文件名顺序记录为「01.jpg：……」，逐张读出图中全部文字，按视觉顺序用「/」分隔。
- 图片只有画面无文字时写「无可读文字」；目录里没有图片时写「无封面图」。
- 图文笔记的正文图也记在此字段，注明是正文图和分辨率。
- 无法读取的图片记录具体路径，不得跳过或推测内容。

## 6. 口播开头与口播结构

- 「口播开头 1-3 句原文」从逐字稿开头照抄，保留口语和语气词，不改写不润色；逐字稿带时间戳的保留起始时间戳。
- 「口播结构」按逐字稿实际讲述顺序列出，用箭头连接，包含结尾动作（引导关注、引导评论、留钩子、下集预告、行动号召等）。不提前压缩或合并步骤，不套用「痛点—方法—总结」这类现成模板。
- 素材目录没有逐字稿的（图文笔记、未转写视频），两个字段一律写「无逐字稿」。

## 四位置分离原则

标题、平台文案、封面文字、口播开头是四个不同位置，分开识别，不得互相顶替：不把封面上的一句话当口播开头，不把视频描述当口播原文，不把描述第一句当已核实标题。

## 规律条目格式（AI 示例）

```markdown
## 规律 1：【模式名】

- 大白话解释：……
- 适合什么内容：……
- 不适合什么内容：……
- 不可照搬点：……
- 来源素材：
  - 素材 01《什么是 Skill？》（小红书）
  - 素材 08《第1集｜什么是大模型》（抖音）
- 状态：本期可用（YYYY-MM-DD 用户确认）   ← 仅在用户确认后添加
```
