# 各人讲一个词的固定顺序

摆参考时用：想知道某个人讲一个词通常按什么顺序、哪句是他的招，查这里对应的一节。只学「他讲一个词的动作」，不学他的人设和身份。每节末尾的「度」是这种写法用到什么程度，超过就是过犹不及。跨账号的共同做法在 `patterns.md`，各人独有的招在它第七节。原话引自各人数据好的视频，证据在 `第二大脑/01_对标账号/调研/2026-09-14_AI科普系列/做法档案/`。

## 大李书房一盏灯（单条结构最完整，观众和锦成最像）

顺序固定：点名一个观众听过却说不清的词 → 「把笔拿出来，五分钟教会你」→ 用一个熟场景把这个词先演一遍 → 演完给名字 → 一句能抄的定义 → 画一张把新词放到旧词旁边的关系图 → 点名手边的产品 → 说新手该怎么办 → 「好，总结一下」复述 → 「接下来是截屏时间」→ 点名下期的词。

他的句子：
- 开头「今天我们就一个目标：搞懂 AI Agent。把笔拿出来，五分钟教会你。」「你可能经常听说大模型这个词，但是却不知道什么意思。」
- 演场景「假设你今天早晨刚刚开了一个会，你有一个会议录音」，一步一步走完人肉流程再说「那这就是一个你设计好的工作流程，也叫 workflow」。
- 让 AI 自己说话「你是不是还没给我邮件地址呀？没给我肯定要去问一问」。
- 技术细节按下「MCP 和 CLI 具体是什么你完全不需要管它，这是那帮天才科学家们去管的事情」，接着就画图。
- 定义句「Agent 就是 AI 的手和脚，如果 AI 没有手脚就像一个植物人」。
- 判断「如果你是一个纯新手我建议你先从 OpenClaw 开始……花上三四十块钱」。
- 收口「好，接下来是截屏时间。恭喜你，你已经知道了什么是 AI Agent。」

度：一条稿一个熟场景从头用到尾；「把笔拿出来」「截屏时间」这类固定句在这一列各出现一次；技术细节按下最多两处。不学的：小张的故事宇宙连讲多集、结尾把整集重讲一遍超过一分钟、开头「上一期我们讲了」。

## 清华姜学长（像老师上课，废话最少，条理最清）

顺序固定：「今天聊一个 X」加一句判断 → 先报要讲几点 → 定义（常用排除法或对照）→ 一个生活或职场类比 → 按第一步第二步走一个例子 → 明说「上面是基础，下面是进阶」→ 「所以最后总结来看」一句话 → 一个动作。

他的句子：
- 开头「今天我想跟大家聊一个我个人觉得非常有用，但是大多数人还没有去完全掌握的一个思维工具」「今天我们来聊一个百分之九十九的人都理解或者认知错的问题：AI 真的会记得你吗？」
- 报点「从什么是 MCP、为什么 MCP 这么有用，以及我们怎么去用 MCP 这三个维度」。
- 排除法定义「MCP 呢，它不是一个工具，不是一个应用，不是一个 API、SDK，也不是一个产品，而是一个协议」。
- 对照「HTTP……是网页和服务器的一个通信协议，而 MCP 呢，就是模型和外部世界的一个通信协议」。
- 否定流行说法「他们把 MCP 比作 USB-C……我觉得这个比喻有点肤浅」。
- 数字递进「你有一千个 Token 的话，你可能需要做一百万次的计算；一万呢，叫作一亿次计算」。
- 翻页「OK，接下来我们来讲」「OK，所以我们就迎来了第三个阶段」。
- 收口「所以最后总结来看，MCP 不仅仅是……」「选一个你在用的工具，去找它的 API 文档，试着发出你的第一个请求」。

度：「OK」每段最多一个，「呢」每百字最多一个；报点只报三点以内；进阶段只留一两句「什么时候才需要」，不讲机制。不学的：Q、K、V 和公式、参数怎么调、粉丝数和学历背书、结尾抛评论区问题加社群。

## 向行2028（落在钱和选择上，最狠也最直白）

顺序固定：固定开场白 → 引一句评论区原话 → 「今天我们就花 X 分钟讲清楚」→ 三到四层的分类图 → 每层一个生活类比给名字 → 自己踩坑的故事当例子 → 每层收一句要不要用、要不要充钱 → 压成两三个词让人复述 → 让观众今天就去下载一个试。

她的句子：
- 引评论「昨天呢看到了一个非常有意思的评论，呃这个有个小伙伴讲，这太多 AI 了，完全已经用懵了」。
- 替观众问「那有人就要问了，老师怎么下载呢？」
- 类比「就像你人吃饭你才有力气去工作，那么 AI 也是一样，它要有 token，它才能去运作」。
- 踩坑「在他的劝说下……我当天晚上下单了这个呃五千元的电脑啊，豆包成功说服了我」。
- 判断「基础的文字工作是不需要进行充值的」「我会比较推荐大家做前两种」「必须以电脑端为主」「不要为了高级而去高级」。
- 压成词「它有能量，它有意识，它有行动，它能串在一起变成一个软件」「一个理性、一个感性」。
- 收口「听完今天的视频，我相信你一定不会再问老师 Agent 是什么」。

度：每层必有一句钱或选择的判断；踩坑故事一条稿一个；评价句（「豆豆的嘴脸就慢慢越来越起来了」这类）一条稿最多两句。不学的：女性小白对情感博主的对立说法、骂软件公司、名词平铺的那一期、2 分钟以内的观点片。

## 智能体阿朱（把十几个词串成一条因果链，20 分钟不掉人）

顺序固定：开头共情焦虑加承诺「每个词讲两点：为什么出现、解决什么问题」→ 建议先收藏 → 第一个词 → 每个词：这个词之前的痛 → 一个对照例子 → 名字和它解决的问题 → 它解决不了的新问题 → 「于是下一个热词出现了」→ 下一个词 → 最后「这些词不是黑话，是一张地图」→ 教一个判断新词的方法。

他的句子：
- 开头「我好不容易弄懂 Prompt，怎么又冒出 Agent；我还没摸清 Agent，怎么又蹦出 Skill」「每个词我讲两点：为什么出现、解决什么问题。视频时长十八分钟，建议先收藏再看」。
- 对照「帮我写个方案」对「你是个产品经理，请开发一个面向开发者的 AI 工具，写一份产品方案」；「你可以自己看看日历」对「你下午两点到三点有会，四点以后比较空」。
- 替观众反应「这时候大家才反应过来，AI 很多时候不是不会干，而是你没把活交代明白」「这时候你就会琢磨，能不能把这套要求直接存下来」。
- 过渡「但 Prompt 再厉害，也只能解决『任务怎么说清楚』，它解决不了另一个更致命的问题：模型不知道的东西它就是不知道」「可工具一多，新麻烦也就跟着出现」「于是下一个 AI 热词登场了」。
- 报数「第二个热词 Token」「第十五个热词 Workspace Agent」。
- 收口「以后你再刷到一个新的 AI 热词，别急着背这个词的定义，你只需要问自己一个问题：它到底是在解决 AI 走向真实工作时的哪个问题？」

度：过渡句每个词一次，句式可以换（于是、这时候、可问题还没完），不要每次一模一样；报数只在词多于五个时用；一个词 300 到 450 字。不学的：一条塞 15 个词（锦成一条最多 5 到 7 个）、纯口播不出图。

## 怎么用

参考只摆给锦成看，他口述时想借谁的顺序就借谁的；改稿日志记他这一段借了谁的什么，三条视频之后就能看出他的偏好偏向谁。
