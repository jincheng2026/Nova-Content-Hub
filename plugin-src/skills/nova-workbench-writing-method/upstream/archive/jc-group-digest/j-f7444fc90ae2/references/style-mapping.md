# 群气质到视觉风格映射（检查点 2）

输入：群画像 + 阶段 2 的 3 天真实精华数据。产出：2 到 3 个候选风格 demo，用户手机上挑一个。

## 推导方法：从群画像的三个维度到视觉语言

1. **内容形态**：以长文深度内容为主的群，视觉为「阅读体验」服务（衬线标题、大留白、克制配色）；以短平快信息为主的群，视觉为「扫读效率」服务（卡片、列表、强层级）。
2. **成员气质**：职业构成和说话方式（术语密度、表情包密度、正式程度）决定视觉的「体感温度」。满屏行业黑话的群配冷峻工具感，聊生活聊到深夜的群配温度感。
3. **情绪基调**：群的主导情绪是严肃克制、温暖热闹还是效率至上。视觉基调跟着走，反着配会让群成员觉得「这不是我们群」。

每个候选方向都必须能说出推导链：「因为群里有 XX 证据（引群画像），所以配 XX 视觉」。说不出推导链的方向不要出。

## 映射表（起点，允许组合出变体）

| 群气质 | 视觉方向 | 关键元素 |
| --- | --- | --- |
| 读书 / 人文 / 深度内容 | 杂志风 | 衬线标题、大留白、暗色或米白底、单一克制强调色、极细分隔线 |
| 技术 / 情报 / 工具 | 终端风 | 等宽字体点缀、深色底、绿或琥珀强调、代码块美学、紧凑信息密度 |
| 生活 / 育儿 / 兴趣 | 暖色卡片风 | 圆角卡片、奶油或浅暖底色、柔和但明确的强调色、宽松行距 |
| 投资 / 商业 | 金融报纸风 | 数字与表格美学、窄栏多列感、红绿语义色、报头式标题 |
| 健身 / 打卡 / 行动 | 高对比运动风 | 超大数字、粗黑标题、强撞色、进度感元素 |

映射表是起点，最终以群画像证据为准。气质混合的群（比如技术人的读书群）做组合变体，主气质定底盘，次气质做点缀。

## demo 要求

- 每个方向一个独立单页 HTML，**必须用阶段 2 的 3 天真实精华数据填充**，禁止 Lorem ipsum 和编造内容。原因：占位文字看不出中文排版、长短消息混排、超长清单这些真实场景的效果，挑了也白挑。
- demo 阶段就要遵守 tech-redlines.md 的字体红线（系统字体栈、零外部资源），否则用户挑中的效果和上线效果不一致。
- 本地起服务给手机看：

```bash
cd <demo目录> && python3 -m http.server 8899
# 局域网地址：
echo "http://$(ipconfig getifaddr en0):8899"
```

把局域网地址发给用户，让用户用手机（最好在微信里打开一次）挑。手机上挑的原因：最终用户几乎全部在手机微信里看这个站，桌面浏览器的效果没有代表性。

## 通用审美底线（所有方向都要守）

- 高级感来自克制：强调色一到两个，层级靠字号、字重、间距拉开，禁止靠加颜色加图标堆
- 禁止装饰性 emoji
- 中文排版基线：正文行高 ≥1.7、字号 ≥15px、段间距明确大于行间距
- 暗色方向要过对比度检查（详见 tech-redlines.md 的可读性条目）
