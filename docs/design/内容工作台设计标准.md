# 内容工作台设计标准

本标准约束自媒体工作台后续的页面、弹窗、控件与视觉验收。目标是延续用户指定的「内容工作台」配色、层次、多图 VI 和玻璃表面，同时使用项目现有 Semi UI、N 图标及业务流程。它是设计与实现约束，不是已完成验收声明。

## Surface：卡片与玻璃

| ID / 适用 | 规则与精确值 | 验收 / 代码归属 |
|---|---|---|

| **Surface-02 / 玻璃层** | 参考侧栏 `rgba(255,255,255,.72)` + `saturate(180%) blur(20px)`；图片角标白底 `.75–.92` + `blur(6px–8px)`；图片 Hero 次按钮白底 `.16` + 白边 `.25`。适配：将模糊集中于侧栏、悬浮工具和覆盖层，正文阅读卡保持实白。 | 玻璃后有可辨识层次但文字清楚；不将所有白卡统一半透明。低性能/无滤镜环境用同色更不透明底保证可读。归属外壳、图角标和浮层样式。 |
| **Surface-03 / 模态** | 参考圆角 24px、投影 `0 30px 80px rgba(0,0,0,.25)`；常规模态遮罩黑 `.35`、`blur(6px)`，图片大预览遮罩黑 `.45`。常规宽度 `min(92vw,560px)`，宽表单 `min(94vw,860px)`；图集可至 `min(96vw,1100px)`。 | 适配项目现有宽表单/设置容量；标题、关闭与提交可到达，正文长时内部滚动。焦点进入、Tab 范围、Esc、关闭后归位以及未保存保护完整。归属 `ManagementDialog`、提示词/图片 dialog、`assistant-settings.tsx`。 |

**Image-01 / 图片边缘**：列表、卡片、模板叠图与照片缩略图使用小圆角矩形，主体图约 10px，紧凑缩略图 5–8px。圆角跟随实际图像边缘，横图留白时不能只给外框加圆角；使用等比完整展示，不以椭圆、胶囊或 `cover` 裁掉封面文字。图集/原图与批注坐标画布保留原矩形，装饰背景单独处理。此规则只改变显示，不改原图字节、尺寸或下载内容。

## Interaction：动效与行为边界

| ID / 适用 | 规则与行为 | 验收 / 代码归属 |
|---|---|---|
| **Interaction-01 / 常规动效** | 参考基础过渡 `180ms cubic-bezier(.2,.7,.3,1)`；局部叠图可 320–380ms。适配只为当前状态变化提供反馈，保留现有异步忙碌/错误态与可取消机制。 | 动效不承载唯一的信息，也不延迟保存/选择的完成；悬浮缩放不遮挡相邻控件。 |

| **Interaction-03 / 范围** | 当前工作改变视觉和明确要求的资料交互；业务实体、库结构、权限边界、IPC 与生成/发布规则继续由既有模块负责。 | 不新增依赖，不复制参考业务实现，不改现有 N 品牌。流程需改动时先标出用户要求及受影响调用者。 |
