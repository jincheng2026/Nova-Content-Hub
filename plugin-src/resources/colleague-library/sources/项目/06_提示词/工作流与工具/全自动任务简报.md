接下来这个任务你可以按无人值守的方式去推进，信息我一次性给你：

- 目标：{{要达成什么}}
- 背景和素材：{{相关文件/资料路径}}
- 截止时间：{{时间}}
- 交付物：{{最终要给出什么形态、什么数量}}
- 交付方式：完成后把结果放在 {{路径}}，并通过 {{日历/文档等方式}} 通知我，不用实时汇报进度
- 卡点处理：如果中途遇到需要我决策的事，不要停下等我，先把情况写进 {{异步沟通文件路径}}，然后继续做其他能做的部分

请先确认这些信息是否够你开始，如果够，就直接开始推进。
