## 演示顺序

1. 打开自媒体工作台，在设置补充个人信息并添加自己的照片。人物照片需要明确本人声明；也可以全程选择“这次不放人物”。
2. 设置里选择 Codex 或 WorkBuddy。所有生成入口使用这里的助手；配套插件需要安装并启用，实际生成使用助手现有套餐。
3. 设置 → 发布渠道 → 管理渠道，新建常用渠道并设置封面比例。之后在内容与日程中直接选择，不重复创建。
4. 内容 → 新建内容，填写标题、正文并保存。合集可把同一系列内容归在一起。
5. 制作封面 → 选模板组、人物参考、张数与比例 → 去当前助手生成。模板样张数和生成张数分开设置；发出后回工作台选择候选并下载原图。候选可收藏并筛选，选择 2–4 张后并排对比；需要局部修改可用“批注修改”，点原图位置写要求，再明确确认交给助手生成新候选。
6. 发布计划 → 选渠道、日期与时分，保存。日程月视图看整体、周视图看时段。只定日期的计划显示“时间待定”。
7. 到社媒平台手动发布后回到计划点“记录已发布”。误填可更正或撤销，本机保留原记录；操作不会自动发送或删除平台帖子。
8. 提示词 → 选择条目，右侧填写并复制。关联内容后主动勾选才带入正文；可返回原内容继续编辑。
9. 内容库 → 备份与维护，演示备份入口。恢复会新建独立目录，原库保留。

## 安装与演示环境

- 当前实际验证机器为 Apple 芯片 Mac。Apple Silicon / ARM64 包用于 M 系列 Mac，不能发给 Intel Mac 或 Windows 当作通用包。
- Mac 双击 DMG，拖入“应用程序”；也可按工作台提示移动到应用程序。已有版本会先完整校验并保留旧应用再替换。
- 免费体验包尚未完成苹果 Developer ID 签名、公证。首次打开可能被系统拦截；先使用系统设置 → 隐私与安全性里的“仍要打开”。不要把任意安装失败都解释为隔离标记；损坏文件应重新校验或下载。
- 内容库单独保存在用户选择的本机目录，升级应用不应替换内容库。勿删除“系统（别动）”目录。
- 现场生图耗时、服务是否可用及额度由所选助手决定。准备一篇已回流两张真实候选的内容，可先展示选图、下载和日程，再现场发起新生成。
- 当前测试库含虚构创作者、验收内容和验收历史，不代表真实平台发布。个人模板学习结果仍待人工验收，不冒充已验收模板。
