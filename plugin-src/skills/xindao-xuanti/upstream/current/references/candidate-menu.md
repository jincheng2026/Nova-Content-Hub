# 候选菜单与定题

## 选题卡字段

每张卡固定七项，一行一件事：

| 字段 | 要求 |
| --- | --- |
| 选题名 | 内部工作名称，一句大白话说清这条讲什么；不是最终发布标题 |
| 说明 | 讲什么、给谁，一句话 |
| 改动 | 相对资料改了哪个词、哪句话或加了什么信息；原样的写「没有改，用资料的说法」 |
| 谁会感兴趣 | 具体人群，加一句人数多少、在不在意；不写「所有人」 |
| 资料够不够 | 资料的哪一段能兑现；不够时写清还缺什么 |
| 标题示例 | 一个，标注为示例；最终标题由后续包装任务定 |
| 要注意 | 只在有明显风险时写，一句话说清会发生什么 |

## 菜单格式

```markdown
这份资料可以讲成下面几个选题，从 1 到 4，面对的人越来越多。

1. 选题：……
   改动：……
   谁会感兴趣：……
   资料够不够：……
   标题示例：……

2. ……

我推荐 N。原因：一句话。

还想请你补充（最多两问）：……。补充后会写进选题说明和标题示例，观众更容易信你。

你可以回复编号，也可以直接说你的想法。
```

- 最多 4 张卡，第 1 张用资料原样的说法；有效候选不足时如实少给，不凑数。
- 推荐一张，给一句真实理由说清为什么是它，不只写「最好」。
- 追问最多 2 个，问用户手里可能有、观众会信的经历或数字；不需要时省略。
- 只覆盖资料某一段的方向不进菜单，可以在末尾用一句话提为「其他方向」。
- 菜单控制在一屏内；分析过程用户问「展开」「为什么」再给。

## 给用户的文字

- 一句话一个判断，写清谁做什么；
- 内部术语不出现：盘材料、放大点、底气、限定词、扩层、上限校验、收回主线、记忆点、大主题、占位；
- 效果预测与转化承诺不出现：爆款、必火、流量密码、稳上热门、互动率、转化、推播放、评论区容易起来、涨粉；
- 除标题示例外每行不超过 40 字；
- 用户的强判断和有力说法默认保留，不因扩层而建议削弱。

## 定题处理

用户回复编号、要求合并（如「3，加上我刚补的数字」）或提出新想法时：

- 新想法先一句复述理解，再按选题卡字段补全，等用户确认；
- 用户补了底气信息，写进选定卡片的说明和标题示例，至少用一处；
- 全部否掉时先判断原因——方向看错、改动不对、太大或太小——再按原因重新扩层，不原样重发。

## 定题交接

用户选定后输出交接字段，一次性给全，不另留影子记录：

```markdown
**选定选题**：<选题名>
**工作名称**：<选题名>（内部工作名称，非发布标题）
**卡片**：<选定卡片的完整字段>
**来源资料**：<本次使用的资料清单与出处；工作台模式含任务与内容引用>
**标题示例**：<示例标题>（标注：示例，正文定稿后由包装任务复核）
**未选候选**：<其余卡片随产物保留，可回看>
```

- 工作台任务模式：交接字段随研究类产物提交；建内容、写入工作名称与探索标题由工作台在验收后完成，本 Skill 不直接改内容库。
- 直接对话模式：输出交接字段后停，等用户确认再进行下一步。

## 停止线

菜单发出、用户选定、交接字段交出，本任务即完成。以下内容一律不提前交付：正文与逐字稿、开头钩子、正文结构、最终标题定稿、封面文字与图片、发布节奏。用户要这些时，一句话说明那属于内容创作任务。
