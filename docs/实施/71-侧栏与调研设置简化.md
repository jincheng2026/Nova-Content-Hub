# 侧栏与调研设置简化

2026-10-26，开发构建版本0.3.50，功能源码 `e51553b`。本轮承接用户截图及最新要求；不覆盖0.3.49的历史证据，也不以旧测试数量作为本次修改的验收结果。

## 实际修改

- 侧栏：原布局被后加载的grid样式覆盖，剩余高度分摊到四行。真实Electron复现折叠后的分组约147px、“提示词与知识”约147px。改用明确的纵向flex布局，一级行统一42px、间距7px；展开二级行36px；箭头仍靠右。
- 新建调研：删除固定粉丝数、点赞数字段及默认值，也删除任务prompt中自动拼接的低粉／爆款筛选条件。用户原始需求直接冻结。简单／精细模式、报告标题和逐任务评论勾选保留；短文本框遵循实际行数，避免通用240px最小高度撑大表单。
- 按需澄清：研究和写稿Skill共用任务契约。借鉴grilling的决策依赖和推荐答案，先读资料查事实，仅问实质影响本次成果、且前提已定的问题，允许自定义；已给的条件直接沿用。普通研究不加低粉限制；只有用户要求且口径不清时才推荐并询问范围。用户明确让助手自行决定的事项沿用该授权；任务不要求穷尽所有分支或额外确认才能开始。
- 设置：默认展示Key、模型和识别方式；接口地址、本地路径、备用云端配置可展开。原保存动作合并本地路径检查，移除独立检查按钮；无修改可重做检查而不重写配置。Key清除／撤销在原位置切换；只在有修改时显示“放弃修改”。已保存的值保留；保存失败保留输入；检查失败与保存失败分别提示。没有新增付费调用或修改真实用户的服务授权。

## 验证与证据

[本轮证据目录](../verification/production/2026-10-26-navigation-and-research-0350/)包含修改前复现和修改后真实Electron截图／回执。所有UI探针仅使用临时合成库和测试凭据，助手启动为mock，付费请求为0，未改写真实内容库。

- 两授权模式构建成功，包含native／renderer类型检查。
- 受影响的服务、生产控制器、助手runtime与skills契约测试58/58通过，见`targeted.log`；本轮没有重跑并冒称此前1222项为新的结果。
- 研究／写稿两个Skill的quick_validate通过，见`skill-validation.log`。五个规则场景人工核对：普通研究无低粉约束、口径未明才问、已有阈值直接用、问题按依赖分轮、推荐不扩大费用或评论授权。这是指令与路由核对，不是对真实助手所有回答质量的保证。
- Electron1440×1000及1000×800：收起后的四行均42px、间距7px，隐藏子项不占空间；展开后仍可导航；报告标题和未勾选评论保持；冻结prompt与输入一致；短需求输入区小于150px。
- 设置真实UI／IPC：默认高级配置折叠，正常仅一个主保存动作；清除可同位撤销；无效HTTP地址保存被拒后输入保留；更正后保存成功并执行本地检查；没有修改时重复检查不重写凭据文件，也不打开预算。本地测试路径故意不存在，未将其写成模型识别成功。
